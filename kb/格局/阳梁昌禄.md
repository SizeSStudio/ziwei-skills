# 阳梁昌禄

> **原始星意级重建：太阳（亮 / 高 / 发散，庙旺）+ 天梁（顶梁柱 / 正统，庙旺）+ 文昌（传播 / 传导）+ 化禄（增幅）= 一个「被大的正统机构宣传出去」的意向。**
> 「阳梁昌禄主科甲、状元、贵显」是吉凶标签。本 KB 拒绝用五行（火土相生之类）去解，直接拿四颗组成星的原始星意拼出这个「被官方放大宣传」的象。

## 原始星意级重建

阳梁昌禄指 [[../星曜/主星/太阳|太阳]]、[[../星曜/主星/天梁|天梁]]、[[../星曜/辅星/文昌|文昌]]、化禄四者会合。源文（mid-2247484268）特别强调：别用五行去绕——

> "其他流派在解说这个格局时……扯什么五行中的火、土结合啥的，说的玄而又玄，不着门道！……在自我论断星意中，直接拿星的原始星意去论断就好了，扯五行只会变得不伦不类，因为这都不是一个系统的！"

逐颗退回原始星意，并注意**庙旺是硬条件**：

- **太阳 = 亮、光、前、新、高、广博。** 格局要求太阳**庙旺**——庙旺才是「高、发散、向外放光」；落陷就是「矮、收敛」，发不出去，格不成。
- **天梁 = 根、柱、受力的（顶梁柱）。** 庙旺的天梁有「正统」意——三观正、跟着时代主旋律走、靠得住；落陷则是「偏门、小众、靠不住」。格局同样要求**庙旺**。
- **文昌 = 传播 / 传递 / 传导**（文昌原始星意含「传递消息」与「偏斜」两义，此处取传导义）。它是把太阳天梁那份「高 + 正统」**传播出去**的通道。
- **化禄 = 增幅 / 放大 / 开始。** 它把太阳和天梁原本的意向**加大**——是一个放大器。

合起来：**一个「高 + 正统」（庙旺太阳 + 庙旺天梁）的东西，通过「传导」（文昌）被「放大」（化禄）出去 = 被大的正统机构大规模宣传出去的意向。** 源文原话：

> "天梁是庙旺的人，只要没有跟毁坏的意向结合在一起，其实就是代表三观正……古代被大肆宣传的好的，一般都是考试，考上了然后上报纸了！"

所以「状元 / 登科」只是这个象在**古代语境**下的落地——古代被正统机构大规模宣传的事，主要就是科举高中。命理是「通过结果反推」的学问，「阳梁昌禄 = 状元」记录的是结果意向，不是机制；机制是「高+正统被官方放大」。

## 正向应卦（在哪类事 / 哪个时代显吉，哪类显凶）

这个格局少见地**偏吉**，但仍受正向应卦约束，且作者亲自点出它常落空：

- **显吉（事的性质 = 走正统体系、要被官方/主流认可放大）：** 在「被正统机构宣传」能直接兑现成好处的赛道上——古代的科举功名，现代对应的是体制内晋升、考公考编、走主流评价体系（学历、职称、官方奖项、上「正统榜单」）这类「正统机构盖章 + 大规模背书」的事。事的性质与「高+正统+被放大宣传」对号，于是显化为名声、台面上的认可、顺势上位。
- **显凶 / 落空（事的性质 ≠ 正统体系，或太阳被引偏）：** 太阳原始星意是「向外放、放大」，一旦旁边换了煞星，放大的就不是名声而是别的。作者明说太阳「庙旺加擎羊 = 放大伤害」（眼睛/光芒刺人，反被修理）。而且——

> "我们之前说过阳梁昌禄，这个是大众意义上比较好的格局，但好事不出门，坏事传千里，大多数人都是应在不好的地方的。"（mid-2247484315）

也就是说，「被大规模传播」这个核心象，**对号正统好事**才显化为登科扬名；很多人这股「广而告之」的力**不对号、或被煞星引偏**，反而应在「坏事传千里」上。所以阳梁昌禄绝非「有此格必贵」——要看这个人是不是真走在「被正统体系放大」的事上。

## 落宫 / 应用要点

- **四件齐 + 太阳天梁双庙旺**，才谈得上成格；缺一角或太阳/天梁落陷，按各星本意单读，别套「科名」。
- **化禄是引动键**：源文反复提「用甲干让太阳化忌/化禄去点亮太阳」——太阳没被点亮时，旁边再好的星（天贵、天喜）也是「藏着、没被发现」；一旦四化引动，格局才真正启动。判此格要连四化引动一起看，不能只看先天有没有凑齐。
- **核心象是「被正统机构放大宣传」，不是「考试」本身**。换到今天，凡「靠官方/主流体系背书放大」的事都吃这个象；脱离正统体系，则这股「放大」可能应在别处（甚至坏事）。
- **校验方向（[[../断事方法/现实校验|现实校验]]）：** 过去是否有过「被官方/主流渠道公开表彰、上榜、放大」的经历（升学、获奖、考编上岸、被正式宣传）？还是这股「爱往外放、想被看见」的力反而招来过「坏事传千里」式的反噬？据此判断它对号在哪一端。
