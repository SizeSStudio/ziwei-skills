# 杀破狼

> **原始星意级重建：七杀（线/片）+ 破军（破/新/找/打）+ 贪狼（体积/欲）三颗星在盘上互成 120° 三方，永远绑死在一起的一组「动」结构。**
> 「杀破狼 = 大起大落 / 命苦」是吉凶标签，不是结论。本 KB 先把它退回成「这三颗星各自的底层含义 + 它们为什么必然同框」，再按事的性质判显吉显凶。

## 原始星意级重建

杀破狼不是一个被单独取名的「格」，而是天府星系 / 紫微星系排盘结构里一个**绕不开的事实**：[[../星曜/主星/七杀|七杀]]、[[../星曜/主星/破军|破军]]、[[../星曜/主星/贪狼|贪狼]]这三颗星，在任何一张盘上都互成三方四正（彼此隔四宫），位置一旦定下就同时定下，谁都甩不掉谁。所以谈「杀破狼」，本质是谈这三颗「动星」凑在一起会合成什么。

先把三颗星各退回原始星意：

- **七杀 = 线 / 片（平面）。** 七杀属金、无四化，是对维度的抽象——把三维压成二维的「面」、把二维压成一维的「线」。性格上呈现为**直、单线、把事情拍平、直来直往**。本身不带特别含义，旁边是什么就纯粹放大什么。
- **破军 = 破 / 新 / 找 / 打。** 先打破现状，再立新。是「掀桌子、换棋盘」的力量——革命、创新、把旧局面砸了重来都靠它。
- **贪狼 = 体积 / 量的涨缩。** 一个东西忽大忽小，延伸到人身上就是欲望的膨胀与放下。

把三者合起来：**一个不断「想要更多（贪狼）→ 把现状打破重来（破军）→ 把事情拍直拍平、单线推进（七杀）」的循环。** 这就是杀破狼给人的整体观感：不安于现状、动得厉害、阶段性地推倒重来。传统说的「大起大落」，其实是这股「动」在时间轴上的投影——不是命定的吉凶，是这组结构天然「不肯停」。

### 关键：它是一个系统，不能单宫论

这是本 KB 对杀破狼最重要的一条立场。源文里作者明确反对「破军在夫妻宫 = 杀破狼 = 婚姻很差」这种单宫断法：

> "很多人说，'破军星是杀破狼，在夫妻宫上很不好啊！'说出这些话的人，我很想给他们框框来上几拳，脱离了系统的思想，以单宫论是很容易出现这样的问题的。紫微星系、天府星系是一个系统，每颗星都是按照一定的顺序排列的，所以，天府的夫妻宫必然是破军。"（mid-2247484364）

换句话说：天府坐命的人，夫妻宫**必然**是破军、迁移宫**必然**是七杀、福德宫**必然**是贪狼——这是排盘锁死的，不是「碰巧凑出一个凶格」。把破军单拎出来喊「不好」，等于责怪结构本身。正确读法是看**这个动的结构落在哪个宫、对号哪类事**。

源文给的范例（天府坐命）：贪狼在福德（他向往的）、七杀在迁移（他看着像的）、破军在夫妻（他要找的伴侣类型）——三颗动星刚好框住「天府缺什么就向往什么」的心理：一个本性藏、守、稳的人，骨子里反而追逐杀破狼式的折腾，去找一个破军型的伴侣来补自己的缺。

## 正向应卦（在哪类事上显吉 / 显凶）

杀破狼的「动」本身不分好坏，**事对号入座就是吉，不对号就是凶**（[[../断事方法/正向应卦|正向应卦]]）：

- **显吉（事的性质 = 需要动 / 需要破旧立新 / 需要扩张）：** 创业、转型、开拓新市场、做需要不断迭代推倒重来的事（产品、创作、革命性的活）、运动员/外科这类需要「线、片、切、冲」的行当。事情本身就要求「打破—扩张—拍平推进」，杀破狼的结构正好供得上这股力，于是显化为闯劲、突破力、规模感。
- **显凶（事的性质 = 需要稳 / 需要存 / 需要守成）：** 守一份不能折腾的家业、需要长期稳定积累的关系或岗位、求「安稳不变」的人生。事情要求「停住、存住」，而结构偏偏「停不下来、隔几年就想推倒」，于是显化为反复、留不住、积累被自己打断——传统说的「破败」「劳碌」就是这种**结构与事不对号**的结果，而非杀破狼天生坏。

所以任何「杀破狼好不好」的问题，都必须先反问：**这件事需不需要动？** 需要动则吉，需要静则这股动反成消耗。

## 落宫 / 应用要点

- **永远三方同参，不单宫断。** 看到破军/七杀/贪狼任一坐某宫，先把另外两颗在哪一并调出来，再读整组「动」结构投在哪三件事上。
- **庙旺定动的「量级」，不定吉凶。** 贪狼庙旺=欲望/体积大、破军庙旺=破得彻底，量级越大，对号时越猛、不对号时反噬也越大。
- **旁边的小星定动的「方向」。** 七杀本身纯，左辅就是双线（事业双线 / 感情脚踏两条船 / 多个孩子），地劫就是断线，文曲就是曲线——杀破狼最终长什么样，看挂在三颗主星旁的小星。
- **疾厄 / 身体维度：** 七杀（线、片、动刀）+ 破军（破、打）落疾厄相关位时，要结合小星看「切、破、伤」的应法，而非笼统说「身体差」。
- **校验方向（[[../断事方法/现实校验|现实校验]]）：** 过去是否出现过「主动或被动地把一段关系/事业/居所推倒重来」的节点？折腾后是更好还是更耗？据此回证这股「动」在此人身上是对号还是不对号。
