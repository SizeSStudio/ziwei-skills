# 格局

翻星摇斗 / 原始紫微对「格局」的态度是**破除格局迷信**——把每个格局退回到它的星意组合，不靠口诀，不下吉凶标签。所以这个目录不是传统格局大全，而是**「常见格局的星意级重建」**。

## 概念页写作规范

每个格局页按本 KB 主线结构写（与 [[../星曜/主星/贪狼|星曜页]] 同一套语言）：

1. **原始星意级重建** — 把格局拆成组成星的底层含义，再合成出那个「象」。说清为什么会有那个常见的现实结果。
2. **正向应卦** — 同一星组合，**事对号入座就显吉，不对号就显凶**（[[../断事方法/正向应卦|正向应卦]]）。任何吉凶判语必须附「在 X 类事上才 Y」的语境。
3. **成立条件 / 落宫 / 应用要点** — 只有某几颗辅星/煞星也在场时才真正成立（如泛水桃花要天姚/咸池）；庙旺定量级不定吉凶；落宫换解释对象。
4. **现实校验** — 给出可回证的过去/可查事件（[[../断事方法/现实校验|现实校验]]）。
5. **支撑文章** — wikilink（路径 `../../sources/...`）。
6. **参考（他派对照）** — 全书/中州/飞星的说法只放在**页尾**这一节，作反面参照，绝不写进主线。
