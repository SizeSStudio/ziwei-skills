# 廉贞七杀（半路埋尸）

> **原始星意级重建：廉贞（抓 / 禁锢）+ 七杀（线 / 片 / 平面压缩）落在丑宫（地辟之地 / 坟 / 与另一个世界的交界）= 被规则铸成的坟墓里的、被压扁的生存空间。**
> 「半路埋尸」是被夸张化的意象标签，源文原话就说它「实则是种夸张的意象化表达」。本 KB 把它退回三件事：廉贞抓什么、七杀压成什么、丑这个位置意味着什么。

## 原始星意级重建

「廉贞七杀」指 [[../星曜/主星/廉贞|廉贞]] 与 [[../星曜/主星/七杀|七杀]] 同宫；古书所称「半路埋尸」特指它落在**丑宫**（或廉贞在此化忌）时的意象。逐层拆：

- **廉贞 = 抓、密、复杂、血、癌。** 原始星意是「抓取的力度」——管得多、抓得紧、眼里容不得沙子。投到精神层面就是「禁锢、枷锁」，像 24 小时盯着的监控；投到身体层面常指血液、肿瘤。
- **七杀 = 线 / 片 / 平面。** 把维度压平。投到「空间」上，就是**生存空间被压缩、被拍扁**——像被压扁的易拉罐。
- **丑宫 = 坟。** 「混沌初分，天开于子、地辟于丑、人生于寅」，丑是「地辟之地」，又是人与另一个世界的交界处，所以取象为「坟」。

把三者叠起来：**廉贞（抓 / 禁锢）施加在七杀（被压扁的空间）之上，又落在丑（坟）这个位置 = 一个被规则、被高压抓死，压得喘不过气，仿佛活在坟墓里的局面。** 源文给的具象比喻：

> "廉贞象征'精神禁锢'（如枷锁般抓取管束），七杀代表'平面空间压缩'（如被压平的生存空间）……当禁锢（廉贞）施加在受制空间（七杀）之上，恰似原本开阔大地凸起压抑土包，象征被规则束缚的生存空间。"（mid-2247484076）

所以「半路埋尸」根本不是「会横死在半路」这种字面凶兆，而是**「被规则铸就的坟墓里」的窒息感**这一意象。

### 它常应在「父母 / 管控」，且要靠小星定具象

源文的实战范例里，廉贞七杀落**父母宫**，配上煞杂曜，被读成一套「高压监狱」式的成长环境（mid-2247484076）：

- **擎羊（伤害）+ 天刑（刑罚）** = 体罚 / 精神打压的「混合双打」——客厅挂戒尺、书房摆家法的意象。
- **恩光 + 天寿** = 「无影灯式」的监控：持续（天寿）且无死角（恩光）。
- **天虚 + 天才** = 高压下思维被压抑：能思考（天才）却在高压下虚脱（天虚），表面乖巧、内心写满叛逆。

可见**廉贞七杀本身只给「被抓死的压缩空间」这个骨架，具体压成什么样、应在哪类人事上，全靠旁边的小星填充**——单看「廉贞七杀」喊凶是没意义的。

## 正向应卦（在哪类事上显吉 / 显凶）

「抓死 + 压缩空间」这个结构，**对号则吉，不对号则凶**（[[../断事方法/正向应卦|正向应卦]]）：

- **显吉（事的性质 = 本来就需要把东西抓死、压紧、严格框住）：** 需要极强纪律、严密管控、把流程压成一条线死死执行的事——高度规范化的技术/管理岗、需要「抓得紧、不容出错」的把关工作，乃至外科（廉贞=血、七杀=线/片，切、缝、压）这类「对口」的行当。事情本就要求「抓紧、压实」，廉贞七杀正好供得上，于是显化为强执行、严谨、扛得住高压。
- **显凶（事的性质 = 需要松、需要喘息、需要自由生长）：** 成长环境、亲密关系、需要个性舒展的事，被这套「抓死 + 压扁」罩住，就是窒息——父母宫范例里的「高压监狱」、亲密关系里「控制与被控制」的轮回模板，都是结构与事不对号的结果。

判廉贞七杀好坏，先问：**这件事需不需要被抓死、被压紧？** 需要则这股「抓」是定力，不需要则它是牢笼。古书的「半路埋尸」只是把「不对号那一端」夸张成了凶兆。

## 落宫 / 应用要点

- **丑宫 + 廉贞化忌** 才是「半路埋尸」意象最浓的位置；廉贞七杀在其他宫，读「抓死的压缩空间」骨架即可，不必套「埋尸」凶名。
- **骨架靠小星填具象**：擎羊/天刑加重「刑罚、伤害」，恩光天寿加「无死角监控」，天虚天才加「高压下的思维压抑」——廉贞七杀长什么样看挂在旁边的小星。
- **看是谁的「抓」**：落父母宫 = 父母/长辈的高压管控；落命/疾厄相关 = 自身被规则/疾病抓住（廉贞=血、癌时尤其要谨慎，结合 [[../星曜/主星/太阳|太阳]]、[[../星曜/主星/天机|天机]] 同看，按 mid-2247484315）。立太极点不同，「抓」的施受方就换（[[../断事方法/宫位立太极|宫位立太极]]）。
- **校验方向（[[../断事方法/现实校验|现实校验]]）：** 成长中是否有过「被严密监管、动辄受罚、喘不过气」的真实经历？当下是否在一段「控制与被控制」的关系里？据此回证这套「抓死 + 压缩」结构是否成立、对号在哪。

## 参考（他派对照，非本 KB 主线）

> ⚠ 以下仅做辨析用，不进入本 KB 主线推理。

- **全书一脉**：「廉贞七杀于丑未，路上埋尸 / 半路埋尸」被当作凶险断语，主血光、横事、不得善终之类，强吉凶标签。本 KB 视「半路埋尸」为「被规则铸就的坟墓」这一**意象**，明确指出它是夸张化表达；吉凶取决于所做之事是否需要「抓死 + 压紧」（正向应卦），并由旁边小星定具象。
- **中州派 / 飞星**：重视廉杀的煞忌会照与大限引动来定应期。本 KB 星意层可与之并存，但不混用「见煞忌即应凶」的判语。
