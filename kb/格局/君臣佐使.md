# 君臣佐使

> **它不是一个「星组合格局」，而是一套读盘的「分层 / 优先级」框架——借中医方剂的君臣佐使，给盘上各要素排权力位次：先认核心矛盾（君），再配辅助（臣），再设制衡（佐），最后铺传导（使）。**
> 放进「格局」目录是因为习惯上有人这么叫，但本质是**方法 / 思维范式**，不是「某几颗星凑一起 = 某结果」。判读时它管的是「先看谁、谁说了算」，不产出吉凶。

## 这一页和别的格局页不一样

其余格局页（杀破狼、紫府、廉贞七杀……）都是「某几颗具体星凑在一起，重建出一个象」。君臣佐使不是——它是源文（mid-2247484700，「紫微斗数重构7」）从中医「君臣佐使」搬来的**系统组织架构**，用来解决一个读盘的元问题：**面对一张盘上密密麻麻的星、宫、四化，先抓哪个、谁优先、谁制衡谁？**

作者点明它对应的是「**状态洞察优先于干预**」的范式——先准确掌握盘面当前的主要矛盾与次要矛盾，再谈改命/干预。所以它更像是 [[../断事方法/README|断事方法]] 的同类（语法 / 流程），只是因为命名习惯收在格局目录里。实战主入口见 [[../断事方法/宫星四化合力|宫星四化合力]]；本页保留为君臣佐使框架的展开说明。**它不替代「正向应卦」等方法，是给读盘排个先后。**

## 四级架构（按源文落到紫微斗数上）

源文给出一套「举例性」的对应（作者自己也说「不够全面，只是举个例子」）：

| 级 | 中医职能 | 落到盘上（源文示例） |
|---|---|---|
| **君** | 主病机、定方向、药力最强 | **主事宫位及其星意**；具体占断中，[[../宫位/README|来因宫]] 等三层卦象是起点。定义个体的核心结构与气运。 |
| **臣** | 辅助君、加强主治 | **化权、[[../星曜/辅星/左辅|左辅]]、[[../星曜/辅星/右弼|右弼]]**。化权=权力/维持/保护；左辅=资源的「多 / 重复性支持」；右弼=「转向 / 改变」，是系统应对变化的执行力。 |
| **佐** | 制衡、制约、调节 | **化科、[[../星曜/煞星/地劫|地劫]]、[[../星曜/煞星/地空|地空]]、煞星**。化科=拖延/缓慢/对凶象的补救化解；地劫=窟窿/缺失；地空=超出/过分（使星体膨胀或虚化）。在细节层面维护平衡或警示风险。 |
| **使** | 传导、调和、引经报使 | **化禄、化忌**。化禄=「放大 / 开始」的触发点，用于追溯因果与启动点（[[../紫占方法/追禄|追禄]]）；化忌=「终止当前状态 / 结束点」，也用于追隐性因果（追忌）。连接内部结构与外部（大运流年）的变动。 |

读法落地（源文给的思维范式）：

1. **定核心矛盾（君）：** 先准确锁定当前最主要的问题/目标 = 主事宫 + 其星意。
2. **配资源支持（臣）：** 看化权 / 左辅 / 右弼怎么巩固这个核心。
3. **设风险制衡（佐）：** 看化科 / 空劫 / 煞星在哪里制约主导力量、防止「矫枉过正」。
4. **铺执行传导（使）：** 看化禄 / 化忌怎么把这股力引到目标、连接大运流年。

## 与「正向应卦」「星意还原」的关系（不是吉凶）

君臣佐使**不下吉凶判语**，它只排「先看谁」：

- 它先帮你定**君**（主事宫），再用 [[../断事方法/星意还原|星意还原]] 把君的星退回原始星意、投到所问的事上；
- 是吉是凶，仍由 [[../断事方法/正向应卦|正向应卦]] 决定（事的性质对不对号星的原始星意）——君臣佐使不越权回答这个；
- 它的价值在「**别头痛医头**」：源文反复强调先洞察整盘的权力结构（君臣佐使齐看），再谈干预/改命，否则就是西医式的「脚痛医脚」。

所以把它当「格局」去问「我有没有君臣佐使、好不好」是用错了——每张盘都天然有君臣佐使（必有主事宫、必有四化与辅煞），它是**读盘的排序工具**，不是「拥有即吉」的某种配置。

## 落宫 / 应用要点

- **先立君**：占一件具体事就以主事宫/来因宫三层卦为君；读一个人就以命宫结构为君。君错了，后面全偏。
- **臣佐使是「角色」不是固定星**：源文的星—角色对应是举例（化权当臣、空劫当佐、禄忌当使），实战中同一颗星在不同问题里可能换角色——以「它在这件事里起的是辅助/制衡/传导哪种作用」来归位。
- **配合四化分层**：四化本就分先天/大运/流年/宫位多层，启动时间与顺序不同，正好和「使（禄忌传导）」「臣（权辅助）」的分层呼应，连着 [[../四化/README|四化]] 一起用。
- **它是方法，不是知识**：和五个 [[../断事方法/README|断事方法]] 动作同层，记到「读盘流程」里，而不是当成某个会显吉显凶的星组合。
