# 紫微斗数知识库（原始紫微 / 原始星意 路线）

这个知识库不是紫微斗数的"全集"或"中立百科"。它是一个**立场鲜明**的 wiki，底层 ideology 是**原始紫微**学派——拒绝传统的"吉凶格局"标签，把每颗星先退回到它最底层的含义（原始星意），再根据问题和语境重新组装结论。

本 KB 的主线由**两股同源语料**共同支撑：

1. **翻星摇斗 / 闲枢**（`sources/fanxingyaodou/`）— 偏重**人事/关系**的解读路线；143 篇公众号文章，含完整断事方法、星曜、宫位、四化、案例。（另有 `sources/翻星摇斗_文集.md`：作者精编合集，126 章 8 类，是这条线的人工精校子集，排版更干净、便于通读引用，但篇目是子集。）
2. **紫占方法论 / 紫微新语**（`sources/紫占方法论.md`）— 偏重**紫占 / 物象/时间**的解读路线；20 期连载，含起卦机制、三层卦、同音卦、物象化、十二相、正向应卦、追禄等紫占专属方法。

两股语料学派相同（都用原始星意，都拒绝吉凶标签），但**应用场景互补**：翻星摇斗主要服务"为人"（终身命盘），紫占方法论主要服务"为事"（短期占卜）。下游两个 skill 也对应这两条线：

- `skills/ziwei-natal/` — 个人命盘推演，主要用翻星摇斗语料 + 星曜/宫位/四化/断事方法
- `skills/ziwei-zhanbu/` — 紫占，主要用紫占方法论语料 + 紫占方法/物象化 + 三层卦

## 为什么要立场鲜明

命理体系之间有深层冲突。如果把紫微斗数全书、中州派、飞星紫微斗数和**原始紫微**的解释混写在同一个「贪狼」页面里，读者会得到一个四不像，下游任何基于这个 KB 的推理系统也会在解盘时内部打架。

所以这个 KB 的设计原则是：

1. **一条主线保持纯净。** 所有 `kb/` 下的概念页，`ideology: 原始紫微`（或更早写的 `翻星摇斗`——两者等价，后者是前者的具体支流；后续新页统一用 `原始紫微`，旧页暂不回改）。
2. **其他学派集中、隔离、可对照。** 全书、中州派、飞星的内容放在 `kb/_reference/` 下，清楚标注来源，用于辨析差异，不参与主线推理。
3. **案例是证据，不是论证。** 抓取的公众号文章在 `sources/fanxingyaodou/articles/` 下，整本 `紫占方法论.md` 在 `sources/`；概念页向下 wikilink 引用它们作证，概念页本身不复述原文。

如果之后引入其他学派的主线知识库，做法是**再开一个同级目录**（比如 `kb-quanshu/`），不是把内容混进来。

## 原始紫微 ideology 的几个差异点

以下是本 KB 与主流紫微资料最明显的分叉。写概念页时请对齐这些差异。

### 1. 原始星意 > 格局标签

传统紫微会先告诉你「贪狼是桃花星」「武曲是财星」「擎羊是煞」。原始紫微先不承认这些标签，而是把每颗星退回到更底层的**原始含义**再重建：

- **贪狼**的原始星意是**体积 / 大小的变化**，欲望只是它在人类经验上的一个延伸；在紫占里贪狼就是实际物体的"量"（肉、面积、长度、容积）。
- **文昌**的原始星意含**偏斜**，所以贪狼文昌 = 大肉塔偏了 = 粉身碎骨，不靠吉凶口诀。
- **煞星**不默认是"不好"的；翻星摇斗的`为煞星正明`专辑 + 紫占方法论的**正向应卦**原则共同揭示：同一颗煞星，落在"对口"的事上反而是吉（擎羊于雕刻师、铃星于按摩师、地劫于切肿瘤）。

**写作要求：** 每个星曜页必须先写「原始星意」，再写它如何延伸出传统说法 / 物象 / 同音。不要把传统说法当作默认结论。

### 2. 宫位立太极 > 单宫断

同一颗星在同一张盘里，因为所立的太极点不同，解释对象会换。父母宫看自己时是父母运，但在夫妻宫的三方四正里立太极看时，解释对象变成配偶的家庭。

在紫占里这一原则延伸出**天卦 vs 人卦**——太极立在来因宫（环境/天意）还是命宫（本人回应），读出来的故事不一样。

**写作要求：** 宫位页不只讲"这个宫管什么"，要讲"以此宫为太极时能看到什么"和"它如何被其他宫投影"。紫占相关 宫位 还要标注 天/人卦差异。

### 3. 命盘惯性 > 宿命预言

原始紫微不把命盘当作固定未来，而把它看成过去因缘、习惯、天赋和卡点形成的**惯性结构**。预测之所以成立，是因为人在没有新增外力时会重复旧模式；如果改变分力，合力方向也会变。

**写作要求：** 命盘推演不要写成「你一定会怎样」，而要写成「若沿当前惯性继续，合力指向哪里；若调整哪些分力，现实路径如何改变」。详见 [[断事方法/命盘惯性]]。

### 4. 宫星四化合力 > 标签拼接

宫位、星曜、四化和小星不是四份独立解释，而是同一系统的分力。读盘要先定主事宫，再分辨核心矛盾、支持力量、制衡力量和传导链，最后求合力方向。详见 [[断事方法/宫星四化合力]] 和 [[格局/君臣佐使]]。

**写作要求：** 不要把「宫位解释 + 星曜解释 + 四化解释」直接拼成结论。每个结论都应交代主事宫、主星意象、四化传导、宫位关系和现实校验。

### 5. 关系反推 + 现实校验 > 玄学收口

不管解命盘还是起卦，最终都要落到**可验证的生活事件**（考试结果、身体反应、搬家后变化、应期内是否发生）。看不见摸不着的结论站不住。

**写作要求：** 案例引用里要记录"收口方式"——最终是靠什么现实证据回证判断。

### 6. 正向应卦 — 同样的星组合，事对号入座就是吉，不对号就是凶

这是**紫占方法论**贡献的一条关键原则（翻星摇斗语料里隐含但未明说）：事业宫"太阴陷 + 地劫"传统读法是"事业不能存+财窟窿"，但如果这个人是**卖空集装箱**的——东西确实没存东西、确实是空心的——这个凶组合就是他事业的**正向应法**，反而生意兴隆。反之同样命盘另一个人做不匹配的行业，就一辈子做不长。

**写作要求：** 同一星组合在不同事业/问题/语境下可能吉可能凶，取决于"事的性质和星的原始星意是否对号"。任何"凶"结论都应附加"在 X 类事上 才凶"的语境。

## 断事方法骨架

原始紫微的推理先有三条上位公理，再有五个可以被显式写出来的方法动作。这是本 KB **最重要**的内容，也是下游 skill 的核心逻辑。

三条上位公理：

1. [[断事方法/命盘惯性]] — 命盘呈现惯性和潜力，不是固定未来。
2. [[断事方法/宫位关系]] — 十二宫通过对宫、一六共宗、三方四正和四化链互相投影。
3. [[断事方法/宫星四化合力]] — 宫、星、四化、小星要合成方向判断。

五个基础动作：

1. [[断事方法/星意还原]] — 把星退回原始含义，再按事情的维度投影出具体表达。
2. [[断事方法/宫位立太极]] — 根据问题对象切换太极点，让同一颗星换解释对象。
3. [[断事方法/关系反推]] — 从现实关系症状倒推盘面结构。
4. [[断事方法/现实校验]] — 任何判断最后都要落到可验证的现实证据上。
5. [[断事方法/正向应卦]] — 同样的星组合随事的性质切换吉凶，"对口 = 吉，不对 = 凶"。

这五个动作是**方法论，不是知识**。星曜页是字典，断事方法页是语法。

## 本 KB 不做什么

- 不做中立综述。想要中立综述的去看维基百科或紫微斗数全书。
- 不做排盘工具。排盘请用现成软件（紫微星语 / 文墨天机等），本 KB 只做解释层。
- 不做无根据的吉凶占卜结论。所有"好坏"判断都必须交代它依赖的具体星意、宫位结构，以及是否满足正向应卦条件。
