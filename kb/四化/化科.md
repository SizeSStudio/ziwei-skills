# 化科

> **底层能量流向：把看不见的东西慢慢翻出来、缓和、延续、蓄满——像一个小旋风。**
> 不是"利考试""有名声"。是春天——冬藏之后的东西开始往外长，速度慢，但无孔不入。

## 底层含义

化科属木，对应春、生、圆：

| 四化 | 季节 | 五行 | 状态 | 显密圆通 |
|------|------|------|------|---------|
| **化科** | **春** | **木** | **生** | **圆** |
| 化权 | 夏 | 火 | 长 | 显 |
| 化禄 | 秋 | 金 | 收 | 通 |
| 化忌 | 冬 | 水 | 藏 | 密 |

化科是**从不可见到可见的过程**（圆）——冬藏之后，该长的东西一点点抽出来。能量体感不像化禄那样"放大当前状态"、也不像化权那样"施加一个力"那么直给，它是一种**润物细无声**的缓慢翻转。

作者给的图像化总结是关键：

> 化科的作用是：缓慢、延续、回退、化解、蓄满。
> 这个性质在图像上就像一个小旋风一样——刺头扔进去，会缓和的出来。

这个"小旋风"意象决定了化科不能被解读成"加速"或"施压"：它是让进入这个太极的东西被**同化、融合**掉棱角。太极端的人进来会被融成均值，太平庸的人进来也会多出点新东西。化科的速度很慢，但它无孔不入——只要它覆盖到，那个宫位上的所有星耀都会被它影响一轮。

**化科在水木位力量最大，在金火位力量很小。**这是它在五行里的分布。

这也解释了为什么传统说"化科利考试"：考试是"把学过的东西从密藏翻到可见"的典型动作——正是化科的定义。传统结论没错，但原因不是"考试神"，是化科的能量阶段天然对这个动作有利。

## 紫占视角的底层含义

[[../../sources/紫占方法论|紫占方法论]] 给化科的定义是**所有四化里最复杂的那一个**——因为科不是一个动作，而是一族相关动作的集合：

> "科本身的性质太复杂了，有拖延、有缓慢、有延续、有回退、有补救的性质。"（源：紫占方法论 行 2117）

这五个动作——拖延 / 缓慢 / 延续 / 回退 / 补救——都是**让当前状态不直接结束**的做法。科不像禄（放大）或忌（终止）那样给一个单向动作，它是把时间拖长、把能量回吐、把漏洞补上这一类**延时 / 回流**的操作。本页上半段的"小旋风""润物细无声"意象都是这个集合的不同侧面。

**五行强度（源：紫占方法论 行 2115）**：化科属木，强度分布——

| 位置 | 科的力度 |
|------|---------|
| 水位 / 木位 | 极大（作者用词"都极其大"） |
| 金位 / 火位 | 极弱（"力量太弱了"） |

作者在源文里明确保留了化禄的完整表（金位 90-100% 等），但对化科没有给精确百分比——只给了"水木极大 / 金火极弱"的定性界限。所以判断化科力量靠定性就够，没必要硬套不存在的精确比例。

> ⚠ **化科"登科"是同音卦，不是本意**
>
> 作者在源文里对"化科利考试、主功名、有名声"这一套传统读法做了明确的翻案：
>
> > "你说有没有出名的性质，我不认为有，命中有科但不出名的人太多太多了……这个以古代有登科这么一个概念时应该会有吧，但也是用的科的同音卦意不是本意。而且这么多年大量的紫占中也没有占到谁有科就有名的。"（源：紫占方法论 行 2119–2121）
>
> 换言之，"登科 / 科名 / 出名"是**「科」这个字在古代科举场景里的同音用法**被反复叠加后留下来的印象，不是化科本身的动作含义。化科本身的动作是**拖延 / 缓慢 / 延续 / 回退 / 补救**——这五个才是本意。紫占实战里一见化科就往"出名 / 考得好"上读是把同音当本意，会错。本页上半段的"传统说'化科利考试'……原因不是'考试神'，是化科的能量阶段天然对这个动作有利"也是同一件事：考试能不能考好跟化科没有直接因果，化科只是在"把学过的东西从密藏翻到可见"这个动作上天然契合。

紫占里化科经常和 [[../紫占方法/追禄|追禄]]、[[../紫占方法/物象化|物象化]] 一起用——追科时追的是"是谁在帮着缓和 / 延续 / 补救这件事"，物象化时化科给物象加上"慢、匀、润、兜底"这一层修饰（一块要碎的玻璃被化科拖住、一段要断的关系被化科延续）。

## 作用对象

**化到哪颗星**：那颗星的能量被缓和、被翻出来、被蓄满。紫微化科 = 主星被翻出来并被柔化；武曲化科 = 金钱能量被缓慢化解（对照武曲化忌是"金钱被卷走"）；文昌化科 = 文气/语言从隐转显。

**化入哪个宫**：那个宫的事项进入"润"的状态——进展慢，但全方位起作用；有毛刺的会被磨平，有亏空的会被蓄满。

**地支宫位决定力量大小**：**水木位力量最大，金火位力量很小**。所以同一颗星化科在子/丑/寅/卯这一带 vs 落在巳/午/酉/戌这一带，效果差异大；火位化科基本可以忽略。

## 组合模式

**化科作为化解器**（作者在武曲七杀卯酉案例中的核心操作）：

- 武曲七杀在酉宫 = 兑卦 = 金金相战 → 两金打到缺。酉宫是金宫，**化禄和化忌力量最大**，武曲**化忌**效果最好——直接干掉一个金，立竿见影。
- 武曲七杀在卯宫 = 震卦 = 金木相战 → "木压雷惊"，被雷劈、被电线杆砸。卯宫是木宫，**化权和化科力量最大**，化禄化忌力量很小。此处若用化权则是"给打架的宫再加把力"——风险极大，本来应验是电线杆砸到你，化权后变成开车时电线杆砸到你车上，**只是延时并等量升级**。所以卯宫**应该用化科化解**，柔和缓慢地把力量融掉，避免正面对撞。

这是化科作为"迂回解法"的典范——**不对抗、让系统自己柔化出路**。

**追科**：逻辑与追禄、追权同构——A 宫 → B 宫化科，A 在给 B 送柔化/蓄满。作者原盘例：**交友宫（乙天干）引官禄宫紫微化科** → "众生利我，交友让我的紫微变得更好更有贵气，也让我更有行动力"；交友宫坐火星/地空/天才 → 顶级聪明的人会来反向补足自己。

**万能公式**（作者原文）：

> 看乙天干在哪个宫位——乙天干是会使得紫微化科。在紫微斗数中，紫微化科绝大多数都是好的，紫微化权绝大多数都是不好的。

这是读一张盘时的捷径：先定位乙天干那个宫，紫微化科落点就是这个人的"贵人/柔化来源"所在。

**自化科 / 冲化 / 飞化**：留待补充。

## 改命用法

化科的改命思路——**用在需要"不对抗地融掉硬冲突"的地方**。

1. **在两强相战的宫位用化科做迂回**（最经典场景）：如卯宫武曲七杀"木压雷惊"，正面用化权等于加码对撞，应该用化科慢慢柔掉。对所有"打架型"星系（金金相战、火水相冲）都适用——前提是**地支在水木位**，化科才有足够力量。
2. **用来让暗星蓄满/焕发**：原盘星情太弱、太端、太突兀的，让它化科可以润物细无声地补上（作者原话"原本一成不变的事物在化科后，也会吐出一些东西出来"）。这是对照化忌"让暗星被点亮"的另一条柔路。
3. **追科找贵人**：反推"让自己的某颗主星化科的那个宫"，那个宫对应的人/事就是自己的柔化/蓄满来源。作者的"众生利我"即是。要主动扩大这类接触面。
4. **紫微化科定位法**：看乙天干所在宫 → 锁定紫微化科落点 → 这个落点所在宫的属性就是你生命里自带的贵人方向。
5. **注意误用**：化科在金、火位力量很小，基本可以忽略；在这些地支上靠化科改命是无效操作。得改走化禄/化权/化忌里更对症的那一条。

## 跟 星曜 / 宫位 的互动

- [[../星曜/主星/紫微|紫微]] 化科是整个化科里最值得拎出来的典型——"万能公式"的主角。
- [[../星曜/主星/武曲|武曲]] 化科 = 金被柔化 / 钱被蓄满。与武曲化忌（被卷走）、武曲化权（堵住）、武曲化禄（落袋）形成完整四化对照。贪狼没有化科（不在天干四化表里出现），所以讨论 [[../星曜/主星/贪狼|贪狼]] 时不用化科。
- 落 [[../宫位/官禄宫|官禄宫]]：工作进展缓慢但扎实、口碑蓄满型。
- 落 [[../宫位/仆役宫|交友宫]] / [[../宫位/父母宫|父母宫]]：容易出"众生利我"的格局——外部柔化力量反向补足自己。
- 地支落水木位时，跟 [[../断事方法/星意还原|星意还原]] 搭配读最准——被柔化的是那颗星的哪一层含义，要先把底层含义拆出来。
- 在 [[../断事方法/宫位立太极|宫位立太极]] 下，化科落点的"缓和"是对谁而言的，要跟随太极点换人，不能默认都是"我被柔化"。
