# 宫位

十二宫 + 身宫 + 来因宫。翻星摇斗的宫位用法有两个特点：

1. **太极切换** — 同一个宫位立不同太极点，解释对象完全换。父母宫以命为太极看时是父母；以夫妻为太极看时是配偶的原生家庭。
2. **宫位关系** — 十二宫通过对宫、一六共宗、三方四正和四化链互相投影，不是十二个孤立格子。详见 [[../断事方法/宫位关系|宫位关系]]。
3. **结构反推** — 很多解盘不是顺着宫位直读，而是从现实关系症状反推宫位结构出了什么问题。详见 [[../断事方法/关系反推|关系反推]]。

## 概念页写作规范

每个宫位页必须有：

1. **本宫的核心对象** — 以命为太极时解释什么。
2. **太极切换规则** — 以其他宫为太极时，本宫变成解释什么。这是最容易被传统资料忽略的部分，必须写清楚。
3. **结构位置** — 本宫在命身线、夫财福/父疾迁/兄仆子田 等结构中的角色。
4. **高频症状 → 本宫问题的反推路径** — 哪些现实症状常被翻星摇斗反推到本宫的哪类星。
5. **支撑文章** — wikilink 到 `sources/fanxingyaodou/articles/`。
