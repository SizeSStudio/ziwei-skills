# 迁移宫

> **核心对象：在外的显化 / 别人眼里的自己 / 命宫的对宫镜像。**
> 翻星摇斗一句口诀：自己怎么想的没用，迁移宫决定别人怎么看你。命宫是"我以为的我"，迁移宫是"落到别人眼里的我"。

## 本宫的核心对象

以命为太极时，迁移宫是**命宫的对宫**，承担两个紧密相扣的含义：

**第一层：别人对你的第一印象。** 翻星摇斗原文："迁移宫，即命宫的对宫，代表在外的表现，外人对你的第一印象，也是一个宫位的结果位置。" 命宫讲"灵魂上的你、一生总结的自己"，是你跟自己对话时的那个自己；迁移宫讲"你一走出门，环境里浮出来的那个你"。两者错位是常态，而迁移宫的体感是更外显、更被环境验证的那个版本。典型例子：天府坐命 + 迁移七杀 → "天府自己是仓库型稳重，但外人见到先收到的是七杀的江湖气、不好接近"（天府文原文）。

**第二层：在外的一切——变动、出外、远方的资源。** 出门、搬家、出差、移民、以及所有"离开家这个储存位以后发生的事"，都进迁移宫。迁移宫的星若是动星（[[../星曜/主星/破军|破军]]、[[../星曜/主星/天机|天机]]、天马），则一生多变动、多次向外突破；若是稳星（[[../星曜/主星/天府|天府]]、[[../星曜/主星/天相|天相]]），则在外不容易大折腾。"我的迁移宫是破军左辅" = "我一生要反复多次地突破困难难题和轮回"（辅星案例的原文）。

**第三层（翻星摇斗特别强调的命宫镜像）**：因为是命宫的对宫，迁移宫同时承担"命宫的外化结果位"。宿命黑洞案例里提到了一种极端用法——**来因宫落在迁移宫**的命格，意味着"这辈子的核心课题、资源、甚至命运的转折点都在外面"，必须走出去，留在原地能量点不亮。这类命格"外面其实是一个很漂亮、很柔和的天同……只要走出去，是能够得到别人的认同和善待的"。这不是"建议出门走走"，而是"命的基本盘就要求在迁移位完成"。

反过来也有一条重要心理学口径（同案例）："你对别人的态度，其实就是你对自己的态度。" 迁移宫化忌带来的"外面都是鬼"体感，往往是命宫自产自销的投射。改迁移宫不是改外人，是改自己。

## 太极切换规则

以其他宫为太极时，迁移宫讲的对象会换。配合 [[../断事方法/宫位立太极|宫位立太极]]：

- **以夫妻为太极**：原盘的迁移宫变成"配偶的命宫"——即配偶自己。所以当问"配偶自己是什么样的人（不是在我这段关系里）"，是切到这里读，不是读原盘的夫妻宫。
- **以兄弟为太极**：原盘的迁移宫变成"兄弟的官禄宫"——兄弟姐妹/合伙人的行动能力。
- **以财帛为太极**：原盘的迁移宫变成"钱的田宅宫"——钱的储存位，即"钱会流到外面哪里储存"的象。
- **以官禄为太极**：原盘的迁移宫变成"事业的兄弟宫（现金位）"——事业真正能拿到手里的那部分。
- **以田宅为太极**：原盘的迁移宫变成"家族的福德宫"——家族整体的脑子/福分。

**特别提醒**：命—迁对宫关系最容易被"借星"写法用到——"疾厄宫单看不够，要把对宫父母的星借过来看"（马斯克疾厄宫分析）。命宫和迁移宫同样经常互相借星，读命宫时要把迁移的星纳进来，读迁移时要把命的星纳进来。

## 结构位置

- **命—迁对宫**：全十二宫里最经典的一对对宫。命是里，迁是表；命是"我以为"，迁是"被看见"。**这是迁移宫最核心的结构位。**
- **父—疾—迁（父疾线 / 六内线）**：迁移宫在父疾迁组里。父母宫管规则/眼界、疾厄宫管身体/本质、迁移宫管在外显化——三者联动常出现在考运分析（父疾线代表考运，考试时迁移宫代表"去考试现场的自己"）里。
- **兄—仆—迁（部分文章口径）**：原文"以兄为里，迁移宫为表"——你的同好气质，会在你外显的迁移宫上被看见。"物以类聚，人以群分"的盘面对应。这也是兄弟宫的四化常常和迁移宫有联动的原因。
- **迁移宫是"结果位"**：翻星摇斗把迁移宫定为"一个宫位的结果位置"。所以你想看某件事最终会不会被外界接住，迁移宫是一个关键的落点。

## 高频症状 → 本宫反推路径

应用 [[../断事方法/关系反推|关系反推]]：

- **"我自己觉得还行，别人总说我冷/凶/难相处"** → 典型的命-迁错位。命宫柔、迁移宫有七杀/破军/擎羊一类硬星。不是你变，是迁移位本身就这形状。常见于天府坐命+七杀迁移（天府文原话）。
- **"在家废，出门就活了"** → 命-迁能量分布严重偏向迁移侧。可能是来因宫落在迁移（宿命黑洞案例）、或命宫星陷、迁移宫星庙旺。翻星摇斗的建议不是硬留家里，是顺着去外面完成课题。
- **"搬一次家人生就翻一次"** → 迁移宫有大变动星（破军+左辅、文曲陀罗"突破轮回"组合），每一次物理位移都在触发命的四化，重排整张盘。
- **"外面都是鬼 / 出门就被欺负"** → 迁移宫化忌、交友宫化忌。翻星摇斗原话："你对别人的态度就是对自己的态度……带着鬼脸看世界，世界全是鬼。" 不改迁移宫的星，要改命宫→迁移这条自产自销的投射。
- **"第一印象差，聊开了就没事"** → 命-迁反差大但兼容。迁移宫的硬/冷星构成第一印象，命宫的柔/暖星构成深交印象。这类不是毛病，是盘面本色。
- **"一出门就出事（血光、事故）"** → 迁移宫有凶煞星+相关四化。注意翻星摇斗不主张把这直接读成"不要出门"，而是读出"在外面容易触发什么结构"，然后判是哪个维度（血、骨、撞、病）。

## 常见星曜落本宫

- **[[../星曜/主星/七杀|七杀]]** — 第一印象直接、有些凶、不好接近；但多是"野心的外显"，不一定意味坏。天府坐命+迁移七杀是标准对照组。
- **[[../星曜/主星/天府|天府]]** — 在外稳、仓储型；"外面是房子、外面是仓库、外面才是能收留七杀的地方"——七杀朝斗格的迁移结构。
- **[[../星曜/主星/天相|天相]]** — 在外随和、好打交道、好面子；"内硬外柔"。
- **[[../星曜/主星/破军|破军]]** — 多次向外突破；配左辅右弼是多次翻盘；加文曲陀罗则"突破轮回内容"。
- **[[../星曜/主星/天同|天同]]** — "外面是漂亮柔和的天同" → 走出去能得到认同与善待（宿命黑洞案例原话）。
- **[[../星曜/主星/廉贞|廉贞]]** — 抓取型的在外显化；在申位"抓取力量很少"抓不住美好，一化忌反倒"抓住美好"（考试卦案例）。
- **[[../星曜/辅星/左辅|左辅]] / [[../星曜/辅星/右弼|右弼]]** — 多次、反复；"每次发生矛盾第一反应是想换人"（迁移宫右弼的典型应相，见开瓢女友案例）。
- **陀罗 + 文曲** — 复杂且反复，突破轮回的意向组合。
