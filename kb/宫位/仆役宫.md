# 仆役宫（交友宫）

> **核心对象：朋友 / 下属 / 你接触到的所有人 / 众生对你的反馈。**
> 翻星摇斗 最强的 reframing 之一——**"众生觉得你好，你才是真的好。"** 命宫的贵气是由交友宫（仆役宫）反过来决定的。

## 本宫的核心对象

以命为太极时，交友宫同时讲几件事：

- **你的交友层级——你所接触到的所有人的总称。** 语料直接讲："交友宫广义上是代表所有的人，所有的众生"（[[../../sources/fanxingyaodou/articles/mid-2247483800|改命系列一]]、[[../../sources/fanxingyaodou/articles/mid-2247483895|六亲定位-实战案例]]）。
- **下属、追随者、被你影响到的那一群。** 与子女宫"等级比你低的具体下属"相比，交友宫更接近"你的观众 / 公众 / 受众"这种泛人群。
- **你的"现金结果位"。** "我们要赚钱嘛，钱从哪来？当然是从别人那弄过来，所以交友宫是你潜在的金钱，你现金的结果位"（[[../../sources/fanxingyaodou/articles/mid-2247483800|改命系列一]]）。朋友越多、受众越广、喜欢你的人越多，可能变现的路径越多。
- **你对外散发的人际磁场。** 一个人"总招来什么样的人"，结构上落在交友宫。[[../../sources/fanxingyaodou/articles/mid-2247484848|宿命的黑洞]] 里讲得很狠：你招来什么样的众生，是你自己的磁场决定的。

## 一六共宗：命宫的根在交友宫

这是 **仆役宫在翻星摇斗里被当作"灵魂宫"看待的根本原因**，也是本 KB 最想保全的一条原理。

> "而且很有意思的是，交友宫跟命宫也是一六共宗的关系，**交友宫为里，命宫为表**，所以要看一个人命好不好，就要看你的交友宫怎样！你所结交的众生都很好，而且都很喜欢你，那你肯定就越好，你个人的能量越高，福报也就越多。"（[[../../sources/fanxingyaodou/articles/mid-2247483800|改命系列一]]）

序论文章把它再推了一层：

> "按照一六共宗原则，**交友宫是命宫的根**！也就是说，我们是怎样的，跟我们的众生缘分是相关的！"（[[../../sources/fanxingyaodou/articles/mid-2247483887|宫位体系序论]]）

这是一句重话。它直接推翻了传统"命宫至上"的读盘逻辑——命宫好不好**不是由命宫自己决定的**，它是交友宫的"表"；真正的里是交友宫。换句话说，**众生对你的反馈才是你是什么的基础**；一个独自宣称自己很强但众生都对他发出"忌"的人，命其实不好。

再进一步的改命链条（[[../../sources/fanxingyaodou/articles/mid-2247484018|认知形成的科学解读]]）：

> **交友宫是命宫的根 → 夫妻宫是交友宫的根 → 田宅宫是夫妻宫的根**

所以对翻星摇斗而言，"改命"的操作链是：**改田宅宫（发心）→ 改夫妻宫（行动结果）→ 改交友宫（众生反馈）→ 命宫自然变**。改命不是改命宫，是改命宫的根。

## 太极切换规则

交友宫的立太极在实战中有几条非常好用。详见 [[../断事方法/宫位立太极|宫位立太极]]。

- **以交友宫为太极看朋友/下属/粉丝这个群体本身。** 原盘交友宫变成"众生的命宫"。原盘命宫变成"众生的夫妻宫"——也就是众生眼中"值得与之建立关系的你"。这也是为什么"众生喜欢你，你就好"：它在结构上直接映射。
- **以兄弟为太极看交友宫。** 原盘的交友宫在"兄弟的命宫"视角下，落在某个新位置上。问"我合伙人的人脉质量"比直接看自己交友宫更精确。
- **以子女为太极看交友宫。** 原盘交友宫变成子女的某个六亲位。问"我孩子以后交的朋友"可以从这里读。

## 结构位置

交友宫位于 **兄仆子田** 结构中，对宫是 **兄弟宫**。两宫互为结果位（详见 [[兄弟宫]]）：

> 交友 →（变熟变好）→ 兄弟 ｜ 兄弟 →（盛极而散）→ 交友

一个人的"泛交人群"和"深度陪伴者"之间是动态循环的。

交友宫还有一条重要的对照：**与命宫一六共宗**（宫位序数 1 命 ↔ 8 移不是一六共宗，真正与命宫一六共宗的是 7 位——这是交友/仆役宫）。

（翻星摇斗文本里"改命→田宅→夫妻→交友→命宫"的改命主链，[[../../sources/fanxingyaodou/articles/mid-2247483818|夫妻宫之高维投影]] 里被总结为：**田宅是天魂/发心，夫妻是缘/行动结果，交友是所做成的事 + 所能接触到的众生**。这条链是翻星摇斗 ideology 的标志性结构。）

## 高频症状 → 本宫反推路径

套用 [[../断事方法/关系反推|关系反推]]。

- **"我做事人挺多但没人真喜欢 / 没人变现。"** 交友宫的量够但质不对。看交友宫的主星和四化倾向——是化忌型的"众生认识但不喜"，还是化禄型但没有兄弟宫的接盘。
- **"众生对我总是敌意 / 先被伤害后退缩。"** [[../../sources/fanxingyaodou/articles/mid-2247484848|宿命的黑洞]] 里的"交友宫文昌化忌 + 自产自销"——根源不是众生真的对你不好，是你先戴着鬼脸看世界，然后世界全是鬼。破局在兄弟宫的化科"解忌"，而不是在交友宫硬改。
- **"粉丝多、关注高，但钱进不来。"** 交友宫活但通不到兄弟宫（现金位）。或者，兄弟宫自身的结构没法接住这个流量。
- **"朋友圈子换了一轮，问题还在。"** 典型的**换外不换内**。交友宫的问题往往是田宅宫或夫妻宫源头的投影，改交友圈没用，要改源头。
- **"总当被薅的那个 / 付出多回报少。"** 交友宫里有"耗泄"星组，或者命主磁场让别人理所当然地索取。同时看兄弟宫是不是"供养模式"在运转。
- **"做修行 / 带学生 / 做公众表达，身边人的反馈怪怪的。"** [[../../sources/fanxingyaodou/articles/mid-2247484817|那个从未活过的孩子]] 里的"撞大运清理法"：交友宫四化力度大（武曲化禄 + 贪狼化权），通过身边人的痛苦反馈在"强行清空"主人公内心的陈旧教条。这是交友宫作为"众生帮你清理内在"的功能性读法——众生不是奖励/惩罚，是镜子和清洁工。

## 众生是镜子：翻星摇斗的交友宫 ideology

翻星摇斗对交友宫反复强调两个态度（综合 [[../../sources/fanxingyaodou/articles/mid-2247484077|什么是缘分什么是正缘]]、[[../../sources/fanxingyaodou/articles/mid-2247483887|宫位体系序论]]）：

1. **众生是你的镜子。** "你对别人的态度，其实就是你对自己的态度。"交友宫化忌往往是"自产自销的"——不是众生伤害你，是你先预设众生会伤害你。改交友宫最有效的方法是改你对自己的态度。
2. **没有正缘/逆缘之分。** 所有缘分来都是成全你的。正缘让你感觉圆满，逆缘让你感觉匮乏，归根都是你的体验。第一责任人永远是自己。

这两条在写盘时要保全——它们让"交友宫不好"这种判断不再是结论，而变成一个指向内在调整的入口。
