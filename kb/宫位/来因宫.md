# 来因宫

> **核心对象：这张盘里命运的"发起点"——四化从哪个宫先飞出去、故事从哪里开始讲。**
> 翻星摇斗把来因宫当作"占断的起点"，不是装饰位。

## 本宫的核心对象

以命为太极时，来因宫是**整张盘的第一推动者**——翻星摇斗的用法里，它是追忌 / 追禄的起点，是命盘这个卦象"第一层卦"的发源宫。

在 [[../../sources/fanxingyaodou/articles/04-四化与宫位体系/2025-11-28-紫微重构7-君臣佐使格局.md|君臣佐使｜紫微斗数重构7]] 里，作者明确把来因宫放进君臣佐使的"**君**"这一层：

> "定义个体的核心结构与气运。在具体占断中，来因宫等三层卦象是起点。"

在 [[../../sources/fanxingyaodou/articles/05-紫占与深度解盘/2026-03-19-神明代言人与癔症少女的第五个问题.md|又一个神明代言人？]] 里，作者更直接地讲：

> "我们就可以直接的通过这个从来因宫开始后的无限追忌法，就能直接的看懂这个命盘是怎么回事了！"

所以来因宫的"核心对象"不是某一类六亲、不是某一类事项，而是**这张盘的故事从哪一条线被拉起来**。它给出的是一个**指向**：这一盘真正"活"的那条因果链，要从这一宫开始顺四化读下去。[[../../sources/fanxingyaodou/articles/05-紫占与深度解盘/2025-03-27-紫占实战-公职人员考试卦.md|如何看考试？紫占卦分析]] 是教学级的实操——来因宫落在父母疾厄线上，作者就从这条线的四化开始层层推，一路推出"第一层→第二层→第三层卦象"，这就是翻星摇斗所说的**来因三层卦**。

来因宫本身不带固定星意，它是**一个指针**；被指到的那个宫的星情 + 四化飞出路径，才是真正要读的内容。

## 紫占中作为默认太极

命盘推演默认立太极在命宫，但**紫占完全不一样——紫占的太极默认立在来因宫**。这是紫占体系最关键的结构分歧之一，也是来因宫在紫占里的核心身份。

> "对于我的体系来说，分成两大类天卦和人卦，天卦就是来因宫为太极点的三层卦象体系，人卦是命为太极点的三层卦象体系。"（源：[[../../sources/紫占方法论|紫占方法论]] 行 917）

换句话说，**来因宫 = 天卦的太极点 = 天意进入这个卦的入口**。起卦时事主那一分钟被"快照"下来的 12 宫天地运行，都是以来因宫作为起点、以三层卦（主卦 / 流十分钟卦 / 流分钟卦，参 [[../紫占方法/天卦与人卦|天卦与人卦]]）层层展开的。来因宫在此刻不再是"一生因果的源头"，而是**"此时此刻天意落到哪里"的指针**。

紫占里问题类型会决定要不要再加一层人卦：

- **问环境型问题（房子升值、考试录取、经济大势、天气变化）**：只看天卦——命宫对这类"外部大环境"问题无关。
- **问需要本人回应的问题（试用期能不能过、竞争对手能不能压制、这个机会抓不抓得住）**：要看天卦 + 人卦——天卦给出大环境的方向，人卦给出本人的三层卦是否能克制 / 借力 天卦的力量。

（详细切换规则和实操见 [[../紫占方法/天卦与人卦|天卦与人卦]]。）

所以在紫占中遇到"太极在哪"这个疑问，默认答案不是命宫而是来因宫——这是紫占工作流的起手式。与本页下方「太极切换规则」里"命盘推演以命为太极"的讨论不冲突——**紫占和命盘是两种体系，默认太极点不一样**。

## 太极切换规则

来因宫是一个**盘级属性**，不是每个太极都带着一个新来因。但在实战中，切换太极时有一个关键处理：

- **以命为太极**：盘面的来因宫就是本人一生因果的起点。
- **以夫妻 / 父母 / 其他宫为太极**：本人的来因宫**不自动**变成"配偶的来因宫"——配偶有配偶自己的盘，真要看配偶的来因，要用配偶自己的盘。立太极切到夫妻宫后，你在本人盘上看到的那一堆四化关系依然以本人的来因为源头，**只是解释对象换了**。

参见 [[../断事方法/宫位立太极|宫位立太极]]。

所以来因宫的"太极切换"在实战中更像是：**你在本人盘上追来因→追到某一宫→这一宫在新太极下被重新诠释**。来因本身是本人的，但它指向的那一宫在换太极时会换对象。比如 [[../../sources/fanxingyaodou/articles/05-紫占与深度解盘/2025-03-22-天煞孤星遇上开瓢女友-原生家庭情感死循环.md|天煞孤星 遇上开瓢女友]] 的案例里，来因宫指向父母宫的结构，被用来解释命主的**原生家庭如何塑造情感死循环**——这时实际上是在"以命看自己、但读父母宫"，来因起到了"把注意力钉在父母这条线"的作用。

## 结构位置

来因宫不属于三方四正、不属于六亲盘、不属于命身线——它是一个**跨层指针**。它的排法在现行紫微斗数里是按生年干固定到十二宫之一，是一个先天属性。

结构上重要的三点：

1. **它可以落在任何一宫。** 来因落父母宫 / 疾厄宫 / 福德宫 / 田宅宫 / 夫妻宫等，都会让解盘重心完全不同。[[../../sources/fanxingyaodou/articles/05-紫占与深度解盘/2025-03-27-紫占实战-公职人员考试卦.md|考试卦]] 里来因落父疾线，整张卦就围绕考运读；[[../../sources/fanxingyaodou/articles/05-紫占与深度解盘/2026-03-19-神明代言人与癔症少女的第五个问题.md|神明代言人]] 里来因在财帛，读出来就是"财帛有烦恼 + 阴性能量影响"；[[../../sources/fanxingyaodou/articles/05-紫占与深度解盘/2026-03-16-紫占实战-外星人入梦传递信息与护身咒.md|信仰枯萎]] 里作者提到"来因田宅宫其实就是已经在说这个信仰已经枯萎了"——来因在田宅直接给出了信仰 / 家族 / 长期承载位上的状态。
2. **来因宫的四化是第一层卦象的发起。** 追忌从这一宫开始跳——这一宫的宫干四化落在哪里，决定"这张盘最先要讲的故事"是什么。
3. **来因三层卦是翻星摇斗的特征读盘方式。** 第一层来自来因宫，第二 / 第三层沿着追忌 / 追禄的路径继续展开，构成一条完整的因果链。读完三层，整张盘的"主线故事"就出来了。

## 高频症状 → 本宫反推路径

参见 [[../断事方法/关系反推|关系反推]]。来因宫的反推用法和其他宫很不同——它不是"症状直接反推来因宫的星"，而是"症状帮你判断来因宫指到哪条线有没有指对"。

- **来访者说问题核心围绕"父母 / 考试 / 规则 / 环境"** → 到盘上验证来因是否落在父母宫或父疾线。若是，从来因宫起的第一层四化几乎就是答案（见考试卦案例）。
- **来访者问题围绕"钱 / 资源 / 循环消耗"** → 验证来因是否在财帛 / 兄弟（现金位）/ 田宅。
- **来访者问题围绕"精神 / 情绪 / 想不通 / 灵异"** → 验证来因是否落在福德 / 疾厄 / 迁移。典型如 [[../../sources/fanxingyaodou/articles/05-紫占与深度解盘/2025-12-26-深度解盘-双魂同体的少年与因果轮回.md|双魂同体的少年]]，来因链路直接指向福德宫的结构伤 + 家族因果。
- **来访者问题围绕"家 / 传承 / 祖上 / 信仰"** → 验证来因是否落在田宅。
- **盘上找不到"哪条是主线"、怎么讲都对** → 先退回去重找来因，按来因起的三层卦象重新排一次。这是翻星摇斗语料里反复强调的"起点"价值：它把一盘巨大的信息量压缩成一条可讲的主线。

## 常见星曜落本宫

来因宫的星**不能独立读**——它只是那一宫本身的星。具体星情去看那一宫对应的页面（[[命宫|命宫]] / [[福德宫|福德宫]] / [[身宫|身宫]] 等本 KB 宫位页）。真正要读的是：**来因宫的宫干发出了什么四化、落到哪里、继续追忌到哪里**。这是"四化飞法"的层面，不是"星意落宫"的层面。
