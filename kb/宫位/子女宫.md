# 子女宫

> **核心对象：子女（含未出世的胎儿） + 你能创造/产出的东西 + 地位比你低的人（下属） + 性关系位 / 桃花次要位。**
> 翻星摇斗 把子女宫从单纯的"有没有孩子"扩开：它是**"你身上长出去的东西"**——亲生的、带的、做出来的、发展出来的。

## 本宫的核心对象

以命为太极时，子女宫同时承载几层：

- **亲生的孩子。** 一生中"第二个孩子"会被再逆数一位到财帛宫，依此类推——子女宫是"孩子 们 的起点位"，不是单指一个孩子（[[../../sources/fanxingyaodou/articles/mid-2247483895|六亲定位-实战案例]]）。
- **未出世的孩子。** 堕胎、流产的胎儿也在这套宫位结构里有落点。翻星摇斗 [[../../sources/fanxingyaodou/articles/mid-2247484731|双魂同体的少年]] 案例里，命主的兄弟宫（按六亲宫位序列）正是那个被引产的姐姐的位置，子女宫也承担一部分。这部分内容本 KB 保留其结构含义，不做道德评述。
- **配偶的母亲。** 按六亲逆数规则，子女宫也是"配偶的母亲位"。
- **地位比你低的人——下属、徒弟、晚辈、合作关系里的"下线"。** "子女宫是等级比你低的"，子女宫也是福德宫的疾厄宫，所以"你的想法（福德）→ 牵动手下（子女）→ 撑住行动力（官禄）"这条链是改命系列里的重要隐线（[[../../sources/fanxingyaodou/articles/mid-2247483800|改命系列一]]）。
- **性关系 / 熟人缘 / 肉体接触层。** 在翻星摇斗的关系远近序列里，子女宫处于 "交友（陌生人）→ **子女（肉体接触/熟络）** → 夫妻（情侣）→ 兄弟（老夫老妻）" 这一格。它是"桃花的次要位"，尤其管"动性了还没动心"那一段。
- **创造力 / 产出能力 / 作品。** 作品、公司业务、想出来的东西——凡"从本体长出去"的，都落在这里。[[../../sources/fanxingyaodou/articles/mid-2247484991|癔症少女]] 案例里，子女宫"天梁、地劫、大耗、伏兵"直接化忌到福德宫的文曲上，让当事人写小说只写虐文——子女宫在这里被当作"创作产物位"来读。

## 太极切换规则

子女宫的太极切换经常被低估，但它在实战里意义很大。参考 [[../断事方法/宫位立太极|宫位立太极]]。

- **以子女宫为太极看孩子本人。** 原盘的子女宫变成孩子的命宫。原盘的夫妻宫变成孩子的父母宫之一，原盘的兄弟宫变成孩子的兄弟宫（也就是孩子的同辈手足），原盘的命宫变成孩子的福德宫（孩子脑子里装着什么=你身上长出去的东西）。问"我孩子本人怎样"必须从这里起算。
- **以夫妻为太极看本人的子女宫。** 它变成配偶的兄弟宫之一。孩子在配偶那边的影响位，不是直接用原盘子女宫读的——这是"配偶眼中孩子是什么角色"的切入点。
- **以官禄/福德为太极反看子女宫。** 子女宫是福德宫的疾厄宫，也是官禄宫相关位。问"我做事能不能招到好帮手"时，这条链比直接看官禄宫更细。

## 结构位置

子女宫位于 **兄仆子田** 结构中，对宫是田宅宫——**子田线** 是一条常被一起断的线（家里/家族的环境↔孩子的状态）。田宅宫是发心和家族能量，子女宫是家族能量直接投射出来的那个小生命/小作品，一体两面。

在关系远近序列（交友→子女→夫妻→兄弟）里，子女宫居第二格："刚认识都是交友宫，然后熟悉了动性了变成子女宫，动心了变成夫妻宫，老夫老妻了习惯了变成兄弟宫"（[[../../sources/fanxingyaodou/articles/mid-2247484044|感情桃花应期]]）。

## 高频症状 → 本宫反推路径

套用 [[../断事方法/关系反推|关系反推]]。子女宫是翻星摇斗典型的**"看似不是子女问题，其实卡在子女宫"**的反推位。

- **"和伴侣有感情，但没法靠近身体 / 没法进入性关系。"** 子女宫在"肉体接触"这一格出问题——空宫+煞、天空地劫类结构。
- **"孩子一直求之不得 / 生了又立刻不顺。"** 子女宫的堵点，或田宅宫四化入子女宫的结构。需要配合疾厄宫看身体端口。
- **"家里总有'没处理完'的感觉，孩子怪怪的。"** 子女宫可能承载未出世孩子的能量位——[[../../sources/fanxingyaodou/articles/mid-2247484731|双魂同体的少年]] 里"贪狼化禄"在子女宫，意向是"想要生孩子/想要一个男孩"，叠上后来家族中发生的引产事件，变成跟着这一世孩子的因果。这层拆法严肃处理，不做猎奇演绎。
- **"做事没人跟、手下留不住 / 带不动团队。"** 子女宫是"比你低的位"。手下的质量和黏性直接挂在这里，常被漏掉。见 [[../../sources/fanxingyaodou/articles/mid-2247483800|改命系列一]]。
- **"想写/画/做的东西出不来 / 出来的都是扭曲版本。"** 子女宫化忌入福德/官禄线的结构。典型见 [[../../sources/fanxingyaodou/articles/mid-2247484991|癔症少女]] 只写虐文的案例。
- **"和熟人圈/朋友圈里发展出肉体关系后关系散掉。"** 子女宫桃花星组动而夫妻宫没跟上——停在"动性"这一格，进不到"动心"。

## 桃花次要位：和夫妻宫的分工

桃花在翻星摇斗的盘面结构里不是单点，而是**一条序列**。子女宫在这条序列上承担"肉体接触/熟络期"的位置。实战分工：

- **交友宫桃花星动** → 异性缘暴涨、遇人变多（陌生人阶段）
- **子女宫桃花星动** → 开始有身体接触或熟人关系升温
- **夫妻宫桃花星动** → 心动成立、进入情侣关系
- **兄弟宫桃花星动** → 变成老夫老妻式的稳定陪伴

看桃花应期和卡点要同时看这四个宫。子女宫是其中"从陌生到稳定"中段的闸门。详见 [[../../sources/fanxingyaodou/articles/mid-2247484044|感情桃花应期]]。

- **[[../星曜/主星/天梁|天梁]] + [[../星曜/煞星/地劫|地劫]] + 大耗 + 伏兵** — 创造力偏"消耗/暗向"表达，写小说偏虐文的典型。见 [[../../sources/fanxingyaodou/articles/mid-2247484991|癔症少女]]。
- **[[../星曜/辅星/文曲|文曲]] 在子女宫** — "肚子里有内容"，常应在生孩子（子宫里有内容=孩子，出生证明也是文书性质叠合）。见 [[../../sources/fanxingyaodou/articles/mid-2247484276]]（巨门-文曲相关讨论）。
- **[[../星曜/主星/贪狼|贪狼]] 化禄 在子女宫** — 想生孩子的意向强，尤其在"想要某个性别"的家庭能量下会被放大。见 [[../../sources/fanxingyaodou/articles/mid-2247484731|双魂同体的少年]]。
- **[[../星曜/主星/破军|破军]] + [[../星曜/煞星/铃星|铃星]] 在子女宫** — 消耗感和烦恼感并存。见 [[../../sources/fanxingyaodou/articles/mid-2247484848|宿命的黑洞]]。
- **[[../星曜/主星/巨门|巨门]] + [[../星曜/主星/七杀|七杀]] 在子女宫** — 巨门的"门"意向在子宫位置易应在生殖系统；七杀让对孩子的态度偏家长式强势（[[../../sources/fanxingyaodou/articles/mid-2247484386]]）。
