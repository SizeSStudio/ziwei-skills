# 兄弟宫

> **核心对象：兄弟姐妹 + 母亲 + 生活上的伴侣/合作伙伴/同辈战友 + "老夫老妻"式的稳定陪伴者 + 现金位。**
> 翻星摇斗 的兄弟宫远不止"血亲手足"——它是**"跟你同属性、同一层级、需要长期协作的身边人"** 的总称。

## 本宫的核心对象

以命为太极时，兄弟宫同时承载几层，语料里写得非常直白（[[../../sources/fanxingyaodou/articles/mid-2247483895|六亲定位-实战案例]]）：

> **兄弟宫：兄弟姐妹、母亲、配偶的父亲、生活上的伴侣、合作伙伴、同辈。**

这句话有两个值得拎出来的点：

1. **兄弟宫不只是手足。** "合作伙伴、同辈"这几个身份说明它是**"同属性但不同个体"**的位置。翻星摇斗的精确讲法——"兄弟宫代表的是跟你同属性但不同的个体，是财帛宫的田宅宫，也就是资源结果整合后，真正到你兜里的，所以经常被称为**现金位**"（[[../../sources/fanxingyaodou/articles/mid-2247483800|改命系列一]]）。
2. **兄弟宫是"老夫老妻位"。** 在桃花序列"交友（陌生人）→ 子女（肉体接触）→ 夫妻（情侣）→ **兄弟（老夫老妻）**"里，兄弟宫是最后一格——关系进入稳定陪伴、习惯、生活伙伴的状态。这也解释了为什么有些人"谈恋爱没问题，一结婚就完蛋"——卡点在兄弟宫，婚姻稳定不下来（[[../../sources/fanxingyaodou/articles/mid-2247484044|感情桃花应期]]）。

"母亲"在兄弟宫，是因为六亲宫的逆数序——母亲是"上一辈的同辈兄弟姐妹"的一种定位（[[../../sources/fanxingyaodou/articles/mid-2247483895|六亲定位-实战案例]]）。这和一些他派把母亲挂到父母宫不同，本 KB 主线采用翻星摇斗的定位。

## 太极切换规则

兄弟宫的立太极是翻星摇斗经常用来解决"同辈协作者/合伙人出状况"的关键动作。详见 [[../断事方法/宫位立太极|宫位立太极]]。

- **以兄弟宫为太极看兄弟姐妹 / 合伙人本人。** 原盘的兄弟宫变成对方的命宫。原盘的命宫变成对方的夫妻宫（"你是对方眼中的伴侣/搭档"——这解释了为什么有些手足关系更像配偶那样深度绑定）。原盘的夫妻宫变成对方的子女宫，原盘的父母宫变成对方的福德宫。问"我合伙人本身是什么样的人，他的脑子里装了什么"时，必须从这里起算。
- **以夫妻为太极看本人的兄弟宫。** 本人的兄弟宫在"夫妻的命宫"视角下，变成配偶的父母宫。所以本人的兄弟姐妹，在配偶的太极下其实是"配偶的长辈位"——这解释了某些家庭里"兄嫂、姐夫"对婚姻的隐性权重。
- **以母亲为太极看。** 若把兄弟宫当作母亲的命宫，原盘的其他宫位都会重新排出"母亲的六亲图"。问母亲相关的事（母亲本人性格、母亲和外婆的关系、母亲的感情等）走这条路径比直接读原盘干净。
- **以合伙人为太极复盘项目。** 把兄弟宫立太极当对方的命宫，看对方的官禄宫（即原盘的哪一宫）——这是评估"合伙人把这个项目做成什么样"最直接的路径。

## 结构位置

兄弟宫位于 **兄仆子田** 结构中，对宫是仆役宫（交友宫）。翻星摇斗对这条线的讲法很精妙：

> "兄—对，交友宫。交友宫广义上是代表所有的人，所有的众生，交友宫的结果位置是兄弟宫，就是说交朋友嘛！最后变成好兄弟。兄弟宫的结果宫是交友宫，则是物极必反，分久必合，合久必分。"（[[../../sources/fanxingyaodou/articles/mid-2247483800|改命系列一]]）

**兄弟宫 ↔ 交友宫** 是一组结果位互为因果的关系。众生认识多了，一部分变成好兄弟（交友→兄弟）；关系太亲密到尽头，又会散回陌生（兄弟→交友）。

在三方四正结构里：
- **"兄 ↔ 迁移"**（以兄弟为里，迁移宫为表）— 物以类聚，你的外在气质由你同好决定。
- **"兄 ↔ 官禄"**（以兄弟为表，官禄宫为里）— 你做事的行动力与结交到的人互为显化。

兄弟宫还是**财帛宫的田宅宫**——资源流到最后真正到手的现金位。忽略这点会把"钱赚了但没攒住"的问题错放到财帛宫。

## 高频症状 → 本宫反推路径

套用 [[../断事方法/关系反推|关系反推]]。

- **"谈恋爱都挺好，一结婚就完蛋。"** 关系远近卡在兄弟宫这一格——"动心能进得来，稳定陪伴进不去"。见 [[../../sources/fanxingyaodou/articles/mid-2247484044|感情桃花应期]]。
- **"合伙人总和我拉扯 / 用'为你好'的方式控制我。"** 典型见 [[../../sources/fanxingyaodou/articles/mid-2247484848|宿命的黑洞]]：兄弟宫紫微+天府+陀罗+阴煞+孤辰——帝皇星坐兄弟位，身边人用"高姿态出谋划策"来覆盖你。不是直接抽鞭子，是慢性内耗。
- **"手足/合伙人对家里的干扰大，导致家里总在'擦屁股'。"** 同一案例里，兄弟宫四化飞到田宅宫使廉贞化忌——"被囚禁感"直接爆表。这是兄弟宫→田宅宫四化链的标准症状。
- **"钱赚了但总攒不住现金。"** 兄弟宫作为现金位的问题。看的不是财帛宫，是兄弟宫的星组和四化。
- **"身边同辈都没用、没人搭把手。"** 兄弟宫的空宫/煞星结构。也可能是命主散发的磁场本身在"招揽控制你的人"而不是平等的同辈。
- **"和母亲关系持续紧张。"** 兄弟宫立太极看母亲的命宫。很多时候不是母亲"这个人"有问题，而是母亲的父母宫（即原盘福德宫）有重结构，把能量压下来了。

## "解忌"角色：兄弟宫化科的救命草

[[../../sources/fanxingyaodou/articles/mid-2247484848|宿命的黑洞]] 里有一个极精彩的结构：交友宫坐文昌化忌（众生位对本人有敌意），但**兄弟宫飞一个化科进到交友宫**，这在翻星摇斗被叫作"解忌"。

含义：当你与众生的缘分不顺，**根源常常不在众生，而在你和同辈亲密关系里的后遗症**——因为你先预设别人会控制你/害你，所以先射出了"忌"的箭。兄弟宫的化科是能把这堵墙拆掉的扳手——"当你不再把亲近的人看作是要控制我的恶魔，你投向大众的目光才会变得平和"。

这条"兄弟宫化科→交友宫解忌"的路径是翻星摇斗对内向/防御型性格**从亲密关系层开始松绑**的典型操作。

- **[[../星曜/主星/天府|天府]] + [[../星曜/煞星/火星|火星]] + 天刑 + 天才 + 三台八座** — 马斯克命盘的兄弟宫，"固定空间+快速+众多人"指向宏伟协作项目（火星计划），见 [[../../sources/fanxingyaodou/articles/mid-2247484106]]。这是兄弟宫解释"同辈协作网"的另一种极端表达。
- **[[../星曜/主星/太阳|太阳]] + [[../星曜/主星/太阴|太阴]] + 华盖 + 天寿 + 破碎 + 伏兵**（兄弟宫作考试卦的知识点储备位） — "有一些知识点没搞清楚"的意向结构。见 [[../../sources/fanxingyaodou/articles/mid-2247484115|考试卦]]。
- **[[../星曜/主星/天相|天相]] + [[../星曜/煞星/地劫|地劫]] + 天刑 + 红鸾 + 伏兵**（兄弟宫作未出世胎儿位） — [[../../sources/fanxingyaodou/articles/mid-2247484731|双魂同体的少年]] 里的典型结构：兄弟宫伏兵意味着在身边徘徊未处理的能量。
