# 福德宫

> **核心对象：一个人的福报总量、大脑逻辑思考、内心真正想要的东西。**
> 福德宫不是"享福位"，它同时管"你有多少资源可用"和"你这个脑子怎么分配资源"。

## 本宫的核心对象

以命为太极时，福德宫在翻星摇斗的用法里承担**三件事**，都要同时看：

1. **福报总量。** [[../../sources/fanxingyaodou/articles/mid-2247483800|改命系列一]] 原文："福德宫一方面代表，你有多少福德福报……你有这么些福德福报，所以你才会有这些资源。" 福德 — 财帛是一对表里，福多则财有底气来源。
2. **大脑逻辑思考 / 内心想法。** 同文："福德宫是你对这些资源的分配利用能力……你肯定是要用大脑去分配的。" 福德里的星讲的是**想法的质地**：[[../../sources/fanxingyaodou/articles/mid-2247483731|福德宫贪狼]] = 内心想要的是"玩乐 / 花里胡哨的东西"；[[../../sources/fanxingyaodou/articles/mid-2247484364|福德宫贪狼在午]] = 贪狼在午"有欲是人间界、无欲是自在天"，福德宫的欲望强度直接定位这个人的精神频段；福德宫天梁 = 想要像老大哥一样"足"（[[../../sources/fanxingyaodou/articles/mid-2247483672|天梁相关讨论]]）。
3. **祖父 / 祖辈。** 见 [[../../sources/fanxingyaodou/articles/mid-2247483895|六亲定位]] — 福德宫在六亲对应里代表"祖父"（祖父这一代男性长辈）。在 [[../../sources/fanxingyaodou/articles/mid-2247484731|双魂同体的少年]] 里，作者直接用"福德宫可以代表祖上，爷爷奶奶那一辈"来解读祖辈层面的四化冲击。

这三件事在翻星摇斗的语境里是**同一件事**——你累世的福报在这一世以"你能想到什么 / 你天然倾向什么 / 你祖上传来的势"三种形态同时显化在福德宫。它不是"好宫=享福、坏宫=想不通"的二元判断，而是"福德宫里的星决定了你的精神频段和你的可分配资源池"。

## 太极切换规则

福德宫立太极时的切换非常活。参见 [[../断事方法/宫位立太极|宫位立太极]]。

- **以夫妻为太极，本宫变成配偶的迁移宫（配偶在外的样子 / 配偶的运气结果位）。** 从本人角度看，本人福德宫上出问题的时候，往往意味着配偶在外面遇到的事也在跟着动。
- **以子女为太极，本宫变成孩子的官禄宫（子女宫逆数到福德宫刚好是官禄线）的对宫方向**——具体位置要按实际太极数清楚，但核心是"孩子的做事 / 显现 / 身份位"。
- **以父母为太极，本宫变成父母的兄弟宫 / 现金位**——也就是说父母当下的流动资源、兄弟关系等，能部分从命主福德宫看。
- **以福德为太极（即看"自己的精神 / 想法 / 祖辈这条线"本身）**：这是最常用的二次立极——用福德宫做新命宫，再数出"福德的疾厄"（即原盘父母宫）、"福德的财帛"等，看想法这条线自己的内部结构。这在实战中经常出现，尤其 [[../../sources/fanxingyaodou/articles/mid-2247484848|宿命的黑洞与防御式自闭]] 这类精神内耗案例。

福德宫的一六共宗对应是"财为表、福为里"——里层是福报/想法，表层是当下可调动的资源。所以凡是讲"想法要落地"的断法，必须同时动财和福两个宫。

## 结构位置

福德宫在**财福线（财帛—福德）**上，这是翻星摇斗反复强调的一条主轴：

- **对宫：财帛宫**——想法 ↔ 资源。福德动财帛也动，福德宫化忌常在财帛上显化为钱出问题。
- **一六共宗**：福德为里、财帛为表。这是"福报决定资源 / 资源反映福报"的结构基础。
- **六亲位**：祖父 / 祖辈一代的象征位。当解盘涉及家族因果、祖上传承时，福德宫是一个核心探测器。
- **福德—命的连接**：福德宫化忌能直接冲命（通过追忌链），典型就是 [[../../sources/fanxingyaodou/articles/mid-2247484731|双魂同体的少年]] 里"福德宫 + 力士 + 文昌火星天哭"的结构，顺着追忌落到命宫天机化忌，直接显化为"带着原罪出生"。

## 高频症状 → 本宫反推路径

参见 [[../断事方法/关系反推|关系反推]]。福德宫是翻星摇斗**反推出现频率最高**的一个宫。

- **"我脑子一直停不下来 / 想太多 / 睡不好"** → 福德宫有"想法密度过高"类的组合（巨门 + 煞、天机化忌、文昌 + 火星等）。翻星摇斗典型案例：[[../../sources/fanxingyaodou/articles/mid-2247484731|双魂同体的少年]] 原话 —— "福德宫，直接表现出的就是脑子容易有问题，而且容易想歪误解误会别人，而且性子很急，容易感觉到不舒服"。
- **"我命不好 / 一辈子没什么福"** → 先查福德宫是否被严重破坏（文昌 + 火星 + 天哭 + 力士 等叠加），而非直接读命宫。
- **"钱总是攒不住 / 一有钱就散"** → 福德宫出问题，财帛宫只是结果显化位。"福报不足，则财无所依"。
- **"我知道该怎么做，但就是不想做 / 一点欲望都没有"** → 福德宫的贪狼落陷或天空、地空入福德。欲望强度直接影响可用的动机资源。
- **"家族里 / 祖上好像有事一直压着我"** → 福德宫（祖辈位）四化出问题，沿追忌 / 追禄向下看能不能落到具体哪一脉。
- **"看到某些人就浑身难受 / 被讨厌 / 到处被排挤"** → 福德宫恶名位（福德伤）。[[../../sources/fanxingyaodou/articles/mid-2247484731|双魂同体的少年]] 直接给出原文 —— 福德宫文昌火星天哭 = "恶名远扬……一些缘分不太好的，真的看了就会觉得很讨厌"。

## 常见星曜落本宫

- [[../星曜/主星/贪狼|贪狼]] 入福德 —— 内心想要"量"，欲望驱动型的精神结构。在午宫的贪狼则是"无欲"状态，福德宫安静（见 [[../../sources/fanxingyaodou/articles/mid-2247484364|相关讨论]]）。
- **天梁入福德** —— 想要"足"、想当老大哥、想被仰仗。是内心的一种补偿性追求。
- **巨门 + 煞入福德** —— 精神噪音多，典型失眠 / 反刍型脑子。
- **天同入福德** —— 享受能力强、精神柔软，和贪狼入福德常被翻星摇斗并列为"会享受"的类型。
- **紫微天相 + 地劫 + 阴煞 + 擎羊入福德**（见 [[../../sources/fanxingyaodou/articles/mid-2247484115|考试卦]]） —— 高贵但有缺漏，内心对"自己配不配得到"常有隐性焦虑。
- **文昌 + 火星 + 天哭 + 力士入福德**（见 [[../../sources/fanxingyaodou/articles/mid-2247484731|双魂同体的少年]]）—— 福德伤结构，需重点处理。

## 参考（他派对照，非本 KB 主线）

> ⚠ 以下仅做辨析用。主线采用"福德宫 = 福报 + 大脑逻辑 + 祖辈位"这一三合一定义。

- **全书一脉**：福德宫多被译为"享福位 / 兴趣喜好位"，并以吉凶星论"福厚 / 福薄"。翻星摇斗不采用这一吉凶评价，而是把福德宫看作一个**频段计量宫**——你的精神在哪个频段，决定你能接到什么样的资源和机缘。
- **飞星紫微斗数**：重视福德宫四化飞入 / 飞出的路径，和本 KB 的"来因 → 追忌"路线在技法上最接近，但解释语言（精神 / 福报 / 祖辈三合）不混用。
