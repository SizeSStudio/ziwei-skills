# 田宅宫

> **核心对象：家、房、家族、储存位；同时是本人的"发心"与改命的物理通道。**
> 翻星摇斗最重视的一个宫：它既是人的内心最底层的想法，又是能量储存位，又是风水能落地的那个位置——三重身份叠在一个宫里。

## 本宫的核心对象

以命为太极时，田宅宫同时承担三层含义，必须一起读：

**第一层：不动产/家。** 最表层的世俗含义——房子、土地、家族居所。这一层在所有派别里都有，翻星摇斗也承认，但不视为全部。

**第二层：内心最核心的想法 / 发心。** 翻星摇斗的关键定义："田宅宫，代表我们最内心的想法，也是代表不动产的位置，是我们能剩下积攒的东西。"原文进一步："只要你掌握了规则，也就是观天之道了！你最终的发心！也就是发个大愿啥的，整个宇宙的能量都会被你牵引而来！给你提供资源。"田宅宫是一个人"最终想要什么"的那个底——行动线（官禄）只是这个底的外化。

**第三层：储存位 / 能量源码。** 在夫妻宫+量子力学那篇里，田宅宫被直接定名为**"人生源代码"、"投影源"**——"存储累世的情感模式（含家族业力与潜意识）"、"佛教称阿赖耶识，道家称先天元神"。配套的改运公式："夫妻宫显示的情感状态 = 田宅宫存储的能量 × 官禄宫的行动轨迹"。维度穿透律原文："清理田宅宫1分能量，夫妻宫改善7分状态"。翻星摇斗明确反对"在夫妻宫修修补补"——改运要走田宅宫这条上游。

这三层合起来是翻星摇斗之所以把田宅宫叫作"**改命的物理载体**"的来源。风水落地、夫妻关系改善、整条命运剧本重写，都走田宅宫这个接口。

## 紫占中"房子"的三合读法

[[../../sources/紫占方法论|紫占方法论]] 里专门提醒了一点：**紫占中问"房子"不是只看田宅宫就够**。命盘里田宅宫是家 / 储存位 / 发心的主力位，但在紫占这种"当下一分钟的快照"体系里，房子这种具体物象是由三颗星 / 三个宫位合起来共同描述的：

> "紫微代表房子的星和宫很多。有田宅，有天府，有凤阁。这三个是主力的，其它比如龙池也有时会有这方面的性质但意又不同。"（源：紫占方法论 行 1505–1507）

所以紫占里诊断房子要做的是**三合描述**——田宅宫给"家/储存/不动产"的底位，天府给"空间/城府/包容"的主星维度，凤阁给"贵气/美观"的辅星维度，三点都扫完才不会漏。再按问题细节叠加小星：贵气型房子（天贵/三台/八座）、漂亮型房子（天姚/龙池）、多层（左辅）、有楼梯（攀鞍/陀罗）、独栋（孤辰/寡宿）等。

这条规则只在紫占里生效——命盘推演看"家"仍然以田宅宫为主、其他宫为辅。紫占的物象化要求每件具体事都要从多宫合看（参 [[../紫占方法/物象化|物象化]] 和十二相里的"冲宫合卦 / 宫位叠加相"），这是"房子"这条的具体版本。

## 太极切换规则

田宅宫是立太极切换里用得最高频的枢纽之一。配合 [[../断事方法/宫位立太极|宫位立太极]]：

- **以夫妻为太极**：原盘的田宅宫变成**"配偶的福德宫"**——配偶的脑子、福分、资源调度能力。这就是为什么问配偶有没有"想法匹配、福报够不够"要看这里，而不是看原盘夫妻宫。
- **以命为太极 + 田宅是改命接口**：这个不是切太极，而是一个特别强调——田宅宫的四化一旦被触发（用官禄宫去反向化它），整条命盘的能量分布就被重新布线一次（见风水原理入门2的"胶佬"案例）。
- **以子女为太极**：原盘的田宅宫变成"孩子的财帛宫"——问孩子的资源/机会在哪，切到这里。
- **以官禄为太极**：原盘的田宅宫变成"事业的疾厄宫"——事业的身体/承载能力；公司能不能扛得住，看这里。
- **以财帛为太极**：原盘的田宅宫变成"钱的父母宫"——钱的规则、大环境、平台。财帛宫的一六共宗里"父母是财帛的根"，但从财帛立太极看自己的田宅，讲的是"钱要跑进什么样的规则/池子里"。

**特别提醒（来自立太极文）**：不要把"以田宅为太极"等同于"看房子"。田宅宫既可以是房子的太极，也可以是家族整体、财富储存位，甚至是"内心底座"的太极。具体立什么，取决于来访者实际问的是什么。

## 结构位置

- **父—疾—迁—田（内外线/储存线）**：父母宫管规则/大环境、疾厄宫管身体承载，这条线和田宅的关系是——父母是财帛的根，财帛的疾厄是田宅。层层往上堆，田宅是顶。
- **兄仆子田四正**：田宅宫在"兄—仆—子—田"这条四正上，跟子女对宫。所以"家教"、"家庭底蕴"的表达直接应在子女身上——原文："田—对，子女宫，家庭环境是直接体现到孩子身上的"。
- **田宅↔夫妻的表里关系（翻星摇斗口径）**："以田为里，其表是夫妻宫"——田宅是家的发心，夫妻是家的行动表现。这组表里关系是婚姻改运公式的结构基础。
- **财—田一六共宗**：财帛为里，田宅为表——"里面的是有多少资源，表露出的是有多少不动产"。所以存钱买房买地、财帛兴则田宅旺是这个一六链的世俗对应。
- **双宫同卦 / 卦位叠加**：风水原理入门里强调，田宅宫的应验要结合地支宫位和八卦叠加读——如酉宫的廉贞+破军+地劫+龙池+破碎，兑卦"兑上缺"叠加星象缺漏，风水应验点就在"家里容易脏乱、东西易摔碎"。

## 高频症状 → 本宫反推路径

应用 [[../断事方法/关系反推|关系反推]]：

- **"婚姻怎么修都没用，一换人还是老问题"** → 不要盯夫妻宫修。按"投影守恒律"回到田宅宫——投影源没换，换对象只是换投影屏幕。清理田宅的星曜结构（擎羊/化忌/大耗等）才是改运接口。
- **"家里一乱我就出事 / 每次搬家人生节拍就变"** → 田宅宫的风水意向被激活。典型如"田宅宫廉贞+破军+地劫+龙池 → 家里脏乱 → 夫妻宫不顺、迁移宫化忌" 的联动（风水入门2案例）。这属于田宅宫的地支+卦位三重叠加被触发。
- **"内心总空，再多钱再大房子也不踏实"** → 看田宅宫的"美好与空虚"结构——马斯克田宅宫天相+天马+天姚+天福+天巫+截空+天虚，外面看齐全，内里有截空、天虚的空缺。翻星摇斗不把这当"不好"，而是当作"驱动本人不断扩张的底层动力"。
- **"家族代代卡在同一件事上"** → 田宅宫作为"累世情感模式/家族业力"的储存点，反推家族循环问题走这里。父母宫管规则，田宅宫管储存的种子。
- **"风水师摆的东西没效果"** → 共性风水（大家都受影响的那层）和个性风水（个人定制）没分清。个性风水要用本人田宅宫的四化和星意去定制，不能套模板。
- **"夫妻事业/情感起不来"** → 不要直接改夫妻宫。用官禄宫反向化田宅宫的关键星（如"用官禄宫使得田宅宫的廉贞化忌"），把源代码级的能量重置一次。

## 常见星曜落本宫

- **[[../星曜/主星/紫微|紫微]] + [[../星曜/主星/天府|天府]]** — "自带贵气吸引优质伴侣"型的投影源（夫妻宫+量子力学文直接举例）。
- **[[../星曜/主星/廉贞|廉贞]] + [[../星曜/主星/七杀|七杀]]** — 田宅宫里的"情感控制欲"版本，需要清理才不进入"被囚禁"式的家庭体感（见宿命黑洞案例：廉贞+天相+天刑化忌入田宅 = "擦屁股现场"）。
- **[[../星曜/主星/巨门|巨门]] + 陀罗** — "过度牺牲型人格"储存位（田宅宫自查清单）。
- **[[../星曜/主星/天同|天同]] + 火星** — "情感依赖症"储存位。
- **[[../星曜/主星/天相|天相]]（马斯克式组合）+ 天马、天姚、天福、天巫、截空、天虚** — "美好与空虚并存"，内心忙碌驱动对外扩张。
- **[[../星曜/主星/天机|天机]]** — 田宅宫见天机代表"可改变、不重要的地方"。武曲文里说："武曲可以为了达到某个目的而改变自己的底层思想"——天机在田宅是可改变性的星意来源。
- **[[../星曜/主星/天梁|天梁]]+右弼+文昌+天哭**（考试卦案例）— 田宅宫的"悲观、没安全感、心定不下来"结构；化权能立住支柱。
- **铃星** — 需用盐灯化解的焦躁能量（夫妻宫+量子力学文的具体改运法示例）。
