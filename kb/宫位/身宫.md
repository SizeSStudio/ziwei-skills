# 身宫

> **核心对象：中晚年显化出来的自己 + 出生时辰把"自我"落在了哪一宫的那个印记。**
> 本页语料暂薄：翻星摇斗现有文章没有专门谈身宫的，只有零散地把它和命宫并列提起。以下内容按既有语料严格写出，不做外推。

## 本宫的核心对象

以命为太极时，身宫是**另一个"本人位"**，但它跟命宫讲的不是同一回事：

- **命宫** = 一生总结的自己，灵魂层面的你。
- **身宫** = 后天显化出来的自己，尤其是**中晚年**（35 岁之后）逐渐压过命宫显化出来的那个状态。

翻星摇斗现有语料里对身宫的直接描述非常少，只在 [[../../sources/fanxingyaodou/articles/01-主星原始星意/2023-04-24-你会喜欢武曲星吗.md|你会喜欢武曲星吗？]] 里有一句"如果你命宫是武曲，或者身宫是武曲，那是不能幻想着钱财能从天上掉下来的"——把身宫和命宫并列，作为"本人发出的持续信号"的另一个载体来用。这是本 KB 目前能从语料里拿到的最直接的身宫用法：**身宫和命宫同等地刻画"本人"，但身宫更偏向后天、更偏向行动落到哪里**。

本页暂不铺开身宫的原始理论，以免从非翻星摇斗语料里外推，不对齐 KB 主线。

## 身宫寄宫规则

身宫不独立占一个宫，而是**按出生时辰寄入六个宫之一**——这是紫微斗数的基本排盘规则：

| 出生时辰 | 身宫寄入 |
|---------|---------|
| 子、午 | 命宫 |
| 丑、未 | 福德宫 |
| 寅、申 | 官禄宫 |
| 卯、酉 | 迁移宫 |
| 辰、戌 | 财帛宫 |
| 巳、亥 | 夫妻宫 |

**身宫寄哪里，中晚年就在那个方向被显化：**

- 身宫在命宫 → 命身合一，一生的主线和中晚年的主线同频，人较"本色"。
- 身宫在福德宫 → 中晚年的重心转向精神 / 内在 / 想法。
- 身宫在官禄宫 → 中晚年依然靠事业 / 行动结果定义自我。
- 身宫在迁移宫 → 中晚年的样子是"在外面那个我"被放大，远方、环境、对外的状态决定晚境。
- 身宫在财帛宫 → 中晚年被钱财 / 资源调用能力显化。
- 身宫在夫妻宫 → 中晚年的状态高度被伴侣关系决定。

> ⚠ 以上寄宫表是紫微斗数的通用排盘规则，不是翻星摇斗的独家主张。翻星摇斗语料没有直接展开这六种寄宫的差异讲法，具体如何解读需结合星曜落宫 + [[../断事方法/宫位立太极|宫位立太极]] 自行推演。

## 太极切换规则

因为身宫必寄于六宫之一，**身宫在立太极时不独立换太极点**——你以谁为太极，身宫就跟着被那个太极下的对应宫收编。

举例：

- **以夫妻为太极看配偶**：如果本盘身宫寄夫妻宫，那夫妻宫 = 配偶的命宫 = **本人身宫所在**——意味着"我的中晚年"和"配偶的本命"强绑定，这是典型的"身宫寄夫妻的人晚年高度随配偶"的结构化解释。
- **以官禄为太极看事业/单位**：如果本盘身宫寄官禄宫，立太极后身宫所在变成"事业的命宫"，表示"我中晚年所做的事"本身就是"事业这条线的根"。

关键是：身宫 ≠ 一个独立的解释对象，它是**一个修饰标记**——告诉你所寄宫在命主中晚年被持续强化。参见 [[../断事方法/宫位立太极|宫位立太极]]。

## 结构位置

身宫不占地支位，它**叠印在六个可能的宫上**。结构上最有用的一点是：

- 身宫寄在哪，**那一宫就同时承担两个解释任务**：自己原本的职能（比如官禄就是事业）+ 身宫的"本人中晚年显化"。这一宫的四化、星情对本人来说权重更重。
- 身宫所寄宫的**对宫 / 三合**因此也间接被拉进"自我轴"——比如身宫在财帛，财福线对这个人来说就比对命身合一的人更接近命身线。

## 高频症状 → 本宫反推路径

> ⚠ 本节语料薄弱，以下仅按既有片段 + 身宫寄宫通则作保守归纳。详见 [[../断事方法/关系反推|关系反推]] 的一般方法论。

- **"年轻时一个样，35 岁后完全换了个人"** → 命身不合一，身宫寄的那一宫在中年段开始压命宫。去那一宫看星情。
- **"一辈子都在帮配偶/被配偶拖"** → 优先怀疑身宫在夫妻。
- **"事业好了人整个都好、事业差了人整个塌"** → 优先怀疑身宫在官禄。
- **"靠钱立命"** → 身宫在财帛，且疾厄/官禄承得住。
- **"漂在外面几十年回不去"** → 身宫在迁移。
