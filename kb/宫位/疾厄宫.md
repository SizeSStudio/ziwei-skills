# 疾厄宫

> **核心对象：身体 / 肉体承载 / 命宫的表里另一面。**
> 翻星摇斗把疾厄宫从"看病灾"改写为"命宫的一六共宗对位"——它是你在人间的承载体，同时是命宫那个"灵魂自己"在物理世界的映射。读疾厄从来不只是读身体。

## 本宫的核心对象

以命为太极时，疾厄宫同时承担两层含义：

**第一层：肉体 / 在人间的承载体。** 翻星摇斗原文："疾厄宫——肉体、在人间的承载体。" 身体的基本条件、扛不扛得住事、容易生什么病、会不会复发——这些都落在疾厄宫。改命系列一那篇里讲得很直接："当然最主要的是你本人能不能扛得住，你的命宫，看你的运气怎样，疾厄宫看你的身体条件怎样！只要你都扛得住，那钱都可以来！"

**第二层（翻星摇斗核心 reframing）：命宫的一六共宗对位——显露真实底色。** 这是本宫最重要的结构。翻星摇斗把十二宫按一六共宗配对（命与疾厄同组、兄与仆同组、夫与官同组……）。原文的正式定义："在十二盘的排布中，命宫的逆时针数到第六位是疾厄宫，命宫是1号宫，那是6号宫。1号宫代表里面最根源的东西，6号宫代表表面的东西，两个宫位一表一里，相互影响。"

换成翻星摇斗的意象化说法：**命宫是灵魂上的你——"里"；疾厄宫是这具灵魂在肉身上的外显——"表"。** 所以疾厄宫显示的不是一堆病名，而是"这个人真实的底色是什么——精力、底子、耐受力、潜在的能量分布"。身体是底色的物理化。

这就是为什么翻星摇斗会在疾厄宫里读出**灵性/通灵体质**。"疾厄宫巨门禄存、天姚、天巫、天使，自化忌，直接就是说肉身会不断的生成信息，不受控制的溢出"（神明代言人案例）——这既是身体层面的"信息不受控"，也是本质层面的"肉身是地府的接收器"。肉体维度和灵性维度在疾厄宫里被翻星摇斗同时读。

**身体的具体部位由宫位地支承载**（武曲文的完整讲法）：卯宫代表左腰腹、酉宫代表右胸（右肺），疾厄宫落在不同地支，同一颗星表达的身体器官就不同。"小星定星情，宫位定人事"——疾厄宫判身体要合地支。

## 紫占中的一六共宗（表里）

本页上一段已经把"命-疾一六共宗、命为里疾为表"的结构原理说清了。紫占方法论把这条结构落在了一个更实操的用法上——**太极点所在宫 = 里象（本质），太极点的疾宫 = 表象（表现）**，两者不一致时出现一类专门的"反复问题卦"。详细十二相体系参 [[../紫占方法/十二相|十二相]]（一六共宗是其中一相）。

> "太极点的宫位是里象，太极点的疾宫是表象。这个在我们紫占事物时非常多的应用，如果我们要处理一问题总是会有反复时，一定反推一下这个宫的一六共宗位，处理另一个看上去没有关系的宫位，反而效果要好得多。"（源：[[../../sources/紫占方法论|紫占方法论]] 行 1693）

**关键操作原则**：**反复出现的问题要行动于里（太极），不是表（疾宫）**。作者用北京雾霾做类比——尾气（本宫/里）才是源，雾霾（疾宫/表）只是表现；吹散雾霾只能管一时，治理尾气才能从根断。看病时发烧（表）反复不好，往往是因为重金属过敏（里）没处理；感情里女方行为（表）莫名其妙，其实是发心（里）已经变了。

紫占里本宫和疾宫信息相矛盾，衍生出四类典型卦象：

- **陷阱卦**（行 1661–1663）：本宫一片凶象（真实动机是要下手），疾宫却表现得非常平和、欢喜。"人畜无害"的伪装卦——背后正在对你动刀。
- **矛盾卦**（行 1701–1705）：本宫和疾宫的意图互相对着干。典型是"想离开某段关系但身体不让走"、"理智想戒但疾宫一直在馋"。断这类卦看哪一宫的力量大，力量大的那一宫主导未来走向。
- **佯攻卦**（行 1671）：本宫其实是想撤退 / 小目的，疾宫却打得热火朝天像要全力进攻。军事佯攻、虚张声势、小商贩大吵大嚷为几块钱都是这类结构。
- **减肥卦**（行 1705）：作者的原话自嘲案例——命宫天天说"太胖了不能吃"，疾宫天天说"我饿啊"，两宫常年对撞，最后哪个力量大哪个赢（作者自述疾宫赢了，所以体重没降）。减肥卦是矛盾卦的一个亲民子类。

这四类卦有一个共同的诊断入口：**本宫 ≠ 疾宫 的信息源**。发现信息撕裂时不要草率把其中一宫的读法当做最终结论，要两宫并读、再按力量大小裁决。改这类问题时永远先动里（太极本宫），不是表（疾宫）——除非疾宫的力量压倒性地大于本宫。

## 太极切换规则

以其他宫为太极时，疾厄宫讲的对象会换。配合 [[../断事方法/宫位立太极|宫位立太极]]：

- **以夫妻为太极**：原盘的疾厄宫变成"配偶的命宫逆数第六位"——即配偶自己的疾厄位——配偶的身体底色。问"配偶身体怎样"走这里，而不是读原盘的疾厄宫直接说他。
- **以财帛为太极**：**原盘的田宅宫变成"钱的疾厄宫"**——翻星摇斗的关键结构："财帛宫的疾厄宫是田宅宫，只要把财帛宫搞好了，你田宅宫也能提升上去。" 反过来，财帛宫能扛多少事，看田宅宫。
- **以子女为太极**：原盘的官禄宫变成"子女/下属的疾厄宫"——下属能否扛事。
- **以官禄为太极**：原盘的田宅宫变成"事业的疾厄宫"——事业/公司的身体承载。
- **问身体 → 直接以疾厄为太极**（立太极文明文）：所有"问身体"的问题，直接把疾厄立为新命宫，重新数十二宫再读。

**特别提醒**：父疾线（父母宫和疾厄宫的组合）在翻星摇斗里是**考运的核心线**。考试卦案例的原文："来因宫落在了父母宫和疾厄宫的位置……父疾线通常都是代表考运怎样的。" 看考试不只看父母宫，疾厄宫的"知识点储存/消化程度"也要配合读。

## 结构位置

- **命—疾一六共宗**：全盘最底层的一对表里。命是灵魂/本源，疾是肉体/外显。**这是疾厄宫最核心的结构位，超过所有其他位置。**
- **父—疾—迁（父疾线）**：与父母宫、迁移宫构成六内线。父母是规则/眼界，疾厄是身体/本质，迁移是在外显化——考运的官方通道。
- **田宅宫是财帛宫的疾厄**（一六共宗扩展）：这不是本宫自己的结构，但定义同一体系——每个宫都有自己的疾厄对位。财—田的表里关系让田宅承接财的"身体"，是翻星摇斗"财帛兴则田宅旺"的结构原理。
- **疾厄↔福德 对宫**：福德宫是疾厄宫的对宫。脑子的状态直接反映到身体——"马头带剑 + 福德宫文昌火星天哭 → 恶名远扬，且疾厄宫受福德影响"（双魂案例）。福德宫的伤害会通过对宫投射到疾厄。
- **疾厄宫的改善路径**：翻星摇斗的说法——"交友宫对命宫的影响是极大的，我是众生，众生是我，众生对我越好，我命的气运也就越高，命宫好了，疾厄宫也就越好。" 改疾厄的上游通道是命，命的上游是交友。

## 高频症状 → 本宫反推路径

应用 [[../断事方法/关系反推|关系反推]]：

- **"身体没毛病，就是总觉得没劲"** → 疾厄宫是命宫的表；不是疾厄坏，是命宫能量薄，表现为身体没底。调命宫（调交友、调福德）比调身体快。
- **"反反复复生同一种病"** → 疾厄宫有复发类结构（化忌自化、循环组合）。按辅星文口径，"疾厄宫代表经常犯什么病、复发"——要看是哪颗星的意向在循环。
- **"考试前身体就垮"** → 父疾线被干扰。父母宫（规则/眼界）+ 疾厄宫（知识点承载）同时化忌或被煞星冲，考试压力直接落身体。考试卦案例里"疾厄宫左辅文曲 = 复习内容够复杂"是正向结构；反过来煞侵则是负向结构。
- **"查不出的身体不适 / 睡不好 / 气短胸闷"** → 疾厄宫与阴性能量相关的组合（巨门+天巫+天姚+自化忌 一类）。翻星摇斗把这类同时读身体和灵性，既不否认生理也不否认灵性维度。神明代言人案例是教科书样本。
- **"骨折/撞击/金属伤"** → 武曲相关的疾厄结构（武曲=金属/硬），结合地支看器官——卯酉宫落陷的武曲有"木压雷惊"类格局的意向映射。
- **"身体很好就是心里垮"** → 福德→疾厄的对宫冲。福德宫有煞的时候，疾厄宫单看没问题但人整体"扛不住"。要改福德而不是改疾厄。
- **"双魂同体/感觉身上有别人"** → 疾厄宫 + 夫妻宫 + 福德宫联动异常的极端案例。双魂案例的原话："夫妻宫铃星天马天巫阴煞 + 财帛宫天同太阴天寿 → 女鬼带来的烦恼，这孩子天生通阴。" 疾厄宫在这种读法里是"灵体占据的物理接口"。

## 常见星曜落本宫

- **[[../星曜/主星/武曲|武曲]]** — 金属性的身体部位（肺、牙、骨）。武曲在疾厄合地支读器官。
- **[[../星曜/主星/天同|天同]]** — 感受型；天同暗合贪狼，疾厄+天同常有"想去玩/想放纵"的身体冲动。
- **[[../星曜/主星/贪狼|贪狼]]** — 身体的"量"——肉、体积、脂肪分布；配合辅煞星看，不是一见贪狼就胖。
- **[[../星曜/主星/天机|天机]]** — "任性地放弃自己"（天机疾厄的典型应相，见天机文原文）。
- **[[../星曜/主星/破军|破军]]** — 身体的破坏性/突破性。
- **[[../星曜/主星/紫微|紫微]]** — 紫微疾厄是"养尊处优的身体"（紫微文原文）。
- **[[../星曜/主星/巨门|巨门]] + 禄存 + 天姚 + 天巫 + 自化忌** — "肉身不断生成信息、不受控制溢出"的通灵体质（神明代言人案例）。
- **左辅 + 文曲**（在考试卦里）— 知识点储存够复杂；在疾病语境下是复杂病症的组合。同星意两极表达。
- **[[../星曜/主星/天府|天府]]** — 稳定的身体仓储；双魂案例里疾厄宫天府（没四化，动不了）也成了破局盲点——"变动不了所以只能从财帛宫动"。
