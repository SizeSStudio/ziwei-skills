# 命宫

> **核心对象：本人——一生总结的自己、灵魂层面的你。**
> 命宫不是"一生的运气"，也不是"性格标签"，它是整张盘立太极时默认的那个基准点。

## 本宫的核心对象

以命为太极时，命宫讲的是**"一生总结的自己"**——翻星摇斗的讲法里，命宫是"灵魂上的你"，是你这一辈子从头到尾被压缩成一点后那一点的样子。疾厄宫是肉体、是承载体，命宫是里层的根源。这是"一六共宗"的第一组：命（1 号宫）为里、疾厄（6 号宫）为表，两者一表一里相互影响。

命宫的星不是"性格标签"，而是这个人一生被反复显化的那种核心结构。在实战里，一个命宫太阴禄存的人，会持续地**对"存"这件事发出信号**——积攒金钱、积攒能量、积攒底气；命宫武曲的人则是持续地对"行动得财"发出信号，不会等钱从天上掉下来。这种"持续发信号"的方式，才是命宫真正的工作机制。

更关键的是另一条一六共宗：**交友宫是命宫的根**。你命好不好不是看命宫一个宫，而是要倒过来看交友宫——你所结交的众生是怎样的，你接收到的能量回流是怎样的，这决定了命宫能呈现出怎样的命。这一条在翻星摇斗里是反复讲的，"众生对我越好，我命的气运越高"——把命宫孤立读是读不出东西的。

## 紫占中作为人卦太极

命宫在命盘里是默认太极，但在**紫占里它不是默认太极，而是"人卦"的太极点**——与之对应，来因宫才是紫占默认（天卦）太极。详见 [[来因宫|来因宫]] 里「紫占中作为默认太极」段和 [[../紫占方法/天卦与人卦|天卦与人卦]]。

> "天卦就是来因宫为太极点的三层卦象体系，人卦是命为太极点的三层卦象体系。"（源：[[../../sources/紫占方法论|紫占方法论]] 行 917）

实务里：**紫占并不是每一卦都要开人卦**。只有当问题的结果需要本人的回应来决定时（试用期、竞争、对抗、考试发挥），才在天卦之外另起一层以命宫为太极的三层卦，去看本人这三层力量能不能克制天卦给出的趋势。问环境型问题（房子、经济、大势）时命宫是不参与的——这是紫占跟命盘推演最大的结构区别之一。

## 太极切换规则

命宫是**默认太极点**——解盘时如果不做任何切换，一切都以命立太极。但只要问题对象不是本人，命宫就要让位给别的宫，变成另一种东西。参见 [[../断事方法/宫位立太极|宫位立太极]]。

- **以夫妻为太极**：本盘命宫变成配偶的父母宫（夫妻宫逆数一位到命宫）。同一颗星在同一个位置，不再讲"我的本命"，而是讲"配偶的父母和配偶的规则来源"。
- **以子女为太极**：本盘命宫变成子女的田宅宫。命宫里的星不再描述你自己，而是在描述"孩子家里的氛围、家底"。
- **以父母为太极**：本盘命宫变成父母的夫妻宫。你自己那些"一生总结的样子"，在父母的坐标系里是"父母的另一半怎么在夹缝里相处"的线索。

命宫之所以会成为别人盘上的**别的宫**，是因为命宫在任何太极下都是一个"自我轴上的点"，只是这个"自我"换了人。这条切换规则必须想清楚，不然你用命宫的星去断别人的事，等于用错了坐标系。

## 结构位置

命宫位于**身命轴（命—身）**的一端，另一端是身宫——中晚年显化位。两者共同构成"一生的主轴"。参见 [[身宫|身宫]]。

命宫的三方四正把它钉死在一张关系网里：

- **对宫：迁移宫**——命宫的结果位，你在外面怎么被别人看、你的运气如何落地
- **三合：财帛、官禄**——你的资源调用 + 你的行动能力
- **一六共宗：交友宫为里**——你真正的"命底"在你结交的众生里
- **命疾线**：命（里/灵魂）—疾厄（表/肉体）

结构上，命宫是**所有其他十一宫的起点**——其他宫都是从命宫逆时针数出来的位置。这是为什么翻星摇斗要反复讲立太极：命宫不动则其他宫都是"相对于本人的宫"，一旦把太极换到别处，整个十二宫的对象都换一遍。

## 高频症状 → 本宫反推路径

参见 [[../断事方法/关系反推|关系反推]]。以下症状常被反推回命宫的结构：

- **"我总觉得自己对不上号、像在扮演别人"** → 命宫被其他宫压过：典型是父母宫的化忌直冲命宫，或命宫本身空宫而借对宫。命宫没有自己的主张。
- **"我命里好像一直缺一样东西"** → 命宫里某颗核心星的原始星意"缺"——比如太阴代表"存"，太阴落陷坐命就是存不住；禄存坐命的人反而有囤积症状。
- **"别人都说我命很硬/很孤"** → 先别看命宫的煞，先看**交友宫**。交友宫煞重、不靠谱，才是命宫呈现"孤"的根源。一六共宗。
- **"我做什么都成不了事"** → 可能是命宫 OK 但官禄/夫妻（对宫）结果位承不住；也可能是命宫太软而疾厄宫过硬，肉体拖着灵魂跑。
- **"我一生的关键转折都跟某类人有关"** → 看交友宫的星性：这个"某类人"大概率就是你命宫的"根"在以人形显化。

## 常见星曜落本宫

- [[../星曜/主星/贪狼|贪狼]] 坐命——对"量"敏感，欲望 / 体积 / 规模感是本人的底层频率；落在哪个维度（身体、财、关系、玄学）要看其他星修饰。
- **太阴禄存坐命**——防御式囤积。一辈子在发"我要存、我要更多"的信号（见案例：[[../../sources/fanxingyaodou/articles/mid-2247484848|宿命的黑洞与防御式自闭]]）。
- **武曲坐命 / 身**——主行动得财；不能等钱从天上掉下来。
- **天机坐命 + 福德宫异常**——思虑过重、容易"带着原罪出生"，需要看命盘整体的福德—命链路（见案例：[[../../sources/fanxingyaodou/articles/mid-2247484731|双魂同体的少年]]）。
