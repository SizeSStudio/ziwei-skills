# _reference — 他派资料隔离区

这里放**不是**翻星摇斗主线的紫微资料：

- `全书/` — 紫微斗数全书、全集相关
- `中州派/` — 王亭之一派
- `飞星/` — 钦天门 / 陆斌兆系、飞星紫微斗数

## 放这里的规矩

1. **每个文件必须标注来源。** `ideology:` frontmatter 写学派名（不是"翻星摇斗"）。
2. **不要跨目录互相引用做论证。** `kb/星曜/主星/贪狼.md` 不能拿 `kb/_reference/全书/贪狼.md` 来支撑结论，只能在「参考」小节做差异对照。
3. **他派内容不出现在主线页的正文段落。** 只出现在明确划线的「参考」小节下。
4. **目录名前缀 `_`** 是给 Obsidian / 未来 skill retrieval 用的视觉信号："这里的东西不进入主线推理。"

## 为什么要隔离

未来的 `skills/ziwei-reading/` 检索 `kb/` 时会按 `ideology: 翻星摇斗` 过滤。隔离区的内容被自动排除，保证 skill 的输出有一致的声音。

如果要做"翻星摇斗 vs 全书 的差异辨析"类的对照页，写成一个明确的 compare 页（例如 `kb/对照/贪狼-翻星摇斗-vs-全书.md`），frontmatter `ideology: 对照`，而不是把两派内容塞进同一个主线页。
