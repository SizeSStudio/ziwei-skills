# 宫位立太极

## 核心原则

同一张盘、同一颗星，**以哪个宫为太极点，解释对象就换成谁**。默认以"命宫"立太极时讲的是本人，但一旦问题对象不是本人，就必须先把太极立到对应的宫，再重新读盘。

父母宫里的天机化忌，以命立太极 = 我和父母关系有波动；以**夫妻**立太极 = 夫妻宫的父母宫（也就是这张盘上的福德宫线）讲的是配偶的原生家庭；以**子女**立太极 = 孩子看祖辈的关系。同一颗星，同一个位置，**三种不同的解释对象**。

## 为什么

不立太极直接读盘，最常出的两种错：

1. **把自己的运气解释到别人头上。** 来访者问配偶事业，你却用命宫官禄宫的格局断，结论就和问题错位。
2. **把同一颗星讲死。** 不知道它会随太极切换换解释对象，遇到矛盾结果就解释不通。

立太极是让一张盘**生长成一整个关系网络**的机制。十二宫 × 十二个可能的太极点 = 144 种解释视角，这才是紫微斗数的信息容量。

## 操作步骤

1. **识别问题对象。** 来访者问的人是谁？自己、配偶、孩子、父母、同事、合伙人？
2. **选定太极宫位。**
   - 问自己 → 以命宫为太极
   - 问配偶 → 以夫妻宫为太极
   - 问孩子 → 以子女宫为太极
   - 问父母 → 以父母宫为太极
   - 问事业/单位 → 以官禄宫为太极
   - 问居住/家 → 以田宅宫为太极
   - 问朋友/下属 → 以仆役宫为太极
   - 问身体 → 以疾厄宫为太极
3. **重新数十二宫。** 以所选宫位作为"新的命宫"，顺逆序把原盘十二宫重新编号：夫妻宫看出去，夫妻的命是原盘的夫妻宫，夫妻的财帛是原盘的福德宫（因为夫妻宫逆数四位），依此类推。熟练之后不用真的重画，心算即可。
4. **把待解释的那颗星放回新宫位里。** 它在新结构下是"主星"还是"辅星"？在哪个新宫？
5. **按 [[星意还原]] 的方法重新投影。** 底层含义不变，但投影维度换了——同一颗贪狼在自己的命宫讲的是自己的欲望/体积，在"夫妻的命宫"讲的是配偶的欲望/体积。
6. **必要时做多点立太极交叉验证。** 问配偶事业，可以既从命宫立太极看夫妻宫、也从夫妻宫立太极看官禄宫，两次结论对齐说明判断稳。

## 典型触发信号

- 来访者问的不是自己。特别是配偶、孩子、父母、合伙人。
- 来访者问具体对象（公司/房子/项目），不是一般运气。
- 同一颗星在不同话题下得出矛盾结论——很可能是漏了立太极，在拿错的太极讲事。
- 遇到"按命宫读盘讲得通但跟来访者描述对不上"——通常是问题对象其实不是本人。

## 常见误用

- **不立太极直接用命宫。** 最常见的错误。尤其在问婚姻时，把自己命宫的夫妻宫读一遍就完事，没切到"夫妻的命宫"去看配偶自己的格局。
- **立太极但忘了重新数宫。** 把夫妻宫当作新命宫，但接下来还用原盘的"财帛宫"下结论——那个财帛是自己的，不是夫妻的。
- **多点立太极做出来的结论不交叉验证。** 如果两次立太极的结论打架，其中至少一个是错的，应该回头查，不是两个都写进去让读者自己挑。
- **把"以田宅为太极"等同于"看房子"。** 田宅宫既可以是房子的太极，也可以是家族整体、财富储存位。具体立的是哪个太极，取决于来访者实际问的是什么。

## 输出形态

"以 X 为太极点看 → Y 是新的命宫 → Z 星在新结构里位于……所以……"。一定要在输出里明确写出**以谁为太极**，让读者（或下游 skill 的验证层）能回查。
