# 追忌

## 核心原则

追忌解决的问题不是“这件事好不好”，而是：**这颗星、这个宫、这个物象到底在说什么**。

操作定义：如果 A 宫的宫干使 B 宫某颗星化忌，那么 A 宫就是这颗星在本问题里的**解释说明宫**。追忌就是顺着这条“忌”的关系，找到更深一层的说明来源。

追禄与追忌分工不同：

- **追禄**：追开始、原因、因果起点、触发链。
- **追忌**：追隐藏说明、收束点、终止点、具体指向。

## 为什么

单看一个宫或一颗星，常常只得到抽象语义。比如文曲可以是内容、文字、信息、曲折、内耗；如果不追忌，很难知道它在某一卦里到底指“考试知识点”“皮肤图案”“感情里的内容要求”，还是别的东西。

翻星摇斗文集里反复强调：不能只读单宫，要用其他宫来帮助理解本宫。追忌就是其中一条四化链式读法。

## 操作步骤

1. **锁定待解释对象**  
   先确定哪颗星、哪一宫、哪一个物象“不够具体”。不要为了炫技无差别追忌。

2. **找化忌来源宫**  
   查哪一个宫的宫干使这颗星化忌。这个来源宫就是解释说明宫。

3. **读解释说明宫**  
   读取该宫的宫义、主星、辅煞、四化状态，把它作为“这颗星为什么这样表达”的说明层。

4. **必要时再追一层**  
   如果解释说明宫仍然抽象，可以继续追下一层忌。每一层都必须能让问题更具体，否则停止。

5. **无四化星不用硬追**  
   天府、天相、七杀等不参与常规四化的星，不能伪造追忌。需要时改用一六共宗、双宫同卦、对宫，或明确标注“此处无法用追忌”。

6. **回到现实校验**  
   输出时记录追忌链，并给出用户能检查的现实锚。追忌不是自洽文学，必须能落地。

## 典型触发信号

- 关键星意太宽：如文曲只读成“内容”还不够，需要知道是什么内容。
- 来因宫要展开整盘主线：来因四化给第一层，追忌/追禄补后续层。
- 阴宅、祖上、家族结构、隐性来源等问题：盘面明处不够，需要看隐藏说明宫。
- 紫占里的复杂物象或复杂事件：三层卦只能定主故事，具体对象要靠忌链细化。
- 同一星在不同语境中可能完全换义：如考试卦里的疾厄宫不按疾病读，而按考试能力与知识掌握读。

## 常见误用

- **把追忌当追禄**：追禄看因果开始，追忌看解释说明。两者不能混。
- **把化忌直接当坏**：化忌是收束、藏、终止、点亮暗处，不等于坏。
- **无限追链**：文集里有“无限追忌”的说法，但实战必须在解释充分时停止。
- **套用追禄的顺逆框架**：追忌语料没有给出追禄那种“顺为凡、逆为仙”的框架，不能挪用。
- **事件未触发就硬断**：有些追忌结构要等现实事件激活，未激活时只是一条潜在说明线。

## 输出格式

```text
待解释对象：B 宫某星/某物象
追忌来源：A 宫宫干使该星化忌
解释说明：A 宫宫义 + 星情说明 B 宫该星的具体含义
链路：B 星 ←忌— A 宫（必要时再追）
现实锚：用户可验证的现象
```
