# 关系反推

## 核心原则

不是所有解盘都从"星盘长什么样"出发。翻星摇斗的**典型入口**是反过来：**从来访者口述的现实关系症状，倒推盘面上应该存在哪一组结构问题**，然后再回盘面验证。

来访者先说"我父母永远在吵架"——这是现实症状。反推：父母宫应该有**对立/冲动/过度主张**类的星或四化；父母宫三方四正里应当能看到**把这个矛盾循环供起来**的结构；父母的夫妻宫（以父母为太极立）应当能解释双方的匹配模式。**然后**回盘面看是不是真这样。是 → 判断成立；不是 → 重新找入口。

## 为什么

单靠"从盘面读过去"的断法，在一张信息量巨大的紫微盘面前会被淹没：十二宫 × 主辅煞星 × 四化 × 会合 → 可讲的东西太多，你不知道挑哪句讲。

而来访者的**现实问题是一个天然的压缩指针**——它直接指向盘面里真正"活着"的那组结构。翻星摇斗大量文章都是这个路径：先用两三句话抓住来访者的问题核心，然后只盯盘面上与此相关的结构讲，其他部分不浪费笔墨。

这也是为什么翻星摇斗的案例可读性高——它不是在炫技，它在解决一个被提问的问题。

## 操作步骤

1. **抓问题核心句。** 来访者描述一堆背景后，通常会有一两句话是真正的问题核心（"他一谈钱就翻脸""她根本不想生孩子""我一到晚上就睡不着"）。把它单独拎出来。
2. **把核心句翻译成"关系结构词"。** 不要用星曜名或宫位名，用抽象的关系结构：
   - "翻脸" → 断裂 / 对冲 / 冲动
   - "不想生" → 回避 / 空缺 / 封闭
   - "睡不着" → 亢进 / 过载 / 不安定
3. **推理：什么样的盘面结构会产生这个关系结构？**
   - 断裂 → 擎羊/陀罗/化忌 冲着相关宫
   - 回避 → 空宫 + 煞 / 天空地劫 + 相关宫
   - 亢进 → 火星铃星 / 化权过重 / 疾厄宫某类组合
4. **确定对应宫位。** 用 [[宫位立太极]] 确定问题对象的太极点，再找该太极下哪一宫承载这个结构。
5. **回盘面验证。** 真的去盘上看刚才推的那组结构在不在。三种结果：
   - 在且明显 → 判断站得住，往下展开讲
   - 在但弱 / 还要辅星辅证 → 把细节说清楚，不要硬拔
   - 不在 → 入口选错了，回到第一步重新抓核心句
6. **落到 [[现实校验]]。** 说一个能被来访者在自己生活里具体核对的事件作为收口。

## 典型触发信号

- 来访者主动开口描述一段现实问题/关系困局
- 来访者带着一个具体的"对方"来问（家人/伴侣/同事）
- 来访者的问题不是玄学问题，而是一段**活着的纠结**（睡不好、戒不掉、谈不成）
- 盘面本身信息量太大，不知道从哪讲起——这时候反推是天然的压缩器

## 常见误用

- **现实症状被直接映射到传统口诀上。** 听到"父母吵架"立刻往"父母宫煞重"背，没做结构翻译也没验证。
- **核心句抓错。** 来访者说了十分钟背景，你抓了个无关细节当入口，后面全跑偏。翻星摇斗语料里作者反复强调"问到第五个问题"——核心句常常不是第一句话。
- **反推到的结构在盘上不成立，硬讲。** 是这一步的最大失败模式，本质上是在迁就自己的预判而不是迁就盘面。盘面不支持就回第一步重选入口。
- **只做反推不回盘验证。** 反推是一个假设生成器，不是结论。不回盘验证就和心理咨询/算命口嗨没区别。

## 输出形态

"你说 X → 这类困扰通常对应 Y 类结构 → 看盘面上 Z 宫的 …… → 验证一下：你是否还在 W 事件里也见过这个模式？"——入口、反推、验证、收口一条链。
