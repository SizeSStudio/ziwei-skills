# 星意还原

## 核心原则

不接受传统给星的标签（"桃花星""财星""煞星"），**把每颗星先退回到它最底层的物理/数理含义**，再根据所问事情的维度把这个底层含义**投影**成具体表达。

贪狼不是"桃花星"。贪狼是**体积/大小的变化**。当问的是感情时，"欲望膨胀"是它在情欲维度上的投影；当问的是身材时，"肉的多少"是它在身体维度上的投影；当问的是房子时，"面积大小"是它在空间维度上的投影。

## 为什么

传统标签是某个维度投影的固化版本。记住固化版本，在那个维度上也许能断事，一换维度就抓瞎。把星退回到底层含义，可以迁移：

- 遇到没在书上读过的组合也能推出来
- 遇到"按书上格局说应该怎样但人不是那样"的反例能解释
- 解盘时同一颗星跨维度结论可以互相验证（都指向底层含义）

这也是翻星摇斗反复提"紫微斗数的数理性质"的原因——它追求的是一个**数学意义上可迁移**的星意体系，不是一本词典。

## 操作步骤

1. **拿到要解释的星。** 以及它所在的宫、会合的星、四化状态。
2. **退回底层。** 把这颗星的"原始星意"写出来。可以是：
   - 几何量（长度/面积/体积/方向/偏斜）
   - 运动/状态（膨胀/收缩/流动/停滞/偏斜/对齐）
   - 能量流向（输入/输出/消耗/储存）
   - 数理性质（多少/快慢/正反）
3. **确定投影维度。** 来访者问的是什么维度的事？
   - 身体 → 骨/肉/皮/脏器
   - 情感 → 欲望强度/方向
   - 物质 → 金钱/空间/物品
   - 关系 → 亲密度/支配度/连接
   - 时间 → 速度/持续/节奏
4. **把底层含义投到那个维度上。** 体积 + 身体 = 肉的多少；体积 + 感情 = 欲望膨胀；体积 + 物质 = 大小/多少。
5. **叠加其他星做修饰。** 看会合的辅星煞星各自的底层含义，它们的叠加会改变投影结果。贪狼（体积）+ 文昌（偏斜）= 体积歪了 → 在身体维度上就是粉身碎骨（大肉塔倒了）。
6. **检查。** 投影出的具体表达要能在现实层面看得见摸得着，不能还停留在抽象。

## 典型触发信号

- 遇到一颗不在经常用的星，需要从头推它的作用
- 遇到一个组合"按书上说应该怎样但当事人不是那样"
- 要跨维度（比如从身材推欲望，从房屋推情感）做联动判断
- 要解释一个"为什么这个格局一般说是吉/凶但这里反过来了"的反例

## 常见误用

- **退回得不够底层。** 把贪狼退到"欲望"就停——那还是某个维度的投影。应该继续退到"体积变化"。
- **投影维度选错。** 来访者在问婚姻，却把贪狼投到身材上——看起来讲得很头头是道但跟问题无关。
- **混入传统结论做支撑。** 写"贪狼体积 + 文昌偏斜 = 粉身碎骨"时不要加"按照《紫微斗数全书》贪狼文昌主……"来背书，那破坏了这一步的纯度。
- **忘了辅煞星也要还原。** 主星还原了，辅煞星还用标签（"文昌是文星""擎羊是煞"），组合结论就接不起来。

## 输出形态

一段简短结论 + 一张能在心里想象的画面。案例里高频出现"大家不妨在脑子里想象一个画面：……"——这是星意还原做到位的语感。能出画面说明底层含义和投影维度都接上了。
