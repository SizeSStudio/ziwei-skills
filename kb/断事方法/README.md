# 断事方法

这是本 KB 里最重要的部分——**原始紫微学派的可操作方法动作**。如果星曜/宫位/四化是字典，这里就是语法：先用三条上位公理限定读盘边界，再用五个核心动作落地，四化链动作负责深读扩展。

这些方法**既用于命盘推演（ziwei-natal），也用于紫占（ziwei-zhanbu）**——两个 skill 都把这个目录当作主干。紫占专属的起卦/三层卦/同音卦/十二相等技术细节在 [[../紫占方法/README|紫占方法]] 目录里，不要和这里的通用方法混。

## 三条上位公理

这三页不是新增「口诀」，而是读盘前必须先立住的系统模型：

- [[命盘惯性]] — 命盘呈现过去惯性和潜力，不是固定未来。所有命盘判断都应写成「当前合力 / 可调整分力」。
- [[宫位关系]] — 十二宫不是孤立格子，要用对宫、一六共宗、三方四正和四化链看系统投影。
- [[宫星四化合力]] — 宫、星、四化、小星和宫位关系要合起来求方向，不能拆成标签罗列。

## 五个动作（按实战里的典型顺序）

```
[提问进来]
      │
      ▼
┌─────────────────────┐
│  1. 关系反推          │   来访者只给了现实症状 → 反推到盘面哪组结构有问题
└────────┬────────────┘
         ▼
┌─────────────────────┐
│  2. 宫位立太极        │   问题对象 → 选对太极点 → 同一颗星换解释对象
└────────┬────────────┘
         ▼
┌─────────────────────┐
│  3. 星意还原          │   退回星的原始含义 → 按事情维度投影出具体表达
└────────┬────────────┘
         ▼
┌─────────────────────┐
│  4. 正向应卦          │   判断星组合和事的性质是否对号，对号=吉，不对=凶
└────────┬────────────┘
         ▼
┌─────────────────────┐
│  5. 现实校验          │   回到可验证的生活事件，判断站不站得住
└─────────────────────┘
```

顺序不是死的。有的推理是命盘直读 → 落到现实；有的是从现实回推盘面。但这五个动作基本覆盖了原始紫微语料里绝大多数推理链。三条上位公理负责防止方向错，五个动作负责把判断跑完。

**紫占语境里常用顺序**：起卦（见 [[../紫占方法/起卦流程]]）→ 星意还原 + 正向应卦 → 宫位立太极（天/人卦选择）→ 追忌细化对象 / 追禄定应期 → 现实校验。

**命盘推演语境里常用顺序**：命盘惯性定边界 → 关系反推 → 宫位立太极 + 宫位关系 → 星意还原 → 宫星四化合力 → 来因宫/追忌补主线 → 正向应卦/现实校验。

## 四化链扩展动作

- [[追忌]] — 忌串联 / 解释说明宫。用于“这颗星、这个宫、这个物象到底在说什么”，命盘与紫占都可用。
- [[../紫占方法/追禄|追禄]] — 禄链。用于追原因、开始、触发条件和应期；主要服务紫占，命盘里只保守使用。

## 各页

### 起源自翻星摇斗语料
- [[命盘惯性]] — 命盘是过去惯性和潜力，不是固定未来。命盘 skill 必须先读这一页，避免宿命式输出。
- [[宫位关系]] — 对宫、一六共宗、三方四正、四化链构成宫位关系网，是改命与关系反推的底层模型。
- [[宫星四化合力]] — 把宫、星、四化、小星和宫位关系整合成合力方向，连接 [[../格局/君臣佐使|君臣佐使]]。
- [[星意还原]] — 退回原始含义、按维度投影。最常被单独使用。
- [[宫位立太极]] — 按问题对象切太极点。漏这一步最容易把"自己"的运解释到"配偶"头上。
- [[追忌]] — 通过化忌来源宫解释某颗星/某件事的具体含义。文集里用于文曲、阴宅、马斯克盘、考试卦等多个案例。
- [[关系反推]] — 从现实关系症状倒推盘面。翻星摇斗最典型的入口。
- [[现实校验]] — 任何结论都要能被生活事件回证。区分原始紫微和普通玄学口嗨的关键。

### 起源自紫占方法论语料
- [[正向应卦]] — 同样的星组合随事的性质切换吉凶，"对口 = 吉，不对 = 凶"。卖空集装箱案是典型教材。

## 写作约定

每页固定六节：

1. **核心原则** — 一两句话能讲清的底层主张。
2. **为什么** — 不这么做会出什么错。
3. **操作步骤** — 可以一步一步跑的流程。这是未来 skill 直接执行的内容。
4. **典型触发信号** — 看到什么样的输入应该启动这个动作。
5. **常见误用** — 容易搞错的地方。
6. **支撑文章** — 从 `sources/` 里挑的典型案例，wikilink。
