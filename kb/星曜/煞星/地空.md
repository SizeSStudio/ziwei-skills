# 地空

> **原始星意：多——凸起来、多出来、多余、水分。**
> **正名要点：传统视为"煞"——翻星摇斗看到的是"什么才是真正属于我们的"。地空让你重新审查自己的福报边界。**

## 原始星意

地空属水。底层含义是**多出来的、多余的**——和地劫（缺 / 凹下去）正好相反：**地空是小土包，凸起来的、多了一块的**。名字叫"地空"容易让人误以为是"平地 / 空无"，但图形上它是凸起，意向上它是"多"。

地空 / 地劫是一个组合，有相同部分、也有相反部分：
- **相同**（作为空劫共有）：另类、独特、偏门。
- **相反**：地劫是缺，地空是多。

地空属水，多出来的幅度在**金水位比较大，木火位比较小**——同一颗地空，落在不同五行宫位里，"多出来的量"有差别。

在紫占实战中，地空通常指**"水分"**——我们说一个人"太水"，就是用地空来表达这个意向。夸大、吹嘘、假象、虚高的部分，都归地空。

## 多维表达

| 维度 | 投影结果 | 例子 |
|------|---------|------|
| 物象 | 凸起、多余、小土包 | 多出来的一块 |
| 物质 | 多出来的钱、财 | 中奖、暴富、意外收入 |
| 社交评价 | 水分 | "这个大师太水"、"这个人太水" |
| 认知 | 夸大、吹嘘、虚高 | 考试蒙对几题、发挥超常 |
| 关系 | 过高的要求 / 期待 | 对对象开出超出自己福报的条件 |
| 机会 | 福报接不住的好事 | 看见了但抓不住的机会 |

## 物象表现（紫占视角）

紫占中，地空的原始星意还可以直接映射到具体物体上。以下是 [[../../紫占方法/物象化|物象化]] 方法在本星上的典型应用。

**紫占方法论把地空推到了整本书最高权重的位置**——这是相对翻星摇斗版本的又一个显著的**角色升级**，必须显式记下。作者原话（源文 2447 行）：

> "我认为地空这个星的重要度都已经可以提升到让紫微超其它易学体系的重要程度了，甚至都可以不夸张的说，如果把地空这个星用好，对于人类来说都会很重要。**因为这个星是在紫占中专门用于测量福报的重要指标。这个事或是这个物，你能不能得到他，有没有超出福报上限就是用这个星来衡量**。如果在生活中所有人类都可以活用地空，就不会有贪念产生，也不会出现自不量力的情况。"

配套规则（源文 2463 行）：

> **"想得到或将要得到超出福报之外的东西，1:6–8 的比例还，轮回平衡。"**

即**凡超出福报得到的一份，都要按 1:6–8 的倍数还回去**。所以紫占里看到地空的第一反应不应是"多了就是好"，而应是"超出福报的那一份迟早要还"。

五行位置对"多出来的幅度"有影响：**金位、水位地空幅度大（鼓包大、说话夸张）**，**木位、火位地空幅度小（鼓包小、说话不夸张）**（源文 2461 行）。

### 地空应象（作者原文条目）

源文 2451–2479 行给出地空的应象清单：

- (1)**小鼓包、凸起的东西**——馒头、山包、SUV / 轿车、天空 / 穹顶。"说多了、过分了"。
- (2)**多出来的那部分** = 不应该得到的东西，**应该得到而得不到**。
- (3)**衡量一件东西是否匹配**——哪里说多做多，地空就落在哪。
- (4)同样是"地空"，金水位幅度大，木火位幅度小（见上）。
- (5)**1:6–8 的倍还**（见上）。具体分事例：

> "感情，找老公，有地空，说明这个感情超出福报之外，看超出幅度，太多能不能在一起不一定，**最后一定分**。"（源文 2465 行）
>
> 财宫 + 地空 = 信用卡、借贷（源文 2467 行）。
>
> 事业 + 地空 = 想当公务员，即使当上，最后还是不能得到、会失去（源文 2469 行）。
>
> **溺爱 = 超出应该给的爱，多余了**（源文 2471 行）。

还有一条需要与地劫严格区分：**青春痘留疤** 不是地空，是**地劫**（源文 2451–2479 行对比栏）。地空是"多出来的那一块"（鼓包），地劫是"凹进去 / 缺下来的那一块"（坑）。两者不是对立，是**一对互补的体积修饰**——这也是紫占分清"过 / 不及"的主要轴。

### 小结

地空在紫占里要同时读三层：

1. **物象层** —— 鼓包、凸起、多出来的一块。
2. **福报层** —— 多出来的东西是不是超出了当事人的福报上限。
3. **应验层** —— 若超出，按 1:6–8 的倍还轮回平衡，钱、感情、事业、身体都会在未来某个点把多出来的那一份收回去。

紫占地空卦**不是一个单纯的"吉 / 凶"符号**，而是一个"**福报对照尺**"——问自己"这件事 / 物配得上吗？"才是它在现场的用法。

详见 [[../../../sources/紫占方法论|紫占方法论]] 源文 2441–2693 行。

## 为煞星正明（正名核心）

标题问的是**什么才是真正属于我们的**。地空的正名核心就在这一问上：它不是"夺走你的东西"，是"逼你看清哪些根本不属于你"。

1. **多和少都不好，一切刚刚好才是最好。** 翻星摇斗反对"多就是赚"的世俗直觉——多出来的东西，如果超过了你的认知和福报，就会流向别处。
2. **水分 = 实战中最常用的地空意向。** 行业里遇到"看起来厉害、其实水分大"的大师、人物、评价——全部用地空标注。地空不是让你否定对方的所有价值，是让你校准"该学的学，不该学的不学"。
3. **过高期待 = 夫妻宫地空的典型卦象。** 起恋爱卦时出现"紫微 + 贪狼 + 地空在夫妻宫"，代表对对方有过高的欲望和要求（一线城市、一米八、月薪几W、有房有车、顾家、无不良嗜好……）——**你想的人，你的福报跟不上，你们搭配不到一起**。
4. **暴富 = 福报接不住的风险。** 财帛宫 武曲贪狼 + 地空（再化禄）= 突然多了很多钱。但当金钱和你的认知不匹配时，**突然增加的钱总会流向别处**——多出你福报的地方。中了大奖的人后来过得不好，不是命运作弄，是"一下拔得太高"导致大手大脚的消费习惯回不去，最后坐吃山空。反过来，把大奖留一部分、大部分存定期、再拿去学习或还贷的人，给再多的钱他也 hold 得住。
5. **外相的考验。** 地空和地劫都是"外相的改变"——都是用来考验你能不能控制得住自己。控制住 = 多出来的是老天的奖励；控制不住 = 这笔钱变成对你的诅咒（欲使其灭亡，必使其疯狂）。
6. **让你重新审查自己。** 不止是钱——考试多考几分（不知道是蒙对的还是真实水平）、人生中看到但抓不住的机会（房子、黄金、比特币……）——地空让人**更深层地重新审查自己**，想清楚什么对自己来说才是最重要的，不要因为错失的幻想反复阻碍现在的自己。

地空和地劫一样：问题不是"有没有"，是"多在哪、为什么多、这些多出来的是不是你 hold 得住"。

## 在十二宫的落宫解读

- **命宫 / 身宫** — 本人自带"多 / 水分"的倾向——容易显得比实际强，也容易夸大自己；或承接了超出自身福报的事。
- **夫妻宫** — 对伴侣的期待过高 / 超出自己福报（典型卦例：紫贪地空在夫妻宫）。
- **财帛宫** — 突然多的钱（暴富 / 中奖 / 意外收入），但要看能否 hold 得住。
- **福德宫** — 思维里多出来的东西——容易想得比实际多、容易自我夸大。
- **迁移宫** — 在外遇到的夸大、水分、虚高的人和事。
- **交友宫** — 朋友里水分大的多、容易遇到"看似厉害实则虚高"的人。
- **官禄宫** — 事业上的虚高、评价超过实际水平的部分。

以其他宫立太极时按 [[../../断事方法/宫位立太极]] 重新推——"多出来的"对象随太极点切换。

## 典型组合

- **紫微 + 七杀 + 地空（在亥）= 比普通人厉害 + 水分大。**
  - 紫微 = 顶级；七杀 = 一条线 / 一个平面；紫杀 = 一条分界线；在亥 = 最底层。所以**紫杀在亥 = 最下面的一条线**——已经是底层分界。
  - 再 + 地空 = 比普通人要厉害，但有很大水分。实战意义：起卦看某位"大师"得到这个组合，该学的学，不该学的别全盘接受。
- **紫微 + 贪狼 + 地空（在夫妻宫）= 对对象过高的要求。** 见正名部分。福报跟不上则搭配不到一起。
- **武曲 + 贪狼 + 地空（在财帛宫，再化禄）= 突然暴富，但超出自己福报则流走。** 见正名部分。
- **地空 + 其他主星小星**：拼法跟地劫类似——先读出"多在哪个维度、多的是什么"，再看能否接住。
