# 天府

> **原始星意：房、范围——一个可以被划定的空间。**
> "财库"只是空间概念在财富维度上的投影，不是本质。

## 原始星意

天府属土，**没有任何四化**。文章明确说"所以我们会说天府是最稳定的"——四化缺席直接对应稳定性，这是天府最底层的结构属性。

天府的原始星意是**房子和范围**，即**空间**。凡是"法界上可以形成一个空间的意向"都归天府：一个实体房子是天府，同一个微信群也是天府。它既可以是超大的空间，也可以是小小的范围——"一花一世界，一叶一菩提"，心有多大，天府就有多大。

因为只是一个"空间"容器，**天府本身并不携带具体含义**——它是一个主语。就像说"这是我家"，家是干净的还是肮脏的、是极简的还是温馨的，要靠同宫的其他主星和小星填进来。"财库"只是这个空间在财富维度上的一个投影：空间可以放东西，放进去的恰好是钱，就成了库。

传统说"天府是财库"，翻星摇斗的修正是：**财库不是天府的本义，是空间概念投到财帛维度上的一个结果。** 换一个维度（心、群、界），它就换一种意向。

## 多维表达

天府是"范围"这个概念本身，不同维度上投影出不同的空间：

| 维度 | 投影结果 | 例子 |
|------|---------|------|
| 物理 | 房子、居所 | 家、房间、建筑 |
| 社群 | 群组、边界 | 微信群、朋友圈范围 |
| 财 | 财库 | 存钱的容器（"库"的意向） |
| 心 | 心境的容量 | "一花一世界"——心有多大天府多大 |
| 界域 | 三界划分 | 申宫紫府 = 天界；亥/子天府 = 地府；寅天府 = 人间界；丑 = 坟 |

在组合上有一条很特别的空间层级：**申宫紫府 = 天界（最高处 + 最高级）**；**寅宫天府 = 人间界**；**亥/子天府偶尔代表地府**（低处）；**丑宫 = 坟**（天地人三才中"地辟于丑"，是人与另外一个世界的交界处，"廉贞七杀，半路埋尸"即落此位）。

田宅宫本身也是空间，天府加田宅会**加重空间的含义**。

## 物象表现（紫占视角）

紫占中，天府的原始星意还可以直接映射到具体物体上。以下是 [[../../紫占方法/物象化|物象化]] 方法在本星上的典型应用。紫占方法论给天府的原始星意：**房子、空间、城府、包容**（源文 2373 行），并延伸为**一个世界、一个空间、甚至一个 qq 群**（2633 行）——"凤阁天府田宅" = 空间 / 固定资产（2633 行）。

### + 地劫（空间空 / 家空）

- **天府 + 地劫** = 腹中空空 / 脑子空 / 银行存款没 / 家空（源文 2375–2381 行）——空间里什么都没有。

### + 地空（鼓起来的空间）

- **天府 + 地空** = 鼓包 / 蒙古包 / 穹顶 / 蓝天（2635 行）——空间本身鼓起来，变成顶棚或穹顶。

### 小结

天府 = 空间本身。**加劫 = 空间里是空的**；**加空 = 空间鼓成穹顶**。天府无四化，所以紫占读天府的卦主要靠加的小星去定空间属性。天府在 1507 行也被列为"房子"卦的主力主星（与田宅 / 凤阁并列）。

详见 [[../../../sources/紫占方法论|紫占方法论]] 源文 2373–2635 行。

## 四化表现

天府**无四化**。这正是它"最稳定"的本义——它不参与禄权科忌的能量流动。在看盘时，天府更像是一个由周边星和四化去填充、去染色的"场"。

## 在十二宫的落宫解读

天府星系中其他七颗星在天府命盘里的排布是固定的，所以天府的解读很大程度上来自**整个星系如何铺开**：

- **命宫（天府）** — 本人的"空间感"。稳定、有容量、"我的空间我做主"。气质上接近"管"，即"官"——官字就是管字的来历。
- **夫妻宫（破军）** — 见「典型组合」。安稳的人会喜欢不安稳的人，是这个结构的核心洞察。
- **福德宫（贪狼）** — 脑子里的欲望。**申宫天府的福德在午，午贪狼无欲 → "天界"；寅宫天府的福德在辰，辰贪狼欲望很强 → "人间"。** 天府的两极分化就在这里，不能一概而论。
- **官禄宫（天相）** — 擅长"帮别人做事"。天相不论庙旺都是帮助意向，所以天府当公务员说法成立——稳定 + 愿意帮人。
- **交友宫（天梁）** — 天梁是支柱，交友是命宫根基，所以**天梁是天府的"定海神针"**。天梁只在巳、申、亥落陷，其他都庙旺，所以大多数天府众生缘厚、朋友靠得住——"什么人才能过上安稳的生活？朋友多的人。"
- **父母宫（太阴）** — 太阴为母星，父母宫太阴加重母亲或家中承担母亲角色那一位的分量。太阴旁的小星决定具体性质（如 加火 → 窝火）。
- **田宅宫（巨门）** — 巨门是门/通道，也代表嘴和内心想法。田宅宫的巨门让天府想要"盖过家里其他人"，"我才是老大，这个空间必须按我的模式运行"。天府的"官气"就从此来。
- **疾厄宫（七杀）** / **财帛宫（武曲）** 等由星系排布决定，文章未专门展开。

## 典型组合

- **天府 + 破军（在夫妻宫） = 稳定的人找不稳定的伴侣。** 天府的夫妻宫**必然是破军**（星系结构固定）。一个本身安稳、不变的人，在感情上反而会寻求突破——"一个外向一个内敛、一个性急一个沉稳"的互补结构。很多家庭都能看到这一对。作者特别点出：单宫论破军在夫妻宫"很不好"是脱离系统的讲法——在天府命盘里这是**必然配置**，不是凶兆。
- **紫府在申 = 天界。** 申在高处，紫微是"最高级"，申宫紫府 = 最高级的空间 = "上等人"。偶尔也用来指"天界"。
- **天府在亥 / 子 = 地府。** 低处的空间。
- **天府在寅 = 人间界。**
- **天府在丑 = 坟。** "地辟于丑"，人与另一个世界的交界。"廉贞七杀，半路埋尸"格局就在丑。
- **太阴与天府旁同样带火星**：太阴 + 火 = 窝火（性格上）；**天府 + 火 = 房间着火**（空间意向）。两者在紫占卦上差别很大，在命盘上近义——展示了"空间" vs "储存"的细微分野。

## 格局对照

- **廉贞七杀半路埋尸（丑宫）**：传统凶格。翻星摇斗修正：**丑 = 坟（人与另一个世界的交界）**，廉贞若在此化忌，容易出现类似意向。但作者明确强调"具体情况具体分析，不要害怕"——不是看到就等于事。
