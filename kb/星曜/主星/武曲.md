# 武曲

> **原始星意：财，硬，寡，平淡。属金，为金属和金属性。**
> "曲"不含文曲那种曲折复杂的意思，而是指向武力、军队、强硬。

## 原始星意

武曲**属金**，底层意向就是**钱财、硬的东西、金属**。和"文曲"的"曲"不一样——武曲里的"曲"不带曲折复杂的含义，而是指向**武力**，所以武曲也会代表军队、武力、强硬。

武曲的性质**纯粹单调**，就是金属和金属性而已。因此在身体上：**肺部**（属金，呼吸器官，疫情相关的肺病都走武曲）、**牙齿、骨头**（坚硬部位）都归武曲管。

2023 早期文章补一层"阴金"：所以武曲也有**冰冷感**。是**财帛主、正财星，主行动得财**——命宫或身宫武曲不能幻想钱财从天上掉下来，必须自己辛苦去赚，但赚得也多。这也是为什么武曲看起来"高冷、直来直往、很果断、心直无毒"。

但"**武曲不傻**"——天生财星没有一个傻的。武曲暗合**太阴**，看上去很直接不说废话，其实内心想法很多很复杂，正是这种复杂让他们在社会上打拼还不怎么会被骗。

## 多维表达

| 维度 | 投影结果 |
|------|---------|
| 物质 | 金属、硬物、坚硬部件 |
| 财 | 正财、行动得财、现金流掌控 |
| 身体 | 肺、牙齿、骨头 |
| 性格 | 刚强直接、冰冷、果断、不拐弯 |
| 行动 | 目的性强、效率高、阻力小 |

## 特殊格局：木压雷惊（武曲七杀在卯）

卯宫属**震卦**，震卦为雷、为一阳生，"跟打雷一样轰隆隆的，突然发生什么事情"。木压雷惊就是**金属性 + 木属性突然相撞**的意向——**突然发生一件硬碰硬的事情**。

具体是什么事，要结合卯宫单宫 + 双宫同卦（丑宫）+ 一六共宗 + 武曲化忌去看：

- **+ 铃星**（烦恼+垂吊物）→ 容易被东西砸到、骨折
- **+ 天机**（汽车、速度）→ 被车撞
- **+ 巨门** → 牙齿磕破
- 也有被雷劈、被电线杆劈到的走法

武曲七杀在卯和酉原始星意相同，但**卦位不同**：

- **卯（震卦）** → 强调**打的多激烈、多壮观**
- **酉（兑卦）** → 强调**损伤情况、哪里伤了**

身体位置也随之不同：卯=左腰腹（难找到金相关器官），酉=右胸（肺刚好在这）——所以酉宫的武曲七杀更容易应在肺上。

"**小星定星情，宫位定人事**"——这是原文里的原则。

## 物象表现（紫占视角）

紫占中，武曲的原始星意还可以直接映射到具体物体上。以下是 [[../../紫占方法/物象化|物象化]] 方法在本星上的典型应用。紫占方法论给武曲的原始星意：**钱 / 金属 / 硬东西**；身体则是**骨头、牙齿**（源文 2243 行），核心是"金"的力量。

### + 地劫（钱缺 / 骨缺）

- **武曲 + 地劫** = 钱窟窿 / 骨头或牙齿缺失（源文 2245–2249 行）。

### + 地空（钱膨胀 / 骨质增生）

- **武曲 + 地空** = 钱膨胀 / 发财后自我膨胀 / 投资上市股票杠杆 / 骨质增生 / 骨刺 / 牙龈肿（2503–2511 行）。
- **武曲 + 地空 + 铃星** = 钱烦恼增加（2509 行）——多出来的钱反而变成烦恼。

### + 右弼（钱转向）

- **武曲 + 右弼** = 钱转向（2731 行）——**好**向应在"改投资方向"，**结构性负面**应在"挪用公款"（同一动作在不同语境下对号/不对号）。

### + 火星（发光的金属）

- **武曲 + 火星** = 亮的金属 / 白色金属（自行车存车桩案，源文 223、1621–1625 行）。

### 小结

武曲 = 金属 + 钱 + 硬。**加劫 = 钱或骨头缺一块**；**加空 = 钱或骨头多一块**；**加弼 = 钱换方向**；**加火 = 金属发亮**。这四条基本能覆盖紫占里的"钱卦"主结构。

详见 [[../../../sources/紫占方法论|紫占方法论]] 源文 2243–2731 行。

## 四化表现

武曲是金钱通道本身，四化直接作用在这条通道上——**四化俱全**，最适合成组对照：

- **化禄（己干）**：通道打开、财落袋，金钱能收得到。金水位力量最大。
- **化权（庚干）**：通道被一对力顶住、堵上——钱"绷"在那走不动，目的性强但硬顶（作者亲身盘武曲化权落寅木位，"超级大的力"）。
- **化科（甲干）**：金被柔化、蓄满——亏空被小旋风慢慢回填、缓和（对照化忌的"卷走"，化科是"回流补亏"）。水木位力量最大。
- **化忌（壬干）**：通道被掐断——金水位是"被卷走 1500 万"级的硬算子，午宫火位则只卷 10%、给点小钱消灾。同一化忌，地支差一个数量级（见 [[../../四化/化忌|化忌]]）。
- 此外，化忌也可当"碰撞"武曲固执抓取点的手段（"用四化去碰撞就好"）；"木压雷惊"分析里也要对武曲化忌去看突发事件的具体面貌。

## 在十二宫的落宫解读

以武曲在命的架构：

- **命宫** — 刚强直接、阴金冰冷、果断、心直无毒。眉毛间距比较短的人里不少是武曲。**奋斗欲望强、容易成就孤寡气**。
- **父母宫（太阳）** — "**向上管理**"——对更高位的人憧憬、热情。武曲直来直往、能干，领导赏识。但"**媚上者必欺下**"这个心理在武曲身上同样成立，对弱者"不欺负但也不在意"（会觉得那样做掉格局）。2023 版补：太阳暗合天府——对"认定为长辈"的人才好，不是对所有长辈都好。
- **兄弟宫（天同）** — 天同是感悟感受，兄弟宫同时是现金流位置。武曲把人当伙伴就会很用心，自己是兄弟姐妹里**最强硬的那个**（反衬其他人更柔和）。对朋友要求不高，"能成长就行"。对现金流的变化**感知敏锐**——容易得到正反馈，所以更爱赚钱。2023 版补：天同暗合贪狼，放大武曲对金钱的欲望。
- **财帛宫（廉贞）** — 廉贞是抓取的力度。庙旺廉贞 = 对资源抓取紧、**精细化掌控**——这就是武曲"**擅长炒股、理财**"的结构来源。落陷则对金钱无所谓。2023 版补：**利益点复杂**，武曲喜欢挑战难题，从困难处赚钱有成就感，容易成为**工作狂魔**（与破军爱砸成就做对比：武曲看着钱增长很开心，破军喜欢砸掉享受破坏）。
- **官禄宫（紫微）** — 夫妻宫是空宫，**要借官禄的紫微到夫妻宫**，所以武曲的**生活重心更多放在事业行动上，以行动力为第一**。没事干就全身难受，很多武曲是卷王。"事业武曲入命的人很多时候并不需要太担心自己的感情，因为**你的决胜点在赚钱上，而不是浪费时间搞感情**"。2023 版补：紫微在官禄让武曲有领导天赋、强势、做事容易无情，**孤寡气**在此强化，容易成独狼。
- **田宅宫（天机）** — 田宅是心灵、灵魂、最安全的地方。天机是"没那么重要、可以改变的"——所以武曲的关键性格是**可改变性**："**江山易改本性难移，但武曲可以为了达到目的改变自己的底层思想**"。为达目标不择手段的性格极其有魅力。武曲容易在这条路上**工具化**。2023 版补：断舍离对武曲很容易，不看重所谓"重要物品"——为钱都可无所谓。
- **夫妻宫（空宫）**（2023 版） — 借对宫官禄的紫微罩着，所以武曲对配偶要求高（紫微是高贵帝星）；加上性格冷硬和对钱的追求，"**当孤寡是常事**"。但不等于没桃花——有钱、直接、常独处还不暧昧的人不缺追求者，问题卡在性格。

## 典型组合

- **武曲 + 七杀（卯/酉）= 木压雷惊** — 见上"特殊格局"一节。金+震（或金+兑）突然相撞的意向，具体事件由同宫小星决定。
- **武曲 暗合 太阴** — 看着直，其实心里计划很多。2023 版补的是武曲不傻的结构性来源。
- **武曲 + 天同（兄弟宫架构中）** — 对现金流感知敏锐，正反馈驱动武曲更爱赚钱。天同的心软处也让武曲对朋友柔和。
