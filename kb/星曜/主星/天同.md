# 天同

> **原始星意：福，灵，魂，享受，听，悟，感受。**
> 天同是一个"超维度的星"，代表一个人的感受感悟、内心、灵魂缘分——懂了天同你就懂了人类。

## 原始星意

天同**主水**，原始星意是七个字的集合：**福、灵、魂、享受、听、悟、感受**。在语料里，天同被称为"**超维度的星**"——它代表**一个人的感受感悟、内心、灵魂缘分**，并不是一个普通意义上"管什么事"的星。

作者把命盘中的三魂结构这样对齐：**命宫 = 灵魂/气运上的我；福德宫 = 人魂上的我；田宅宫 = 天魂上的我**（天魂储存全部记忆，每次轮回都带着走）——而**天同代表你的主魂**。这是翻星摇斗给天同的一个特殊位置。

天同在金、水和部分木宫位都是庙旺的，在火位都是落陷的。

- **庙旺** = 感悟感应的能力在线。
- **落陷** = **无感**——"没有感觉是一个很恐怖的事情"。我们形容一个堕落的人"行尸走肉、得过且过、自甘堕落"，其中很多就是天同的问题；现代科学讲的多巴胺、内啡肽没管理好、**兴奋阈值太高、什么都提不起劲**，在天同这里都有对应。

语料里一句关键话：**"懂得了天同，你就懂得了人类。"**——翻星摇斗把"缘分→感觉→行为→当下的你"这条因果链全部挂在天同上。

## 多维表达

| 维度 | 投影结果 |
|------|---------|
| 灵魂 | 主魂、缘分、感悟感应 |
| 情感 | 感受、内心、感触 |
| 感官 | 听、悟、享受 |
| 身体 | 瞳孔（同音卦）、肾水 *（据 紫微 页语料）* |
| 状态 | 懒洋洋、享乐、初生小孩感 |

庙旺↔无感落陷是最重要的两极。

## 物象表现（紫占视角）

紫占中，天同的原始星意还可以直接映射到具体物体上。以下是 [[../../紫占方法/物象化|物象化]] 方法在本星上的典型应用。紫占方法论给天同的原始星意：**心 / 小孩 / 感知 / 认同 / 悟 / 想法 / 缘分 / 希望 / 渴望**（源文 2251、2525 行），并含**瞳孔**这一同音/物象延伸（2251 行）。

### + 地劫（感知不到 / 希望空）

- **天同 + 地劫** = 感知不到 / 无眼缘 / 上课不走心 / 感悟佛道（空） / 希望空 / 谈合同不认可（源文 2253–2259 行）——"心里那一块被挖掉"。
- **天同 + 太阴 陷**（午宫）= 感受不到什么东西（369 行）。

### + 地空（想多 / 妄想）

- **天同 + 地空** = 妄想 / 想多 / 彩民（2525–2531 行）——"心"鼓包，超出现实地想象。
- **天同 + 天喜 + 地空** = 上天厚赐运 / 走完就惨（2533 行）——快乐鼓包，落差极大。

### + 火星 / 铃星（冒蒸气 / 不满）

- **天同 + 火星**（酉宫）= 冒蒸气的烟囱（245 行）——心在冒热气。
- **天同 + 铃星 + 田宅宫** = 对房子不满意（1535 行）——心里对那件事有烦恼。

### 小结

天同 = 心的状态。**加劫 = 感觉不到 / 走空**；**加空 = 想多 / 妄想**；**加火 = 心在冒热气**；**加铃 = 心里有烦**。紫占里用来看"有没有感觉、认不认可、喜不喜欢"的卦，天同所在位置是主要观测点。

详见 [[../../../sources/紫占方法论|紫占方法论]] 源文 2251–2533 行。

## 四化表现

天同是"感受"本身，四化调节的是**感受的开合**（禄丙 / 权丁 / 忌庚，**无化科**）：

- **化禄（丙干）**：感受 / 享受被放大——福气、敏感度、舒适感拉满；但放大的是当前感受，若当前是"身体不适的感受"，化禄就是把不适也放大。
- **化权（丁干）**：给"感受"加一对力——享受被绷住、被要求"必须舒服 / 必须扛住"，懒散被顶成硬撑。
- **化忌（庚干）**：终止当前感受状态——麻木、感受被切断（"瞳孔 / 肾水"的同音意向在此最明显：看不清、水路堵）；但落陷无感的天同化忌反而被掀翻出感觉来。金水位是硬算子。
- （化科 不入天同，不需要讲。）

## 在十二宫的落宫解读

以天同在命的架构（紫微在交友宫）为基准：

- **交友宫（紫微）** — **对天同来说交友宫是最重要的位置**。所有感受感悟里**缘分永远是最重要的**——交友就是我们的众生缘分。为什么你看到一个人就选择相信？是由缘分决定的。所以**紫微的好坏直接决定天同的格局**。作者用一句话总结："**到底是要怎样的一个家庭才能培养出一个不懂事的孩子？就是这个人被挨打得不够，所以才能在社会后依然如此天真——这是缘分决定的。**"
- **子女宫（廉贞）** — 廉贞是抓取，投到子女宫是两个极端：极度抓取或极度放手。作者把"内在小孩疗愈"挂在这里——**每个人究其根本都是孩子，只是喜欢装大人**，要成长就要接受自己是孩子这件事。孩子对所拥有的东西会有占有欲，这就是这颗廉贞。若旁边是桃花星且抓取力度大，会有暧昧。
- **父母宫（武曲）** — 父母比较刚强，天同在父母面前**比较无力**。武曲能抗事，会把家里的事都做了——所以**很多天同比较懒**，要怪父母什么都给做了；父母会潜意识地支配天同按他们的想法行事。作者的现实观察：天同里出有钱人概率蛮高，因为"**有灵气、有感悟、同时父母还比较强**"一般出生在经济条件不差的家庭。
- **福德宫（太阳）** — 太阳庙旺在福德宫 = **本自具足**的状态：觉得圆满、什么都有、做事有别人帮——乐观、阳光、乐于奉献、感恩。反派被主角嘴遁儿歌治愈，其实就是**天同的光芒疗愈内心的麻木**，"我们说天同是小孩，而这天同的性质也极其疗愈"。福德宫=大脑思维。太阳落陷意味着没希望没光芒，但落陷只在金水宫——使太阳化忌就能解决问题，**那个宫位所预示的就是让天同重新感觉到美好的事情**。
- **官禄宫（天机）** — **天同很多时候确实不想做事**。一个人在精神世界探索得多了行动力就下降——思考可以比现实更快获得反馈。"**人生不能活得太清晰，想得太明白就容易变成废柴**"——因为你会觉得很多事情没必要做了。"**因为聪明，所以懒惰，所以想投机**；我们这个社会的所有科技都是懒人发明的。"

*其余宫位（夫妻/财帛/疾厄/迁移/田宅）在本篇语料中未专门展开，**留待补充**。*

## 典型组合

本页语料主要是从天同在命的架构逐宫解读，未专门列"天同 + 某星 = 某结果"的独立组合清单。可从其他页反查的几条线索：

- **天同 + 贪狼（暗合）** — 在 紫微/太阳 页里多次提到：天同暗合贪狼使相关宫位出现"想去玩/欲望"的倾向。
- **天同 + 火星** — 据 紫微 页语料：疾厄天同+火星 = 容易上火、性急。
- **天同 + 铃星** — 据 紫微 页语料：铃星是烦恼，疾厄天同+铃星 = 身体感觉到烦恼=犯病。
- **天同 + 天喜**（在天机财帛宫架构里） — "金钱上老是感觉到很高兴"。
