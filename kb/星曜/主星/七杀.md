# 七杀

> **原始星意：线和平面——对维度的抽象化。**
> "凶""将""肃杀"只是性格投影；底层是"一条线、一张面"这种几何抽象。

## 原始星意

七杀属金，**没有四化**（这一点与天府相同）。**原始星意是线和平面。**

> "看上去很抽象，但很好理解，其实就是线条和平面即是对维度的抽象化。"

作者给的两个图像化锚点：

1. **《三体》的二向箔**："将七杀武器化的一种现实呈现"——把三维拍成二维。
2. **梵高《星月夜》**：把三维二维化最后呈现在画布上。

这是翻星摇斗最不直觉的翻星之一：**七杀不是"杀戮""将星""威猛"，是几何意义上的线和面。** "凶""直""傲"这些都是"线"的延伸——一条直线的性格投影，就是"直来直往"。

因为七杀性质**很单纯**（就是线或面），所以它在命盘应断上经常"没有特别的意思，更多都是指性格很直接、直来直往、单线双线之类的，要搭配上小星才能玩得精彩"。它是**最依赖小星来染色**的主星。

另有一条关键推论：**七杀在所有宫位都可以当作庙旺来看，因为代表线段和平面是没有落陷的。**（"线就是线，面就是面"——几何本身无强弱。）落陷的概念在七杀身上不成立——这是对传统"七杀入庙 vs 落陷"讨论的直接否认。

## 多维表达

| 维度 | 投影 |
|------|------|
| 几何 | 线（1 维）、平面（2 维） |
| 性格 | 直接、直来直往 |
| 命盘 | 小星依附的载体（单贪双线纯粹地体现旁边星意） |
| 紫占 | 数字的曲线、图表、趋势线 |

线的变形全由小星合成：

- **右弼 → 拐弯的线**
- **文曲 → 曲线**
- **地劫 → 断掉的线**
- **地空 → 凸起来的线**

在紫占中七杀用得很多，因为现代社会充满图表（股价、趋势、K 线），**七杀就是"图表"本体**。

## 物象表现（紫占视角）

紫占中，七杀的原始星意还可以直接映射到具体物体上。以下是 [[../../紫占方法/物象化|物象化]] 方法在本星上的典型应用。紫占方法论给七杀的原始星意：**平面（玻璃、显示屏）、线**（源文 2217 行）——在紫占里七杀**极其高频**，因为现代社会全是图表 / 线 / 显示屏。

### + 地劫（断线 / 断裂）

- **七杀 + 地劫** = **断线卦**：财断 / 失业 / 事业崩盘 / 寿元断（源文 2219 行）。
- 股票下跌（2221 行）——趋势线向下断。
- 骨折——条状骨头、肋骨、四肢（2223 行）——身体版的"线断"。

### + 地空（鼓包的线 / 冒泡）

- **七杀 + 地空** = **鼓包的线**：股票涨 / 手机膜起泡 / 水面冒泡 / 水立方 / 指数上升（2519 行）。

### + 左辅（多条线 / 多屏）

- **七杀 + 左辅** = 多条线 / 多线程 / 多核 CPU / 多屏 / 三合板 / 脚踩几条船 / 夹心饼干（源文 2755–2759 行）——"线"的数量翻倍。

### + 右弼（换线 / 变心）

- **七杀 + 右弼** = 换工作 / 变心 / 思想转变（在一段稳定期之后）（2763–2765 行）——一条既有线转了方向。

### + 火星（发光的线）

- **七杀 + 火星** = 一条发光的线（闪电）（源文 269 行）。

### 小结

七杀 = 线 / 平面 / 图表。紫占里最常用的结构：**+ 劫 = 线断（财断 / 骨折 / 崩盘）**；**+ 空 = 线鼓起来（上涨 / 冒泡）**；**+ 辅 = 多线（多屏 / 多线程 / 劈腿）**；**+ 弼 = 换方向**；**+ 火 = 闪电**。K 线卦、股票卦、骨头卦、屏幕卦都从这里读。

详见 [[../../../sources/紫占方法论|紫占方法论]] 源文 269–2765 行。

## 四化表现

**七杀无四化。** 与天府一起，是星系中"不参与四化流动"的两颗星——这是七杀"单纯"和"稳定"的直接结构原因。

## 在十二宫的落宫解读

以七杀为太极时的星系排布：

- **命宫（七杀）** — 性格直接、直来直往。**迁移宫是天府** → 外面才是家 → 想往外跑；若天府旁的星不好则反过来变宅男宅女。
- **兄弟宫（天梁）** — 兄弟是七杀最重要的关系。喜欢靠谱、直爽的人，讲义气。"一个直来直往还没有朋友的七杀，那格局是相当差劲的。"
- **夫妻宫（天相）** — 天相是维护帮助。一方面七杀在感情上需要被照顾，另一方面**感情中容易有他人出现**（天相意向接近辅星）。作者原话："兄弟如手足，女人如衣服"——对七杀来说，伴侣要做他的兄弟而不是情人。
- **子女宫（巨门）** — 巨门是门，容易应在**生殖系统、生孩子**上；巨门也有"遮蔽"（巨大的门），所以七杀在子女宫容易**忽略别人感受、只顾自己、有口角**，对孩子容易变成大家长。
- **财帛宫（贪狼）** — 利益 + 欲望在一起。**"大多数七杀对自己想要的东西都会有比较强烈的追求。"** 贪狼是体积 → 体积越大欲望越大。
- **疾厄宫（太阴）** — 最重要的一条：**太阴对七杀来说决定了"细"还是"粗"。** 太阴庙旺 → 七杀细心，"心有猛虎细嗅蔷薇"；**太阴落陷 → 七杀真的就是横冲直撞、啥也不记得**。举例"七杀是黑社会老大"的格局，**要太阴庙旺且配十恶格才容易成**。太阴庙旺+好星 → 富贵。
- **迁移宫（天府）** — 见命宫条。七杀和天府永远对面相应，这是很特殊的一对——都无四化、都稳定，但天府要窝着，七杀要杀出去。
- **官禄宫（破军）** — 破军是突破。七杀行动上多创新，敢做别人不敢做的事；**成功与否跟众生善缘相关**。低谷期的七杀不要悲伤，有突破性，只是才华还没被发现。

## 典型组合

- **七杀 + 辅星（左辅 / 右弼）** — 双线程。例：事业宫七杀左辅 → 工作上双线 → 应在感情上就是脚踏两只船，应在子女上就是多个孩子。
- **七杀 + 右弼** — 拐弯的线。
- **七杀 + 文曲** — 曲线。
- **七杀 + 地劫** — 断掉的线。
- **七杀 + 地空** — 凸起来的线。
- **七杀 + 太阴（疾厄庙旺）** — 细腻、内敛；成"心有猛虎细嗅蔷薇"。黑社会老大格局的关键之一。
- **七杀 + 天府（对宫永恒固定）** — 稳定 + 稳定；一个窝着一个杀出去。

## 格局对照

- **七杀朝斗 / 七杀仰斗** 等传统格局文章未展开，略。
- **七杀无落陷**：翻星摇斗的格局级修正——**七杀在所有宫位都可当庙旺看**，因为"线"本身没有强弱。这推翻了传统"七杀入庙"讨论的很多分野。
- **黑社会老大格局**：七杀 + 疾厄太阴庙旺 + 十恶格——作者明确给出的组合要求。
