# 天梁

> **原始星意：柱子、支撑、受力的——"根、柱"。**
> 庙旺的天梁是"这个世界的基石 / 大众 / 基本盘"；落陷的天梁是"小众、靠不住、墙头草"。

## 原始星意

天梁属土，**原始星意是柱子、支撑**。凡是"贵人、法律、公共、政府"之类传统含义，其实**都是从"支撑"衍生出来的**。

翻星摇斗在天梁上有一个很硬的二元解释：

- **庙旺的天梁 = 大众的、基石的、撑得住的。** "这个世界的基石，是支撑这个世界的存在，是代表大众的存在。"
- **落陷的天梁（巳、申、亥三位）= 小众的、反其道而行的、撑不住、靠不住。** 作者特别说这"并不代表不好"——如果你要写小说、做新的东西，你就需要落陷的天梁，**"因为新鲜感就不是这个世界的基石，你其他世界的灵感。"**

"根正苗红"——说的就是庙旺天梁没有受损的人，三观与这个世界合；不是顽固，**是"基本盘"**。

另一条关键延伸：柱子 → **根脉** → **男性和父辈**的意向。天梁作为"荫星"的说法**只有在庙旺时才成立**；落陷的天梁"根本就靠不住是墙头草一般"。传统那种"见天梁就是贵人"的讲法被明确修正。

大众基石是随时代变化的——**"我们这个时代的天梁和二十年前的天梁就不是一样的，天梁就是永远跟大环境、大趋势一起的。"** 这是天梁解读最容易被忽略的时代性。

## 多维表达

| 维度 | 投影 |
|------|------|
| 结构 | 柱子、支撑物、承重件 |
| 社会 | 大众、主流、基本盘、公序良俗 |
| 组织 | 政府、法律、公共机构 |
| 家族 | 根脉、男性、父辈 |
| 荫 | 庙旺才算"荫"；落陷靠不住 |
| 方向 | 庙旺 → 主流；落陷 → 小众 / 反主流 / 写小说要用的"其他世界" |

天梁落陷在 **巳、申、亥** 三位；其他宫位皆庙旺。

## 物象表现（紫占视角）

紫占中，天梁的原始星意还可以直接映射到具体物体上。以下是 [[../../紫占方法/物象化|物象化]] 方法在本星上的典型应用。紫占方法论给天梁的原始星意：**支撑 / 支柱 / 主心骨 / 公司高管 / 法律规则 / 祖先**（源文 2263 行）；身体上是**手臂 / 棍状 / 四肢**（833、2415 行）——"柱"意向在紫占里常落到具体棍状物或四肢。

### + 地劫（支柱没了）

- **天梁 + 地劫** = 公司重要人物没了 / 家运支柱没 / 感情寄托没 / 战乱法律没（源文 2263–2273 行）。
- **寅宫四马地同梁 + 地劫** = "外表可以内心空"的**空竹卦**（2273 行）——筒状有外壁但内部中空。

### + 地空（管理过多 / 柱子过载）

- **天梁 + 地空** = 管理过多 / 承受过量 / 道德绑架 / 柱子过载房倒（2541 行）——柱子上鼓了一块、承压过量。

### + 左辅（多支柱）

- **天梁 + 左辅** = 多支柱 / 多个管事 / 多条腿 / 多生意 / 长辈多（2771–2781 行）。

### + 右弼（转行 / 柱子弯）

- **天梁 + 右弼** = 转行 / 柱子弯 / 依靠之人改变（2785–2801 行）。
- **天梁 + 右弼 + 陀罗** = **驼背**的最终态（2791、2793 行）——柱子弯 + 反复打转固定住。

### + 天姚 / 陀罗 / 火星（发亮的伞盖 / 建筑废料）

- **天梁 + 陀罗 + 火星** = 发亮的伞盖（乌云闪电案，265 行）。
- **天梁 + 天姚**（巳宫落陷）= 建筑废料漫天飞（265 行）——落陷天梁 + 美好小星，柱子散成碎块。

### 小结

天梁 = 柱子 / 支撑件。**加劫 = 柱子没了**；**加空 = 柱子鼓包 / 过载**；**加辅 = 多根柱子**；**加弼 = 柱子弯 / 换方向**。紫占里看"公司高管还在不在"、"家里主心骨在不在"、"四肢有没有事"都从这条线走。

详见 [[../../../sources/紫占方法论|紫占方法论]] 源文 265–2801 行。

## 四化表现

天梁是承重的支柱 / 根，四化作用在"承载"上。它**没有化忌**（支柱不被"终止"，只被加载 / 加固 / 缓固）——禄壬 / 权乙 / 科己：

- **化禄（壬干）**：承重 / 荫庇被放大——靠山更稳、贵人更多、能罩住的范围更大；庙旺的定海神针放大成更粗的柱，落陷的墙头草则被放大成更没准的晃。
- **化权（乙干）**：给"柱"加一对力——受力被绷紧，要扛的更重、被要求"必须撑住"，荫庇于是变成压在肩上的责任。木火位力量最大。
- **化科（己干）**：柱被柔化、蓄满——慢慢加固、回填亏空、把急难拖成缓济。天梁"逢凶化吉"的化解本义正落在化科的"延续 / 补救"上，但须在水木位才有力。
- （化忌 不入天梁，不需要讲。）

## 在十二宫的落宫解读

以天梁为太极（即天梁坐命时星系的排布，作者据此讲天梁的"法则"）：

- **命宫（天梁）** — 大众的基石、三观正、有"老黄牛"感。落陷则小众、飘浮、撑不住。"把自己当作父母了，自己就是顶梁柱，即使现在不是，未来也是。"
- **兄弟宫（天相）** — 对兄弟有帮助，热心肠。但"要自己先靠得住、眼里有活才去帮人，所以别怪老有人来麻烦你"。注意别当冤大头。
- **夫妻宫（巨门）** — 巨门是通道/嘴，夫妻宫就成了说话、吵架、**压制对方、争话语权**——所以"天梁老被说固执、不讲理"的来源就在这里。
- **子女宫（贪狼）** — 现代少有想要多孩子的，多表现在"**想要多小弟、有可以支配的存在**"；同时贪狼 = 欲望、天梁 = 男根，**搭配不好容易性瘾**，需注意。
- **财帛宫（太阴）** — 太阴是储存，所以天梁在钱上**倾向存钱、稳扎稳打、踏实过日子**。
- **疾厄宫（天府）** — 天府 = 空间 = 稳定。"对天梁来说最重要的就是稳定"——"政府是天梁"的说法成立，因为稳定是政权的追求。
- **交友宫（破军）** — **天梁对交友是无所谓的**，只要有人支持他。破军的态度：想改变别人让他们都来支持自己。恩怨分明。
- **父母宫（七杀）** — 七杀直接。"**天梁把自己当做父母了**，所以对父母宫的感觉是很奇怪的"——把自己视为顶梁柱，反把父母当需要自己罩的对象。

关于六亲：天梁的六亲宫位看上去都不太好——只有兄弟宫，是天梁"已经认定是自己人的，才会去帮忙"。其他宫位都带着"天梁想当那根柱子"的投影。

## 典型组合

- **天梁在巳 / 申 / 亥 = 落陷。** 小众、飘浮、不主流；但适合写小说、搞创新的人。
- **天梁（庙旺）+ 父母宫/田宅宫** = 靠得住的父母、踏实的家——这是大多数人希望的配置。
- **天梁（落陷）+ 感情位** = 找不踏实的人；"一个愿打一个愿挨，你就会比较喜欢那个类型的人"。
- **天梁 + 擎羊 / 陀罗 / 天刑（传统"刑忌夹印"方向）** — 文章没单独展开，但"天梁加煞改荫气"的思路在天相章中出现过，沿用同一逻辑。
- **天梁 + 贪狼（子女宫方向）** — 搭配不好容易性瘾。
