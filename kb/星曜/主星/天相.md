# 天相

> **原始星意：印、护、助——一个维护系统。**
> 传统吹天相吹过头；它的本质是"生态位里的维护者"，帮哪一边由生态决定。

## 原始星意

天相属木（本系列文章中明确给出属性；早期文章说属水，以较新的系列文为准），**原始星意为印、护、助**。

- **印**：印记、盖戳子——被人拿着用的印章。
- **护**：护士的那个"护"——**给你打针拿药是天相，给你端屎盆子的也是天相**。
- **助**：帮助、助力——你要什么我就给你什么。

作者明确说**传统上把天相吹过头了**。从原始星意看，**天相就是一个维护系统**。

> "我们用生态学的角度看整个社会，社会会需要各种各样的人，剥削人的、被剥削的、埋头苦干、刻苦硬干、为民请命、舍身求法的，各种人都有！天相在其中的生态位是维护者，有跟你说维护者就是为好的那一方维护吗？没有的！"

这是天相翻星的关键——**天相本身不自带"好人"属性**。它的善恶由它所维护的生态位决定：维护好领导伙伴就是好帮手，维护坏势力就变成"资本/帝国主义的走狗、汉奸之类的"。

天相还有一个结构性特征：**两夹是天梁和巨门**。两夹代表父母和兄弟姐妹，也就是领导和兄弟。**天相最受两夹影响**，因为"他没有主见呀"。传统"财荫夹印"就是在说两夹好 → 天相好；两夹烂 → 天相跟着烂。"人以类聚，物以群分"——天相就是这套逻辑里最清楚的例子。

## 多维表达

| 维度 | 投影 |
|------|------|
| 角色 | 助手、护工、维护者、执行者 |
| 身体 | 衣服、穿着、脸面 |
| 物 | 印章、证书、被盖章的东西 |
| 行动 | 维护、呵护、照顾、伺候 |
| 紫占同音 | 相片、相中、相好 |

关于衣服有个特别的意向：**天相在维护系统中对应"衣服"。落陷的天相不太喜欢穿衣服，穿的布料比较少，巴不得全露出来。**

## 物象表现（紫占视角）

紫占中，天相的原始星意还可以直接映射到具体物体上。以下是 [[../../紫占方法/物象化|物象化]] 方法在本星上的典型应用。紫占方法论给天相的原始星意：**衣食主、皮肤、相貌、呵护陪伴**（源文 2291 行）——延续命盘读的"护、助、印"，在紫占里**先落在衣、食、皮肤这三样具体物**上。

### + 地劫（缺衣 / 缺食 / 缺护）

- **天相 + 地劫** = 没衣服穿 / 吃不饱 / 脸上坑多（痘印） / 衣服有洞 / 奶酪 / 感情呵护不到位 / 军嫂（源文 2291–2299 行）。

### + 地空（吃太多 / 穿太厚 / 过度照顾）

- **天相 + 地空** = 吃太多 / 穿太多 / 羽绒服太厚 / 胸罩 / 过度照顾（2553–2565 行）——衣食鼓包 / 呵护过头。

### + 左辅（多呵护）

- **天相 + 左辅** = 呵护多 / 多人关爱 / 多种食物（2807 行）。

### + 右弼（换口味 / 换照顾对象）

- **天相 + 右弼** = 换口味 / 换衣服 / 换照顾对象（2815 行）。

### 小结

天相 = 衣 / 食 / 皮肤 / 呵护。**加劫 = 缺衣缺食**；**加空 = 吃穿过头**；**加辅 = 多份呵护**；**加弼 = 换一种呵护**。紫占里看"吃没吃饱、穿没穿好、被不被照顾"都走这条线。

详见 [[../../../sources/紫占方法论|紫占方法论]] 源文 2291–2815 行。

## 四化表现

天相**无四化**。与 [[天府|天府]]、[[七杀|七杀]] 一同，是星系里不参与禄权科忌流动的三颗星——这正是天相"印 / 护 / 助"始终作为**被动承接者**的结构原因：它自己不被点亮、也不被终止，而是去承接、盖印、帮衬周边那些被四化染色的星。所以看天相不要去等它自己的四化，要看**两夹（天梁、巨门）和环境被四化染成什么样**，天相就跟着维护成什么样——"财荫夹印 / 刑忌夹印"正是这条（见下〔格局对照〕）。

## 在十二宫的落宫解读

- **命宫（天相）** — 老好人、没主见、办事能力强、比较被动、爱面子。两夹（天梁、巨门）好坏直接决定格局好坏。
- **夫妻宫** — 感情需要别人帮助，或有人在帮助这段感情。**天相庙旺**：感情被呵护；**天相落陷**：感情得不到帮助、空虚，容易多情出轨。七杀坐命必配天相夫妻，故此条对七杀也适用。
  - 当"被照顾"的意向明显时，也可能落在**住院、身体不好**的意向上——古代老爷被下人伺候是同一个星意。
  - 天相庙旺 + 照顾人的意向 → 命主容易从事护士、护工等照顾职业。
- **官禄/在公职** — "帮忙"是天相最稳的表达，所以天相擅长执行岗、辅助岗。
- **身体与脸面** — 天相被煞星冲破容易**破相**（天相是"脸"的一种意向）。
- **其他应用** — 紫占中用到天相同音卦的场景很多（相中、相片、相好）。例：问别人有没有相中你，天相落陷一般是没相中。

关于天相与天府、七杀的星系结构：天相的福德宫是七杀、夫妻宫是贪狼——天相"福德宫杀破狼，内心力量也会很强，虽然比较软，没有主见，但任劳任怨"。夫妻宫的贪狼让**天相基本都是颜控**，尤其男天相，"是十四颗星里对感情最深的"，用情太深容易"当舔狗"。

## 典型组合

- **天相被煞冲破 → 破相。** 脸、外貌、形象受损；对宫破军是连动的。
- **天相 + 天梁、巨门两夹** — "财荫夹印"（吉）或"刑忌夹印"（凶）全看两夹星的好坏。天相本身没主见，被动吸收两夹的质量。
- **廉相 / 紫相 / 武相** — 叠加其他主星性质后，天相的"没主见"会被遮盖，性质更复杂难捉摸。
- **天相 + 破军（对宫）** — 永远互为对宫。**"破相"**直接从这里来：两边有一边被破相，命主就容易形象有亏。
- **天相 + 贪狼（夫妻）** — 天相颜控、用情太深，最难处理的就是感情。

## 格局对照

- **财荫夹印**：天相被天梁（荫）和禄类星夹 → 维护者背后有资源，格局成立。翻星摇斗修正：就是"两夹的质量决定天相的生态位质量"，不神秘。
- **刑忌夹印**：擎羊、陀罗或忌星夹天相 → 维护者背后的资源翻黑，天相跟着一起烂。本质仍是生态位逻辑。
