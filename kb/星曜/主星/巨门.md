# 巨门

> **原始星意：门，即通道。**
> "嘴"只是通道的一个具体投影；更重要的是它是**信息通道**。

## 原始星意

巨门属水，**原始星意是门——通道**。作者说"巨门的性质甚至都会有些无聊，因为我们每个人天天都见着，就是通道"。

通道的投影分两层：

1. **物理通道**：房门、车门、水管阀门——一切实体的门。
2. **抽象通道（人体）**：眼耳鼻舌身意是接受外界刺激的入口；皮肤毛孔是门；嘴鼻呼吸是门；大小便排泄也是门。**"这就是一个高度抽象化的门而已。"**

传统讲巨门就是一张嘴，容易说话惹事。翻星摇斗的修正是：**"嘴"只是门在人际交流维度上的投影，真正的本体是"通道"。** 说话只是"信息交换的一种形态"；更重要的是，巨门是**命盘上信息发送和接收的位置**。

> "命盘里无论在哪里，我们都把巨门当作那个人的嘴。" 但嘴只是其中一个意向，**巨门更根本的是"信息通道"**。

## 多维表达

| 维度 | 投影 |
|------|------|
| 物理 | 门、阀门、开口 |
| 身体 | 嘴、鼻、眼耳、毛孔、排泄口 |
| 交流 | 说话方式、爱不爱说话、说什么话 |
| 信息 | 能不能接到信息、能接多大量的信息 |
| 玄学 | 链接高维信息的通道（搞玄学的关键星） |

**巨门的口子越大，能接触的"旁边小星具象出来的那类信息"就越多。** 这是作者把巨门用于改命的核心机制。

## 物象表现（紫占视角）

紫占中，巨门的原始星意还可以直接映射到具体物体上。以下是 [[../../紫占方法/物象化|物象化]] 方法在本星上的典型应用。紫占方法论给巨门的原始星意：**门、嘴、说话、风 / 气**（源文 2303、1849、755 行）。结构性的读法：

> "可以理解成门，门关着里面东西你不知道，门开着你知道。"（源文 753–757 行）

所以紫占里看巨门的关键问题是**门是开着还是关着**。巨门在巳 = 陷 = "天门关"（源文 1485 行）。

### + 地劫（漏 / 筛子）

- **巨门 + 地劫** = 漏风 / 漏水 / 漏财 / 说漏嘴 / 说话不算数 / 小孩漏饭 / 筛子（源文 2305–2313 行）——门上有洞。

### + 地空（说大话 / 嘴上长泡）

- **巨门 + 地空** = 说大话 / 嘴上长泡 / 谈合作水分多（2627 行）——嘴鼓起来 / 话鼓过头。
- **巨门 + 地空 + 天姚** = 巧舌如簧（2623 行）。
- **巨门 + 地空 + 左辅** = 一个口冒出很多气泡（可乐案，1849 行）。

### + 左辅（多门）

- **巨门 + 左辅** = 几个门 / 多门课 / 太能言善辩 / 浑身长嘴 / 拉人吵架（2911 行）。

### + 右弼（改口）

- **巨门 + 右弼** = **改口**（源文 2309、2917 行）——**大律师卦**的核心结构。
- **巨门 + 右弼** 在签合同 / 恋爱场景里 = 话风一转的**改口卦**，对承诺型事务**极不利**（2917–2919 行）。

### 小结

巨门 = 通道 / 门 / 嘴。紫占里**先定门是开是关**，再看小星修饰：**+ 劫 = 门漏洞**；**+ 空 = 嘴上鼓包 / 说大话**；**+ 辅 = 多个门**；**+ 弼 = 改口**。

详见 [[../../../sources/紫占方法论|紫占方法论]] 源文 753–2919 行。

## 四化表现

承上：巨门管信息进出，**四化就是调节"哪些信息能进、进来之后怎么处理"**——这正是作者"调整巨门来改命"（"信息改变了我们就改变了"）的机制。巨门禄辛 / 权癸 / 忌丁，**无化科**：

- **化禄（辛干）**：通道 / 口被放大——信息流量、表达、是非的"量"一起放大；口才与口舌同源，放大的是当前进出量。
- **化权（癸干）**：给"门"加一对力——信息被把关、被绷住，嘴被要求"必须说 / 必须压住"，风气被强行规训。
- **化忌（丁干）**：终止当前信息状态——通道被堵死、口舌被切断、是非粘住走不开（典型"嘴上招祸 / 沟通断流"的落点）；但本就闭塞的反被掀翻出新通路。金水位是硬算子。
- （化科 不入巨门，不需要讲。）

## 在十二宫的落宫解读

作者以自己为例（巨门天同在丑宫兄弟宫，旁边带天刑、天哭、华盖）：

- **兄弟宫巨门 = 对朋友是话痨。** 巨门 + 天同都庙旺，会说很多走心的话。
- 加 **天刑**：对自己要求高、对人要求也高 → 说话容易刁钻。
- 加 **天哭**：低层次是悲伤（说话让人难受），高层次是慈悲（柔软语）。
- 加 **华盖**：与玄学/宗教相关。

更一般的宫位定位：

- **巨门的位置 = 信息发送的位置。** 爱不爱说话、输出的是什么话、输出给什么样的对象，都看巨门所在宫。
- **福德宫的巨门**（如太阴命）= 思考、想得多、憋着不说但脑子一直在转。
- **田宅宫的巨门**（如天府命）= 家中的"嘴"，内心的想法。
- **交友宫的巨门**（如破军命）= 交友的宽度取决于巨门庙旺；性格上想盖住别人。
- **夫妻宫的巨门**（如天梁命）= 说话、吵架、争话语权。

## 典型组合

- **巨门 + 天同（丑）** — 作者本人的例子，庙旺话痨，走心。
- **巨门 + 天刑** — 说话刁钻，对人严苛。
- **巨门 + 天哭** — 低层次：让人难受；高层次：慈悲柔软语。
- **巨门 + 华盖** — 玄学天赋的重要组合，因为"玄学本质上是能不能链接到高维信息，而通道就是巨门"。
- **巨门 + 桃花小星（按文意推）** — 通道对应"那类信息"，所以旁边接什么星，命主就容易被什么类信息喂养。

## 格局对照

- **信息茧房（非传统格局，作者引入的当代类比）**：抖音推送全是美女帅哥、或全是歌颂祖国——这就是巨门在被动接收什么类型的信息。**"我们可以主动选择发现美好事物，而忽略不好的事物。通过这种方法来改变我们的生活！"** 这是巨门改命法的起点。
