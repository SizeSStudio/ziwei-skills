# 太阴

> **原始星意：储存。水的总称，女性的总称。**
> "太阴为什么是财星，是我们生命中的所有女人"——作者原话，是太阴翻星的核心句。

## 原始星意

太阴属水，**原始星意是储存**。作者给的核心比喻：**太阴就是一个保温杯。**

> "你有一个保温杯。中国人的保温杯里装得大多都是热水，而西方人装得大多都是冰水，太阴就是这个保温杯。"

而且是一个"非常高科技的保温杯，可以随着四化的变化而加热、降温、保温、加湿、除湿"。**太阴是容器，里面装什么由同宫小星和四化决定。**

太阴被称为财星的原因也在储存。作者的社会学解释很直接：**中国是典型的农耕社会，中国人的消费观是反消费主义的，偏偏不爱花钱，都爱存钱——"而对应存钱的就是星耀就是太阴"。** 不是先有"财星"这个标签再往储存靠，而是存钱这个行为在中国社会里就是太阴本意的自然展开。

储存之外，太阴直接对应晚上能看到的月亮，月亮在文化上代表女人（对应太阳 = 男人）。所以有作者那句**"太阴……是我们生命中的所有女人"**——这不是修辞，是星意到文化意向的直接映射。

## 多维表达

太阴在不同宫位都是**女人 + 储存**的叠加。女性投影会按宫位换角色：

| 宫位 | 代表的女性 |
|------|-----------|
| 父母宫 | 母亲 |
| 兄弟宫 | 母亲或姐妹 |
| 夫妻宫 | 妻子 |
| 子女宫 | 女儿 |
| 其他宫位 | 命主人生中会遇到的女性（大运流年流动） |

作者提醒：**太阴的"女性盘"是所有女性的基本特质**——你身上女性特质越明显，你的人生结构就越贴近太阴盘格局。这对男命也有解释力。

储存维度上，太阴的"存什么"由旁边小星决定（"简单的拼读"）：

- **太阴 + 火星 = 窝火**（里面储存着火）
- **太阴 + 铃星 = 储存着烦恼**（老有烦恼的人）
- 以此类推，按「原始星意总结表」去拼。

## 物象表现（紫占视角）

紫占中，太阴的原始星意还可以直接映射到具体物体上。以下是 [[../../紫占方法/物象化|物象化]] 方法在本星上的典型应用。紫占方法论给太阴的原始星意：**储存、水、阴、女人**（源文 1087–1089、2359、2931 行）。

> "太阴就是几个基本的东西，第一件事情就说他存了什么东西。"（源文 1087 行）

紫占方法论给太阴一条关键的双层结构规则：

> **小星决定"存什么"，太阴的庙陷决定"存不存"**（源文 1111 行）。

这是整本紫占方法论最具示范意义的"星级 × 小星 × 四化"组合规则。下表是**亥宫庙位 + 巳宫陷位**的正反对照（1101–1177 行的压缩版）：

### 庙陷 × 小星 × 四化 组合表

| 小星 | 庙位（如亥）本态 | 庙位 + 化禄 | 庙位 + 化忌 | 陷位（如巳）本态 | 陷位 + 化禄 | 陷位 + 化忌 |
|------|----------------|-----------|-----------|----------------|-----------|-----------|
| 天喜 | 充满快乐 | 快乐存量放大 | 快乐被清空 | 没存到快乐 | 更没存上 | 反而存了一点点 |
| 铃星 | 充满烦恼 | 烦恼放大 | 烦恼清空 | 没存到烦恼 | 更没存上 | 反而存了一点烦恼 |
| 火星 | 充满急躁（窝火） | 急躁放大 | 急躁清空 | 没存到火气 | 更没存上 | 反而存了一点 |
| 擎羊 | 充满伤痛 | 伤痛放大 | 伤痛清空 | 没存到伤 | 更没存上 | 反而存了一点 |
| 地劫 | 充满空虚 | 空虚放大 | 空虚清空 | 没存到空虚 | 更没存上 | 反而存了一点 |

规则的记法：

- **庙 + 禄 = 放大当前存量**。庙位已经存了，禄让它再多一截。
- **庙 + 忌 = 终止 / 清空**。本来存满的一下倒空。
- **陷 + 禄 = 更没存上**。陷本身就没存到，禄让它更空。
- **陷 + 忌 = 反而存了一点**（约 20%）。因为忌属水在火位力量弱，反向效果出现（对应陷位巳宫的特别机制，源文 1101–1177 行）。

这条规则是紫占方法论里**最具示范意义的"星级 × 小星 × 四化"组合逻辑**——其他主星的庙陷 × 四化读法都可以类比套用。

### + 地劫（漏 / 空）

- **太阴 + 地劫** = 女人身体不好 / 男人命中女人空 / 漏财 / 忘事 / 情空（源文 2361–2369 行）——容器底破了。

### + 地空（溢 / 多水）

- **太阴 + 地空** = 海啸 / 多水溢出 / 守财奴 / 感情存太多 / 女人缘太多（2599–2601 行）——容器装过满。

### + 左辅（多存）

- **太阴 + 左辅** = 多女人 / 存多东西（钱 / 事业 / 感情 / 记忆 / 知识）（2933 行）——容器变多个。

### + 力士 / 其他搭配

- **太阴 + 力士** = 有力量的水（洪水 / 大海）（1495 行）。
- **太阴 + 阴煞陷 + 火星 + 左辅 + 天姚**（午宫）= 很多看不清的漂亮东西快速飘动（燕群案，367–375 行）。

### 小结

太阴 = 容器。紫占里看"钱有没有存上"、"感情里装了什么"、"脑子里装了什么"都从这条线走。**庙旺 = 装满**、**落陷 = 没装上**，旁边小星决定**装的是什么**，四化决定**装的东西被放大 / 清空 / 反转**。

详见 [[../../../sources/紫占方法论|紫占方法论]] 源文 1087–2933 行。

## 四化表现

承上：太阴是容器，四化是调节容器状态的参数（加热 / 降温 / 保温 / 加湿 / 除湿），不改变容器本身。太阴**四化俱全**（禄丁 / 权戊 / 科庚癸 / 忌乙）；它与"庙陷 × 小星"的联动已在上面〔物象表现〕的**庙陷 × 小星 × 四化组合表**里给了示范，这里只给单星层的能量方向：

- **化禄（丁干）**：储存量被放大、推向收成——存满的更满（财 / 储备 / 母性能量能落袋、能聚）；落陷"没存上"的状态被化禄放大则是更空。落 [[../../宫位/福德宫|福德宫]] 是"没有储存被放大成恋爱脑"的著名案（见 [[../../四化/化禄|化禄]]）。
- **化权（戊干）**：给容器加一对力——存被绷住、被要求"必须存住 / 必须守住"，保温与憋闷并存。
- **化科（庚 / 癸干）**：容器被柔化、蓄满——漏的被补、亏的被回填，小旋风式缓慢加湿保温。水木位力量最大。
- **化忌（乙干）**：终止当前储存状态——存满的被掏空、被卷走（容器破口）；本就空的容器化忌反而"存了一点"（约 20%，见上表「陷 + 忌」）。金水位是硬算子。

## 在十二宫的落宫解读

作者以太阴自身的星系排布做女性命盘分析。这是把太阴当太极点看的典型：

- **命宫（太阴）** — 储存、隐忍、含蓄。**"越多的容忍就越多的在弱势的地位"**——储存的性格直接导致弱势位置。
- **父母宫（贪狼）** — **"父母对女儿总有贪欲，有索求，希望家中的女性可以为自己付出。"** 家里要求母亲付出、伏弟魔家庭向姐妹索要彩礼——作者把这解释为太阴盘预设的父母结构：父母足够贪婪，女儿足够隐忍。
- **兄弟宫（天府）** — 天府是空间，关系稳定。人云亦云，主星作用不大，由小星决定好坏。
- **夫妻宫** — 文章在这里讲"妻子"代表时提到，但未单独展开夫妻宫排布。
- **子女宫（破军）** — **典型"慈母多败儿"。** 太阴从父母那接受了太多不好的能量自己吸收了，不想孩子再经历，所以放纵孩子。有智慧的 → 引导；智慧不高的 → 溺爱。
- **福德宫（巨门）** — 太阴的思考。**"一个擅长吸收的人，之所以说吸收，那是因为自己憋着，憋着就是不说的意思。但虽然不说，但想法是很多的。"** 太阴的信息都是直接进入大脑的。
- **田宅宫（天相）** — 想要维护家庭、照顾家庭——"这个是女性的天性"。作者的进化论解释：只有会维护家庭的女性的基因能留下来。
- **交友宫（七杀）** — 七杀在维度上是平面，这里主星作用不大，小星决定好坏。
- **官禄宫（天梁）** — 天梁是大柱子，代表大多数人的选择。所以太阴容易显得**中庸、保守**——因为那是社会中最稳定的选择。社会最优选变成冒险时，这个性质会变。落陷天梁不一样。

## 典型组合

- **太阴 + 火星 = 窝火。** 见「多维表达」。
- **太阴 + 铃星 = 烦恼储存。** 老有烦恼的人。
- **太阴 vs 天府 + 同小星的分野**：两者都是"容器"类星，但一个是"储存"（太阴）一个是"空间"（天府）。在紫占卦上差别很大；在命盘上是近义词。例：同样带火星，太阴多是**性格上窝火**，天府有时是**房间着火**。
