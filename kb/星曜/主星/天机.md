# 天机

> **原始星意：动，道。为移动的速度，为道路、通道。**
> "善星""吉星"只是它温室花朵般的柔性在人伦维度上的投影，不是本质。

## 原始星意

天机的底层定义是两个字：**动、道**——移动的速度、道路、通道。更具象的理解是"**一个被约束后内有可移动介质的通道**"。例如天机在寅宫与太阴同宫（太阴是储存，即容器内水的储量），加上天机就是"**管道水流速度**"的意向。

这套意向投影到不同事情上：落在财运上，是**钱财资金流动大且快**；落在感情上，是**感情变动大**；落在后台/背景上，是**靠山变化大靠不住**。卦象就是这么看的——没有一个固定的好坏，只看对应在什么事情上。

为什么天机被传统称为"柔星"？因为天机的"变"是**温室里被设好控制变量的变**，是在保护范围内让孩子去闯荡，所以会更柔和，能扛一些压力，但扛不了太多。对于天机而言，**最重要的是父母宫**——这就是天机为什么总要找一个可依偎依赖的后台。

2023 的早期文章里，同一套反传统的基调是：天机古书称"吉星""善星"，但其实"**投机**"的意味很重，暗合破军，"看着很聪明其实心很乱"。天机只能学习，难以开创，**虽然暗合破军，但开创能力差了很多，而且很滑头**。

## 多维表达

| 维度 | 投影结果 |
|------|---------|
| 通道类 | 管道、道路、介质中的流速 |
| 财 | 现金流的速度、流动性 |
| 感情 | 感情变动、博爱、暧昧 |
| 事业/背景 | 后台是否稳、是否多变 |
| 身体 | 与运动有关（汽车、速度）|
| 思维 | 活泛、脑洞大、反应快 |

具体呈现由"庙旺落陷"和"旁边小星"修饰。"卦象没有一个固定的好坏，只看对应在哪些事情上"——这是语料里的原话。

## 物象表现（紫占视角）

紫占中，天机的原始星意还可以直接映射到具体物体上。以下是 [[../../紫占方法/物象化|物象化]] 方法在本星上的典型应用。紫占方法论给天机的原始星意：**动、道**（源文 2031 行），延伸至**机器 / 算计**（2033 行）和**车 / 机器 / 道**（2903 行）。**速度由庙陷决定**——子宫庙（水生木）= 100 迈，午宫陷 = <10 迈（1021–1027 行）；化禄放大当前速度态（100→150 或更慢），化忌终止之前状态（庙忌 100→0，陷忌反而稍微动起来 10–20%）（1045–1077 行）。

### + 地劫（原地打转 / 空转 / 断）

- **天机 + 地劫** = 原地打转 / 在洞里转 / 空转 / 脑子白动（源文 2407–2415 行）。
- **机梁 + 地劫** = 四肢有洞 / 断肢（2415 行）——棍状 + 缺口。
- **天机 + 地劫 + 化忌** = 断路卦（2018 年断路卦，1835 行）——道本身断掉。

### + 地空（超速 / 超频）

- **天机 + 地空** = 超速 / 超负荷 / 超频 / 下坡太快 / 会计超速（2619–2621 行）——速度鼓包、冲出上限。

### + 左辅（多）

- **天机 + 左辅** = 多辆车 / 多动脑 / 算好几次（2905 行）。

### + 右弼（转向）

- **天机 + 右弼** = 转向 / 跑偏 / 车开偏 / 绕不出来 / 道路转弯（2907 行）——天机本身是"道"，右弼让这条道拐弯。

### + 其他搭配

- **天机 + 陀罗**（丑宫）= 棍子打转（刷盘子）（831 行）——反复旋转的棍状工具。

### 小结

天机 = 速度 + 路径。**加劫 = 路断或空转**；**加空 = 超速**；**加辅 = 多条路 / 多次算**；**加弼 = 路拐弯**。紫占里看 "车撞了没" "路走没走通" "算对没算对" 都从这条线切入。

详见 [[../../../sources/紫占方法论|紫占方法论]] 源文 2031–2907 行。

## 四化表现

天机的四化都在调节"动 / 道"这条**速度与管道**——四化俱全（禄乙 / 权丙 / 科丁 / 忌戊），可成组对照：

- **化禄（乙干）**：可变动性 / 速度被放大。庙旺位的"车"从 100 迈推到 150 迈；但落陷位的天机本就不怎么动，化禄反而把"停滞"这个当前状态放大，更慢甚至停（见 [[../../四化/化禄|化禄]] 的天机车速案）。放大的是当前状态，不是"快"。
- **化权（丙干）**：给"动"加一对相互作用的力——灵活被绷住、被规训成"必须按某个节奏动"，巧变成硬转。力在木火位最足。
- **化科（丁干）**：让"动 / 道"缓下来、延续、回退——卡顿的通路被小旋风一点点疏通，急转被磨成匀速。水木位力量最大。
- **化忌（戊干）**：终止当前的"动"——在动的被切断（断路、卡死、信息中断），本就停滞的反被掀翻换一种动法。金水位是硬算子。配合 **贪狼化禄 + 天机化忌 = 断路卦**（见 [[贪狼|贪狼]] 物象表现）。作者另提示：四化也可反过来当"碰撞"一个固执抓取点的手段，"大家没必要死磕硬磕，用四化去碰撞就好"。

## 在十二宫的落宫解读

以天机在命的架构（紫微在父母宫）为基准，语料给出如下骨架：

- **命宫** — 天机潜意识上**觉得自己没那么重要**，所以在灵魂成熟后会矛盾：一方面觉得自己重要，一方面又觉得别人更重要，特别是在家庭关系上。
- **父母宫（紫微）** — 很重视父母，自小在家庭里低位、听话；父母也强烈想管他。所以"找一个可依偎依赖的后台是很重要的"，天机爱考公，爱抱大腿——"油油的，想让别人干活"。
- **夫妻宫（太阳）** — 庙旺的太阳代表感情公开、成果示人；落陷的太阳代表地下恋情，或女命"男人不出现"。太阳庙旺还有"广、散"的意向，即**博爱**——"把心碎成了很多份，每一份都是爱你"；难听地讲就是中央空调。天机的"投机"部分由此成立：**自己比较轻，为了目标可以不断改变**。
- **子女宫（武曲）** — 武曲冷、硬，投在下属/孩子身上。天机"**媚上者必欺下**"的模式在这里固定下来——慕强把自己放低位，于是对比自己弱的人就冷漠、不屑。要俘获天机："你要比他强，不能表现出弱"，否则他觉得自己比你强就立刻下头翻脸。
- **财帛宫（天同）** — 对小钱敏感，薅羊毛式的**蝇头小利**就能让他自鸣得意。一六共宗看：天同是表，紫微是里，所以在天机心里"**资源都是父母/领导给的**，拿领导赏钱最开心"。
- **交友宫（廉贞）** — 天机和廉贞也是一六共宗，天机是表、廉贞是里——**天机的呈现由廉贞在抓什么决定**。所以交友宫对天机额外重要。天机"擅长搞暧昧"：有感情缘分，但心不够坚定，想这玩玩那玩玩。

2023 版另外补了一条：**事业宫是空宫**，天机的做事特点看天府星系的安排；很多天机因为事业宫没主星，就容易去做投机的事情。

## 典型组合

- **天机 + 太阴（寅）** — 管道水流速度极快的意向，是原始星意里最典型的一对组合。应在财、感情、背景上分别投出不同具象。
- **天机 暗合 破军** — "看着很聪明其实心很乱"；有一点开创的外壳，但**真正的开创能力差破军很多**。比不过破军：天机在框架内规规矩矩，破军是打烂棋盘。
- **太阳庙旺（天机夫妻宫）** — 博爱、中央空调，"**因夫得贵**"的古诀由此来；但博爱是相互的，不一定是天机单方面的错，"太阳的照射和天机的投机在一起作用"。

## 格局对照

- **天机因夫得贵**（古诀） — 夫妻宫太阳庙旺+天机投机心态的联合产物。翻星摇斗的重述：不是"嫁个好老公运气好"，而是天机用投机心态去选、太阳无私照耀过来，两股力合成了这种"从配偶处得贵"的呈现。
