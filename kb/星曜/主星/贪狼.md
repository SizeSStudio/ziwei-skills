# 贪狼

> **原始星意：体积 / 大小的变化。**
> "桃花"只是它在情欲维度上的一个投影，不是本质。

## 原始星意

贪狼属木。它最底层的含义是**一个物体的体积/大小在变化**——想象一个东西一会儿变大一会儿变小。这是贪狼讲的所有故事的起点。

人见到喜欢的东西身体会前倾、瞳孔放大——这其实是在让那个东西在自己视野里**变大**。而"放下"、不再想要一个东西，就是让它在自己心里**变小**。古人把这种"体积涨缩"的体验绑到"欲望"上，后人就只记住了"欲望"这半截，把贪狼当成欲望/桃花星。翻星摇斗的立场是回到涨缩这个更底层的含义，**欲望只是它在情欲维度上的投影**。

## 多维表达

贪狼是"量"这个概念本身，所以它在不同维度上投影出不同的具体意向：

| 维度 | 投影结果 | 例子 |
|------|---------|------|
| 1 维 | 长度 | 身高、距离 |
| 2 维 | 面积 | 皮肤的面积、房屋面积 |
| 3 维 | 体积 | 肉、身体体积、建筑体量 |
| 情感 | 欲望强度 | 想要变多 / 想要放下 |
| 财 | 多少 / 规模 | 财富规模大小 |
| 关系 | 拥有欲 / 占有感 | 想要更多地拥有某个人 |

"测什么就是什么维度上的体积"——这是翻星摇斗原文里近乎一字不差的讲法。

贪狼的庙旺直接决定这个"量"的大小：庙旺 → 大；落陷 → 小。

## 物象表现（紫占视角）

紫占中，贪狼的原始星意还可以直接映射到具体物体上。以下是 [[../../紫占方法/物象化|物象化]] 方法在本星上的典型应用。本节与上面的「多维表达」互补——**多维表达**侧重人命盘的维度投影（长度 / 面积 / 体积 / 欲望 / 财），**物象表现**侧重紫占卦上"贪狼 + 各小星"直接指代什么具体物体。紫占方法论原话：

> "贪狼在很多紫占的物相中是代表物体的体积大小。"（源文 1565 行）

所以紫占里的贪狼先读**体积**，再让搭配的小星去定具体是什么有体积的东西。

### + 廉贞（戒指 / 烟 / 金元宝）

与廉贞（抓取力度）组合是贪狼在紫占里最常见的配对（详见 [[廉贞|廉贞]]）：

- **廉庙贪陷** = **戒指**——密度大 × 体积小 = 小而抓得紧的物件（源文 2339 行）。
- **廉陷贪庙** = **烟雾**——体积大但抓不住（源文 1573–1575 行）：

> "烟的体积很大把你包含进去了，你也可以认为烟把你囚住了。但这个力量太弱了。你可以随意挣脱。"

- **廉贞 + 贪狼 + 地劫** = 金元宝 / 纸元宝（2325 行）——抓住了一个有洞的体积。

### + 地劫（体积空 / 戒指 / 烟卦）

- **贪狼 + 地劫** = 体积空 / 有洞 / 车顶下陷（源文 2337 行）。
- 戒指卦和烟卦都要借地劫读"缺口 / 中空 / 消散"（2339–2341 行）。

### + 地空（虚泡 / 鼓泡 / 车顶）

- **贪狼 + 地空** = **虚泡 / 鼓泡 / 车顶 / 肉太多**（2587 行）——体积凸出、鼓起来的物象。
- **贪狼庙旺 + 地空** = 欲望爆棚（2589 行）——体积 + 鼓包。
- **贪狼化禄 + 地空** = 体积可改变 / 海绵吸水（2591 行）。
- **辰位贪狼 + 地空**（女性）= 没用的肉太多（2595 行）。

### + 左辅（多个体积）

- **贪狼 + 左辅** = 好几个东西 / 欲望多 / 好几块肉 / 多痘（2925 行）。

### + 右弼（体积扭转）

- **贪狼 + 右弼** = 物体扭住 / 卷起 / 拧衣服 / 欲望转移 / 换东西 / 物体扭曲（2927 行）。

### + 天机（断路卦）

- **贪狼化禄 + 天机化忌** = **断路卦**（源文 1833–1835 行）——贪狼提供"量"（距离 / 里程），天机提供"道"，合起来在路程维度上忽然中断。在 财 语境下则为"财的体积（负债规模）"（1833 行）。

### 小结

紫占里的贪狼，首先读体积，然后让搭配定具体物。**+ 廉 = 抓住的体积**；**+ 劫 = 体积空掉**；**+ 空 = 体积鼓起来**；**+ 辅 = 多个体积**；**+ 弼 = 体积扭曲 / 换对象**；**+ 天机 = 路 / 距离的体积**。这一栏的重点是：**紫占卦面的"贪狼"先当具体物体看，再追加欲望 / 桃花类的人事投影**——与命盘里直接讲桃花的读法顺序相反。

详见 [[../../../sources/紫占方法论|紫占方法论]] 源文 1565–2927 行。

## 四化表现

- **化禄**：量的增长顺畅——欲望能被转化成行动、能长肉、财能聚。好用。
- **化权**：量的控制——能让自己的欲望/胃口有主张、能掌控规模。
- **化忌**：量失控——欲望膨胀到失控、贪心、身材或钱财失衡。贪狼化忌是最容易出"贪"字负面形象的来源。
- （化科 不入贪狼，不需要讲。）

## 在十二宫的落宫解读

以命宫为太极：

- **命宫 / 身宫** — 本人的"量"感。欲望强度、对体积的自然嗅觉（大房大车、多人脉、多经历）。贪狼坐命不等于风流，等于"对量敏感"，落在哪个维度要看其他星和宫位。
- **夫妻宫** — 配偶身上"量"的表达。配偶是否体积大、是否欲望强、是否要求多——看同宫星怎么修饰。
- **财帛宫** — 钱财的规模倾向。庙旺能聚大财，落陷则量级小且易散。
- **疾厄宫** — 身体的量。肉、体积、脂肪分布。贪狼疾厄要注意配合辅煞星看，不是一见贪狼就胖。
- **田宅宫** — 房屋的体量、土地的规模。
- **官禄宫** — 事业的体量、所做事情的规模化程度。

以其他宫立太极时按 [[../../断事方法/宫位立太极]] 重新推——规则不变，只是"量"是谁的量换了。

## 典型组合

- **贪狼 + 文昌 = 粉身碎骨。** 贪狼是肉（体积），文昌含"偏斜"的底层含义。大体积 + 偏斜 = 大肉塔倒了。不一定真胖，但有"体积歪掉"的潜力——可能表现为身材失衡、某一部分不成比例、或长大后身体出结构性问题。翻星摇斗举大胃袋良子（一米六、四百斤）为典型。
- **贪狼 + 天姚 = 真桃花。** 天姚代表"好看的"，贪狼的欲望被导向"对好看的有强欲望"，这才是桃花意向成立的起点。单贪狼不够。
- **贪狼 + 咸池 = 情欲桃花。** 咸池是"咸湿"（体液），欲望落在咸湿维度上。
- **贪狼 + 天刑 = 自律。** 天刑是"自我管控"，贪狼的欲望被自己限制住，反成高度自律。
- **贪狼 + 华盖 / 天空 / 地空 / 地劫 = 爱好空门、修仙倾向。** 欲望指向"空"这件事本身。
- **贪狼 + 天巫 = 灵媒根骨。** 天巫是"信息传递"，贪狼越大 = 能传递的信息越多。
- **贪狼 + 天哭 = 爱哭。** 情绪上的"量"偏大。

## 格局对照

- **泛水桃花（贪狼在子宫）**：传统说法是"桃花极旺"。翻星摇斗修正：子宫在最下面、跟生殖系统相关，贪狼在这里只是**与生殖相关的 量感**强，并不自动等于桃花；**必须同时有 天姚 / 咸池 等桃花小星**才真正成格。很多自以为泛水桃花却"一点桃花都没有"的人，问题就出在缺了那些小星。（系统重建见 [[../../格局/桃花格|桃花格]] 页。）
- **贪狼文昌 = 粉身碎骨**：见上面「典型组合」。
