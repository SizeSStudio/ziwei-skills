# 紫占方法

这里放**只在紫占（占卜具体事件）语境中才用到**的方法和技术。通用的方法（星意还原、宫位立太极、关系反推、现实校验、正向应卦）在 [[../断事方法/README|断事方法]] 里，那些在命盘推演和紫占里都用。

## 为什么要单独开一个目录

紫占和命盘推演虽然共用**原始紫微**的底层 ideology（拒绝吉凶标签、原始星意、立太极），但**技术层面差异很大**：

| | 命盘推演 (ziwei-natal) | 紫占 (ziwei-zhanbu) |
|---|---|---|
| 为谁服务 | 为人（一辈子） | 为事（具体一件事） |
| 起盘时间 | 出生时辰 | 起心念的那一分钟 |
| 太极默认 | 命宫 | 来因宫（天卦）/ 命宫（人卦） |
| 应期机制 | 大限 / 小限 / 流年 | 三层卦 + 四化串联（没有大限） |
| 读什么 | 性格 / 结构 / 人生轨迹 | 一件事的当前 / 过去 / 未来 |
| 时间精度 | 时辰（120 分钟）| 分钟（紫微星语可到秒级）|

紫占的这些技术——三层卦、同音卦、物象化、十二相、追禄、天/人卦——在命盘推演里基本不用，所以分一个单独目录，`skills/ziwei-zhanbu/` 的检索可以直接 pull 这里的全部内容。
