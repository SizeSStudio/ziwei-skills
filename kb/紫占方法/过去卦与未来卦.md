# 过去卦与未来卦

> **核心原则：紫占的当前卦是一张"起念那一分钟的天地快照"——所见即所得。要看过去就「追禄」，要看未来就看「禄源什么时候会被激活」。不需要像传统紫微那样推大运流年。**

## 核心原则

紫占的起卦观很特殊。作者原话（1 期，行 65–73）：

> "紫占起卦就很简单，叫做所见既所得。无论你之前经历了什么，怎么变成目前的状态的。当紫占起卦时就代表了你现在的状态，你是得病了就是有病的状态，你没病就是没有病的状态。"
>
> "你想知道你是怎么变成现在这个状态的就分析过去卦，你想知道未来的变化就分析未来卦。简单明了，不用什么事都和出生的那个点挂上联系。"
>
> "紫微是一个天地描述系统，它实际上可以理解成当我们起卦时就相当于用紫微的这个相机把天地间所有可以用紫微星象代表的力量给拍了一张快照。这张快照所见即所得，即代表现在的你。"

这一套框架下：

- **当前卦** = 起念那一分钟的天地快照，直接读。不用推大运 / 流年。
- **过去卦** = 当前卦的"因"——通过 [[追禄]] 反向追到源头。
- **未来卦** = 当前卦的凶宫 / 吉宫将在什么条件下被激活——通过"禄源激活条件"判断。

**过去卦走得清、未来卦走得虚。** 这是源文档里很实的一条——过去有追禄这套机械手续，未来只有"观察激活条件"这么一条指针，没有"给我一个确定的预言"。

## 核心公式

作者在 2 期（行 183）给出"时间卦"的通用公式：

> "建立好对应关系的公式模型之后，你就可以用未来、过去的时间点去代入到这些公式模型中，去看看哪些东西会被改变了，哪些东西没有被改变，这就是应期和克化的方式方法。"

解读：

1. **先把当前卦读成一个"公式模型"**——把主卦 / 流十分钟 / 流分钟三层都读出来，把四化链也整理清楚。
2. **然后把过去 / 未来的时间点代入这个模型**——同一个模型在不同时间点下，有些变量变了，有些没变。
3. **变了的那些 = 应期在那一点会发生什么 / 克化在那里怎么发生。**

**换句话说**：当前卦给你的是结构（像一个函数），过去 / 未来的时间点是代进这个函数的参数。这是一个非常工程化的思路，和"求一卦看全未来"的玄学路子是反着的。

## 过去卦 —— 走追禄就够

**过去卦的主力工具**：[[追禄]]。

- 来访者问"我是怎么变成这个状态的"→ 从问题所在宫出发，沿着禄链反向一层层追，追到一个解释力够的源头停手。
- 典型层数：1 层（简单问题）到 4 层（小孩咳嗽案那种复杂污染）。
- 原作者的节制原则：查到"卦主能被震憾"就够了，不要追"起因的起因"。

**过去卦的另一个用法**：用过去的时间点代入当前卦公式，看哪些变了。

- 来访者问"我五年前是什么状态"——把"五年前"代入当前卦的三层结构，主要看四化链的**起点宫**在五年前是否已经激活。
- 这一步比追禄精细，但作者没有给成型的操作规范。实战里更常用的还是追禄。

**为什么过去卦的工具比未来卦更成型？** 因为已经发生的事情有现实来对照——看作者追禄追到"发电厂"这一层，家长可以立刻验证家旁边是不是真有发电厂。现实的锚让过去卦能反复迭代改进，所以规则变得严谨。

## 未来卦 —— 只能读"激活条件"

**未来卦的主力工具**：观察**禄源什么时候会被激活**。

作者原文（11 期，行 1889–1893）：

> "如果一个很不好的宫位化禄的地方非常好，而化禄地宫位的事被激活了，那就等同于这个不好的宫位被激活了。"
>
> "反过来就是如果一个宫里的东西还不错。假如一个很烂的宫位可以让这个宫化禄，那这个好宫里的事还是不要发生的好。再好的东西也不能碰，碰了就要有恶事发生。"

**操作层面的翻译**：

| 问题 | 操作 |
|------|------|
| 凶宫何时发动？ | 找它的禄源宫 → 禄源宫何时被激活 → 那就是凶宫的应期 |
| 吉宫何时发动？ | 找它的禄源宫 → 禄源宫何时被激活 → 那就是吉宫的应期 |
| 能不能取消凶事？ | 让禄源宫的激活条件**不要被满足** |
| 能不能挽回已发生的凶事？ | 把已化禄的事再"忌回去"（§追禄反用） |

**教科书案：亡夫（11 期 行 1907–1919）**。凶宫（福德：地劫 + 阴煞 + 天寿 = 断寿之相）的禄源在夫妻宫。**只要不结婚，凶宫不发动。一结婚，禄源即激活，凶事落地。** 该男子 2012 年 1 月还健康，4 月领证，6 月查出肺癌，10 月去世。

**这一条把"未来"从"预言"降维成"条件检测"**：紫占不保证凶事一定发生，只给出**凶事发生需要什么条件被触发**。是否触发很多时候在来访者自己的手里。

## 未来卦的本质局限——源文档自认"走得虚"

作者在源文档里没有给过去卦那样成型的"未来卦推导步骤"。他对未来的处理方式整体是：

1. **用当前卦定结构**。
2. **用禄源激活条件检测激发时点**。
3. **给应期提示（左盘 = 早、右盘 = 晚、五行 = 方位）**。
4. **不给确定预言**。

**本页的立场是跟源文档对齐，也走这条诚实路线**——紫占的未来卦是"条件检测"，不是"必然预言"。凡是看到"算准你未来几年怎样"的句式，大概率是走飞了，不再是原始紫微这套的立场。

## 应期上限——3–5 年，极限 12 年

源文档在 2 期（行 153）给出应期的可靠范围：

> "所以用于算 3–5 年之内的事是可以的，太远就会有偏差了。这个我最多算过 12 年内的事还是有把握的。"

- **稳定范围**：3–5 年内。
- **个别高手可延伸**：到 12 年。
- **超过 12 年**：作者没有公开主张能做。

**为什么会有时间上限？** 作者的解释（2 期）是：人成年后心念杂，卦主起念那一分钟的"纯度"被各种积累冲淡。同时五年以上的外部环境变化太多，当前卦的结构不足以 forecasts 那么远的大环境变化。

所以"未来卦"实际上更适合解三五年内的具体问题——能不能考上今年这个学校、下半年要不要辞职、明年这个企业会不会崩。问"我 30 年后会怎么样"——源文档明确说这不在紫占的诚信区间。

## 操作步骤

**读过去卦**：

1. **确定要追的事和它在盘上的宫。**
2. **走 [[追禄]] 流程**——从这一宫出发，读它的天干化禄指向哪个宫；那个宫是第 1 层因。
3. **如果含义已经解释问题 → 收口。否则再追一层**（看禄源宫的天干又化禄到哪）。
4. **现实校验**——把追到的最终层的含义告诉来访者，让他回想现实里是否有对应事件。对上了，这条过去卦就落地了。

**读未来卦**：

1. **识别当前卦里的凶宫 / 吉宫。** 哪些宫会在未来带来凶事或吉事。
2. **对每个凶宫 / 吉宫，查它的禄源宫在哪。** 禄源宫代表激活条件。
3. **判断激活条件是否在控制范围内。**
   - 凶宫的禄源是"结婚"→ 在来访者的控制里（可以延后 / 不结）。
   - 凶宫的禄源是"接某个项目"→ 在来访者的控制里。
   - 凶宫的禄源是"遇到某个人"→ 部分可控。
   - 凶宫的禄源是"自然季节 / 大环境"→ 不可控，只能提前做准备。
4. **给来访者清楚的建议**——不是"你未来会怎样"，是"如果 X 发生，Y 会跟上"。
5. **应期细化**——如果需要更细的时间，启用 [[十二相]] 第 7 相"四化分布"（盘左时段早、盘右时段晚、五行对应月 / 方位）。
6. **不要超出 3–5 年去给具体预言。** 超出就明确说"这个时间段超出我这套体系能断得准的范围"。

## 典型触发信号 / 适用场景

- 来访者问"我为什么会变成这样"——过去卦。
- 来访者问"我这个病怎么好的 / 怎么治"——过去卦（查根源）+ 未来卦（查激活条件是否能关掉）。
- 来访者问"我明年要不要做 X"——未来卦（条件检测，不是预言）。
- 来访者问"我这辈子会怎样"——**拒绝**，或者降级成"你 3–5 年内的趋势"。

## 常见误用 / 坑

- **把当前卦当成过去卦硬读。** 当前卦是"此刻的状态"——咳嗽就是在咳嗽的状态，不是咳嗽的原因。读原因要走追禄。
- **跳过追禄直接预言未来。** 没有追出禄源宫就给出"你会怎样怎样"——这是玄学口嗨不是紫占。紫占的未来是"条件 + 条件 → 结果"不是"直接结果"。
- **把"禄源激活"当成必然应期。** 源文档明确说可以"忌回去"化解已激活的凶事。激活不等于不可挽回。
- **超过 3–5 年还给结论。** 作者自己封顶 12 年，多数情况稳定在 3–5 年。超过这个范围就不要假装能断准。
- **拿未来卦当预言工具卖给来访者。** 紫占方法论整本书的核心立场是"紫占描述条件不保证预言"——如果把未来卦包装成"我能看你 10 年后"，这已经偏离原作者的立场。
- **过去卦追得太深，脱离现实锚。** 追禄追 4 层到"发电厂"可以 verify。追 10 层到"前世"——没法 verify 就等于没说。回到 [[../断事方法/现实校验]] 的原则。

## 参考（他派对照，非本 KB 主线）

> ⚠ 以下仅做辨析用，不进入本 KB 主线推理。

- **传统紫微 / 全书**用**大运 / 小限 / 流年 / 流月 / 流日**的叠层去推未来。作者在 6 期（行 873–875）明确拒绝这套用在紫占里："什么大运、流年、流月、流日等东西都是对人起作用的体系。对于天意来说分钟走到那里即是天意。一一对应就好不用再拟人化。"——紫占用三层卦（[[三层卦]]）代替大运流年。
- **八字 / 六爻**里有各自的应期系统。八字走日柱 / 月柱 / 年柱的应；六爻走爻动变。紫占的应期靠"禄源激活 + 四化分布"——是三套独立的系统，不要在同一个断卦里混。
- **飞星紫微斗数**的四化飞宫查"人生事件"的思路和紫占追禄接近，但飞星通常用在命盘上（一辈子），紫占用在一件事的当前分钟。同原理不同适用。
