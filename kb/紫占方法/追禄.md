# 追禄

> **核心原则：要查一件事的起因，就顺着「让这件事所在宫化禄的宫」一层一层往回追——禄源即因源。这是紫占"四化因果"相（十二相第 9 相）的操作法。**

## 核心原则

在紫占里，四化不是 4 个独立的事件——它们是因果链的节点。具体：

- **禄** = 放大 / 激活 / 驱动——某宫的禄**来自**让它化禄的那个宫 → 那个宫就是这件事的**起因**。
- **忌** = 终止 / 细化 / 收束——某宫的忌**指向**让它化忌的那个宫 → 两者拼起来是这件事的**补充说明**（这是 [[十二相]] 第 8 相，不是追禄，见下文对比）。

**追禄**就是沿着"禄链"反向追溯：一件事是哪个宫点着的？那个宫又是哪个宫点着的？一层层往前，直到摸到根源。

作者原话（紫占方法论 11 期，行 1873–1875）：

> "就是查因果了，上面上忌的串联，这回是禄的串联。不过我们在实战中很少一直这到串禄下去，只是串个一层而已，查到起因就 OK 了。没有必要去再查起因的起因。这也太累了。"

"通常一层就够"——但遇到复杂问题（小孩咳嗽这种一路追到发电厂的）就可能走 3–4 层。层数是经验判断，不是规则。

## 追禄 vs 追忌

这两条常被混——必须分开：

| | 追禄 | 追忌 |
|---|------|------|
| 作用 | **查因果 / 起源** | **细化一个物体 / 事件的属性** |
| 方向 | 每层往回追"点着这件事的宫" | 每层往前追"描述这件事细节的宫" |
| 走多少层 | 通常一层，难查的 3–4 层就够 | 视物体复杂度，多几层无妨 |
| 典型案例 | 小孩咳嗽（4 层到发电厂） | 可乐（3 层到气泡） |
| 对应相 | 第 9 相（四化因果） | 第 8 相（四化组意） |

都用四化链，但追的是不同方向的东西。**追禄问"为什么会这样"，追忌问"这到底是什么样"。**

## 为什么

**紫微里所有激活都要走四化。** 一个宫如果没被四化激活，它就是静态的——既不是因也不是果。所以要找一件事的起因，就找"**能把这一宫激活的力量来自哪**"——这就是让这一宫化禄的那个宫。

**为什么是禄不是其他？** 因为四化在紫占里的角色分工是：
- 禄 = 放大 / 激活（放大一个状态，让它从潜在变显化）
- 忌 = 终止（终止一个状态）
- 权 = 保持 / 阻挡
- 科 = 拖延 / 缓慢

只有禄是**"把事点燃"**的那个四化。所以追禄 = 追"谁点着了这件事"的火种。

这也解释了作者在"反过来用"追禄时的另一个用法（11 期，行 1889–1893）：

> "如果一个很不好的宫位化禄的地方非常好，而化禄地宫位的事被激活了，那就等同于这个不好的宫位被激活了。"

——反过来说，如果凶宫的禄源宫**不被触发**，凶宫也不会真的发动。这把"起因"的概念推到了"**应期激发条件**"。紫占里"什么时候会应事"就是"禄源宫什么时候被激活"。

## 操作步骤

**标准追禄流程（一层版）**：

1. **锁定要查的宫。** 来访者问了一件事——定位这件事在盘上对应哪一宫（咳嗽 → 疾厄宫；发烧 → 疾厄宫；事业黄 → 官禄宫；感情散 → 夫妻宫；等等）。
2. **读出这一宫的天干，查"被谁化禄"。** 紫微盘上每一宫都有天干，每个天干对应一组四化（甲廉破武阳 / 乙机梁紫阴 / 丙同机昌廉 / 丁阴同机巨 / 戊贪阴阳机 / 己武贪梁曲 / 庚阳武阴同 / 辛巨阳曲昌 / 壬梁紫府武 / 癸破巨阴贪）。**找是哪个宫的天干让这颗星化了禄**——那一宫就是禄源。
3. **读这个禄源宫的卦意。** 它是这件事的"起因"或"早先状态"。
4. **如果禄源宫的卦意已经能解释问题 → 到此停手。**
5. **如果禄源宫的卦意仍然模糊、含义不足 → 重复第 2–3 步再追一层。** 以禄源宫为新起点，再追"让它化禄的宫"。

**小孩咳嗽（4 层版）—— 作者原文（11 期，行 1883–1887）**：

> "比如小孩子发烧了是现状卦，我们把发烧的宫位只要定好了，化禄的宫位所发出的四化一定就是发烧的原因，可能代表的意思是感冒了。那感冒宫位发出的化禄的地方就是感冒的原因，可能是被传染了，传染宫位发出的化禄的地方就是传染的原因。可能是那天去那里玩了。"
>
> "我记得有一个卦就是小孩子总咳嗽，就是这么一层层追禄下去，查出来问题来自外面，查出了空气中有含水气的火性金属粉尘，查出了家旁边有一个发电厂，查出了粉尘让支气管过敏了。所以才咳嗽的。"

这个案例的层数 visualized：

| 层 | 宫 / 物象 | 含义 |
|---|----------|------|
| 当前现状（咳嗽） | 疾厄宫 | 症状 |
| 第 1 层追禄 | 疾厄禄源宫 = 粉尘进入气管 | 咳嗽的直接原因：过敏 |
| 第 2 层追禄 | 上层禄源 = 空气中的金属粉尘 | 过敏的原因：含水气的火性金属粉尘 |
| 第 3 层追禄 | 上层禄源 = 发电厂 | 粉尘的来源：家旁边的发电厂 |
| 第 4 层追禄 | 上层禄源 = 去了那里 / 住进那里 | 接触发电厂的原因：住到附近 |

每一层都是"上一层的因"。层数依问题深度判断——作者的原则是"查到卦主震憾就够了"，不必追到无穷。

## 追禄在"未来"上的反用——禄源激活即应期

这是追禄在[[过去卦与未来卦|未来卦]]方向上的反向应用，直接引原作者（11 期，行 1889–1893）：

> "如果一个很不好的宫位化禄的地方非常好，而化禄地宫位的事被激活了，那就等同于这个不好的宫位被激活了。"
>
> "反过来就是如果一个宫里的东西还不错，假如一个很烂的宫位可以让这个宫化禄，那这个好宫里的事还是不要发生的好。再好的东西也不能碰，碰了就要有恶事发生。"

**换成一个操作句式**：

> "X 宫将发生之事 = 让 X 化禄的那个宫被激活。"

**教科书案（亡夫案，11 期行 1907–1913）**：某位男性命 / 疾 / 福 三宫有"必死之相"（福德：地劫 + 阴煞 + 天寿，其中**天寿 + 地劫 = 断寿之相**）。正常情况下不发动，但 **禄源在夫妻宫**——一旦结婚，激活禄源宫 → 激活凶宫 → 必死之事发生。该男子 2012 年 1 月还健康，4 月领证，6 月查出肺部小细胞癌，10 月去世。

作者引申（行 1913–1919）：

> "只要不让化禄的宫位的事发生或激活就没有问题了。或是如果已经激活了想办法快点忌死了就可以了。"

例：坐牢的宫位禄源是"贪污公款"——不贪污就不坐牢；如果已经贪了，在应期发生前快点"忌死"（把贪污的事先还回去），可以取消应期。

**这条反用把追禄从"查过去"扩展到"控未来"**：知道凶宫禄源在哪，就知道该避免触发什么；知道吉宫禄源在哪，就知道该主动做什么。

## 典型触发信号 / 适用场景

- 来访者描述的是一个**现象 / 症状 / 结果**（咳嗽、发烧、亏钱、感情变冷）——这些都需要追禄查原因。
- 遇到**吉宫 / 凶宫却不发动**——要查它的禄源宫是不是还没被激活。
- 卦里某一宫很好看但来访者却在吃苦 / 某一宫很难看但来访者却过得好——要追一层看这个宫的禄源宫出了什么事。
- 要判断**应期在什么时候** / **怎么激活 / 怎么避免**——追到禄源宫，那里的事就是开关。

## 常见误用 / 坑

- **把追禄和追忌混用。** 前者查因，后者细化物。细化复杂物用忌的串联，不用禄；查一件事为什么发生用禄，不用忌。两个方向完全不同，不要串。
- **追禄追无限层。** 作者明确说（行 1875）："没有必要去再查起因的起因。这也太累了。"通常一层就够，难查的 3–4 层就封顶。不要沉迷于"一路追到宇宙大爆炸"——那不是断卦是自嗨。
- **没搞清楚"让 X 化禄的宫"到底是哪一宫**。每个宫的天干决定一组四化飞向哪里——先把天干对应的四化飞星表打熟（或用 [[起卦流程|紫微星语]]自动标注），不然追错方向。
- **只追一层就当已经找到根源**。简单卦一层就够，但遇到多层结构的（比如来访者的"咳嗽"其实是"发电厂粉尘"这种外部污染），只追一层只能读到"过敏"这个浅因，读不到真正的根。知道何时该继续追——看**当前层的卦意能不能解释来访者的描述**，不能就继续。
- **把反向追禄当必然应期。** "凶宫禄源在夫妻宫 → 一结婚就必然死"——不是必然。作者原文"只要不让化禄的宫位的事发生或激活就没有问题了"说的是激发条件，不是必然结局。还有忌死 / 规避 / 变现时机等操作空间。
- **在命盘推演里大量用追禄**。作者在多处强调：这些多层四化串联用法"在紫占中会有奇效，在普通紫微命盘时真的不一定好用"（11 期，行 1871）。命盘跨度太长，多层串联常常走偏。追禄主要是紫占工具。

## 支撑案例 / 引用

全部来自 [[../../sources/紫占方法论|紫占方法论]]。

- **小孩咳嗽 4 层追禄案**（11 期，行 1883–1887）——追禄的教科书案，上面已全文引用。
- **2017 丁干 四化联动案**（11 期，行 1821–1829）——太阴禄（得财 / 事业）和巨门忌（失感情 / 家庭）是同一次激活的两面，禄源一旦被点，忌果"不会错过"，应期差几个月到几年。这个案例不是典型的追禄（它是四化串意，第 11 相），但说明了"禄源激活 = 应期启动"的机制。
- **亡夫案（反向追禄 / 应期激活案）**（11 期，行 1907–1919）——凶宫禄源在夫妻宫 → 结婚激活凶宫。见上文"反用"节。
- **贪污坐牢案**（11 期，行 1915–1919）——已激活的凶事可以通过"忌回去"取消应期。"比如坐牢的宫位化禄位是贪污公款，你不贪污就不会坐牢。如果已经贪了，在坐牢的应期没有发生前快点还回去就行了。这个就是把已经化禄的事再忌回去。"
- **追禄的上限声明**（11 期，行 1875）——作者对追禄层数的节制："没有必要去再查起因的起因。这也太累了。"

> ⚠ 以下仅做辨析用，不进入本 KB 主线推理。

- **飞星紫微斗数**的"转忌"（飞忌）和追禄思路相近，都是靠四化链追因果——但飞星更多用忌链，本 KB 跟紫占方法论的立场是"追禄查因、追忌细化物"，两者分工。本 KB 不用"转忌"这个词，避免和飞星混用。
- **传统紫微 / 全书**基本上没有这套多层四化追溯法——传统用单宫 + 三方四正读，遇到复杂案例会说"还要看大运流年"。紫占拒绝这种推脱，要求在当前卦里就读完全部因果。
- 对照 [[过去卦与未来卦]] 页——追禄是过去卦的主力技术，"禄源激活"是未来卦的主力技术。
