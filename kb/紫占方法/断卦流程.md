# 断卦流程

> **核心原则：紫占断卦不是从一个宫位直接下吉凶，而是把心念、太极、三层卦、四化链、星意和现实校验串成一条可复查的推理链。**

## 核心原则

断卦的对象是一件具体事。流程的目的不是“更像大师”，而是降低三个系统性错误：

1. 时间和心念错，导致读的不是这件事；
2. 只看单宫单层，导致把局部相当成结果；
3. 没有现实校验，导致卦象被主观臆断带跑。

APK 入门资料给了“来因三层卦九步骤”。入库时这里把它改写成与本 KB 已有方法一致的检查流程：先验证输入，再立太极，再读三层，最后做四化链、正向应卦和现实校验。

## 操作步骤

### 0. 验证输入

- 问题必须是一件事，不能一卦多问。
- 起念时间必须精确到分钟，且要确认不是说完话 / 预约 / 转述时间。
- 心念必须能压成一句话。做不到就先回到 [[心念]]。
- 时间边界、月系星、边界分钟先跑 [[紫占坑]] 自检。

### 1. 定问题对象

把问题先归类：

| 问题对象 | 首选太极 / 宫位 |
| --- | --- |
| 环境、趋势、录取、天气、外部条件 | 来因宫（天卦） |
| 本人能不能应对、竞争、试用期、行动结果 | 来因宫 + 命宫（天卦 + 人卦） |
| 对方想法、关系互动 | 切对象宫，再看对宫 / 相关宫 |
| 物品形状、位置、材质 | 来因宫 + 物象化 + 十二相 |
| 原因、代价、应期 | 来因宫 + 追禄 / 追忌 |

### 2. 定三层位置

按 [[三层卦]] 定主卦、流十分钟卦、流分钟卦。若用户给的盘已有“因 / 2 / 3”标注，直接采用；否则用公式定位。

退化情形先处理：

- 三层同宫：不可查，停手或只做极保守描述。
- 两层同宫：该宫权重大，但不能因此跳过另一层。
- 边界分钟：排相邻两卦，用卦意回证选一卦。

### 3. 读主卦：先看天意，不急着下结论

主卦看的是事情的大局和来因，不等于最终结果。先记：

- 主卦落宫；
- 主星和明显小星；
- 庙旺利陷；
- 四化从哪里发出、落到哪里；
- 和问题对象是否对口。

这一层只形成“故事主题”，不要直接判吉凶。

### 4. 读二层、三层：把主题变成故事

流十分钟卦像分针，流分钟卦像秒针。读法不是平均三层，而是层层嵌套：

- 主卦给主题；
- 二层给行动方向、条件、阶段；
- 三层给精细落点、反转、最终落相。

如果三层互相冲突，优先把冲突解释成故事转折，而不是挑一层忽略。

### 5. 抽取高权重宫位和星曜

统计哪些宫位和星曜被反复强调：

- 三层落点重复出现；
- 四化反复引向同一宫；
- 对宫、三方、双宫同卦一起指向同一对象；
- 阴煞、天才、陀罗、地劫、铃星等干扰星强烈出现。

高权重点决定断语的主语，不要被边角星带跑。

### 6. 用四化链细化

- **对象不清 / 星意太抽象**：追忌。忌链常是解释说明宫。
- **原因、触发、应期不清**：追禄。禄链常看事情从哪里开始、靠什么推动。
- **没有四化可追**：不要伪造链条，改用一六共宗、冲宫合卦、双宫同卦。

追链的目标是让判断更具体，不是为了让流程变复杂。

### 7. 成象与合象

按 [[物象化]] 和 [[../断事方法/星意还原]] 合象：

1. 找相关星：本宫、对宫、三方、四化链指向宫。
2. 定星的属性：心念决定取人事、物象、身体、关系还是动作属性。
3. 拼成一张画面：用最少的星描述最清楚的相。

简约优先。一个简单现象不要套十颗星。

### 8. 做正向应卦检查

任何倾向结论都必须过 [[../断事方法/正向应卦]]：

- 这件事的性质是什么？
- 盘里看似“坏”的星，是否正好对应这件事需要的功能？
- 盘里看似“好”的星，是否在这个场景反而不对口？

输出时必须带语境：“在 X 类事上，这个结构才倾向 Y。”

### 9. 下断语并回到现实校验

对卦主输出时，不要堆星名和术语。断语结构建议：

1. 先说当前状态；
2. 再说主要推动力 / 阻力；
3. 再说条件内走向；
4. 最后给 2-4 个现实校验点。

卦象不清楚就说不清楚。不要为了完整而硬断。

## 常见误用

- **问事业直接看官禄宫。** 宫位要由心念和太极决定，不是机械映射。
- **主卦化忌就判凶。** 主卦只是主题，二三层和正向应卦可能反转。
- **忽略庙陷和小星。** 星名不是状态；庙陷和小星决定味道。
- **追忌追禄混用。** 忌偏解释和终止，禄偏原因和触发；不要当成同一种链。
- **对当事人讲术语。** 内部推理可以写星名，外部回复要翻译成现实语言。
- **制造恐慌。** 不确定或不利结构只能说明条件和风险，不做恐吓式断语。
