# 同音卦

> **核心原则：一颗星除了「原始星意」之外，还有一条通过同音 / 象形 / 语义类比扩展出来的表达通道，叫同音卦。紫占断事时这两条通道并行——问题与哪条通道对得上，就用哪条。**

## 核心原则

每颗星在紫占里其实有两套说法：

1. **原始星意**——这颗星在本体层面到底是什么（天机 = 动、道；天同 = 心 / 感知 / 认同；等等）。所有纯理上的推理都从这里发。
2. **同音卦**——由原始星意派生出来、经由汉语同音、字形或象形的通道加挂上去的"一层约定表达"。比如"天机"派生出"机器"，"化科"派生出"登科"，"天同 + 地劫（窟窿）"派生出"瞳孔"。

紫占断事时两条通道都要留着。看到问题的语境是哪一类就切到哪一条：问的是机器 / 算法 / 心机——走同音卦「机器 / 算计」这边；问的是一个东西在动、在走路、走得快走得慢——回到原始星意「动 / 道」。

同音卦**不是**原始星意的替代品，是附在它上面的**另一个采样口**。该用哪个看事情本身的性质。

## 为什么

原始紫微学派不采用"吉凶格局"标签，把星退回底层含义再投影。这个做法的代价是：很多日常语言里已经约定成俗的用法（"登科"讲的是考中、"天机"讲的是机器）其实不在底层含义里，直接抹掉会丢掉一些**好用的中文现成词组**。

紫占方法论的原作者处理这个问题的方式是开同音卦这条通道——**原始星意是骨，同音卦是这块骨在中文里已经被用熟的那几个身位**。比如：

> "天机的原始星意只有动、道这两个意思。但天机的同音卦太多了，只要和机器、算计有关的都可以用天机表示。"
> ——紫占方法论，13 期

作者很明确：原始星意优先，同音卦作为"另外还可以这么读"的补充。不是两套并列的字典，是一条主干加一些约定好的 alias。

这样处理的好处：

- 遇到真的讲机器 / 电脑 / 数据的紫占卦，"天机"不用先翻译成"动"再强行对回"机器"，直接走同音。
- 遇到问的是"这条路能不能走通"，同音那条就自动退到背景，只剩原始星意"动 / 道"参与推理。
- 避免把"登科 = 考中"这种原本只是同音联想的用法当成化科的本意，进而避免所有化科的人都被断成"会有功名"这种明显不合实际的结论。

## 操作步骤

1. **先定住这颗星的原始星意。** 这一步不能跳。同音卦是原始星意的 alias，不先定主词根直接翻字典会出错。参见各 [[../星曜/README|星曜]] 页的「原始星意」节。
2. **判断问题的语境属于哪一类。**
   - 物理 / 底层状态 / 数理——走原始星意（天机 = 动、贪狼 = 体积变化、巨门 = 门开 / 关）。
   - 日常事物 / 约定俗成的中文用词——尝试走同音卦（天机 = 机器、化科 = 登科、天同 + 地劫 = 瞳孔）。
3. **两条线都读一遍做交叉验证。** 如果原始星意和同音卦指向同一件事，这个断语很稳。如果两者矛盾，回去查问题抓的是不是这颗星本身管的事。
4. **标注走的是哪条通道。** 输出时说清楚："这里『天机』用的是它的同音——机器 / 算法"。下游才知道这是一条**约定的**扩展，不是从原始星意硬推的。
5. **不要把同音卦当成通用结论。** "化科 = 登科"不等于所有化科的人都会考中功名；它只是中文语境里被反复用熟的一个 alias，遇到真在问学业 / 考试时才启用。

## 典型触发信号 / 适用场景

- 来访问的事情是一个**具体物体 / 电子产品 / 机械结构**——考虑同音：天机 = 机器、廉贞 = 电子产品、天同 + 地劫 = 瞳孔 等。
- 原始星意直读**怎么都对不上来访者描述的那个东西**——换同音通道试一下。
- 出现了**中文里已经自带同音联想**的用法（"登科""机关""同理"之类）——这时就是检测同音卦是否适用的时候。
- 紫占占物——作者原话："研究紫占时的中期，要习惯把人间听到的所有话用紫占翻译"（8 期）。

## 常见误用 / 坑

- **把同音卦当原始星意用。** 最典型的坑：把"登科"塞进化科的本意里，默认每个化科人都"有功名"。原作者专门出来纠正：大多数化科的人并不出名（11 期）。登科只是同音 alias，不是本意。
- **原始星意都没定住就开始联想。** 不先把"天机 = 动、道"立住直接跳到"天机 = 机器"，断复杂卦时会出问题：因为只有同音那一层，推理链很脆。
- **同音卦在命盘推演里随便用。** 紫占方法论的原作者在多处强调他自己这一套的很多用法"在紫占中会有奇效，在普通紫微命盘时不要用"（11 期）。同音卦尤其是这样——命盘是一辈子，加太多同音 alias 会稀释原始星意的力量。
- **穷举同音去硬套。** "化禄 = 发财 + 高兴 + 录取"——把所有谐音字往上堆，结果反而不知道该用哪一条。同音卦的启用要看问题的语境，不是看这个字还能念成几个字。

## 支撑案例 / 引用

直接来自 [[../../sources/紫占方法论|紫占方法论]] 的四条：

- **天机的同音通道（13 期，行 2031–2033）**："天机的原始星意只有动、道这两个意思。但天机的同音卦太多了，只要和机器、算计有关的都可以用天机表示。"
- **天同 + 地劫 = 瞳孔（13 期，行 2035）**："天同本不代表这个，但同 + 地劫（窟窿）就是瞳孔的意思了。"这条是最清楚的同音 + 象形组合：天同（同）+ 地劫（窟窿）= 同字的窟窿 = 眼睛里的圆洞 = 瞳孔。
- **化科 ≠ 登科（12 期，行 2121）**：作者在讨论化科时点出，化科的本意是"拖延 / 缓慢 / 延续 / 回退 / 补救"；"登科"是一个同音用法，**不是**本意。很多化科的人并不真的考中或出名，误用"登科"会在断学业 / 名声卦时大量翻车。
- **作者对同音卦的框架表态（13 期，行 2025–2027）**："因为一颗星表现的出的方式有两种，有他自己的原始星意，也有同音卦。"

> ⚠ **源文档的同音卦体系是不完整的。** 作者答应给一份系统的同音卦清单，但这份连载停在 20 期、最终没有给出。目前可引用的只有上面这三四个点对点的例子。未来本 KB 的同音卦条目应该在实战占例里**一条一条收集**——看到一个新的约定同音，记录"星组合 → 约定表达 → 第一次被这样用的出处"。不要试图从中文字典反推。

## 参考（他派对照，非本 KB 主线）

> ⚠ 以下仅做辨析用，不进入本 KB 主线推理。

- **飞星紫微斗数**里也有"化科 = 声名 / 功名"的固定读法，但飞星把这当成本意而非同音。本 KB 跟原始紫微的立场一致，把"登科"归入同音通道，不归本意。
- **传统紫微**（全书一脉）不区分"原始星意 vs 同音卦"——把星的各类联想都当成并列的"意思"罗列。原始紫微学派认为这种罗列法掩盖了底层结构，断细节卦会失焦。
