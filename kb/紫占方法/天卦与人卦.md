# 天卦与人卦

> **核心原则：太极点选在来因宫，看的是天意；选在命宫，看的是本人如何应对天意。**
> 问题的输出是否依赖本人主动应变，决定要不要加看人卦。

## 核心原则

紫占的太极点有两种默认选择——来因宫（天卦）与命宫（人卦）。作者原话：

> 对于我的体系来说，分成两大类天卦和人卦，天卦就是来因宫为太极点的三层卦象体系，人卦是命为太极点的三层卦象体系。（line 917）

> 天卦是大环境，人卦就是要看我怎么在这个大环境下应变，应变的好就是吉，应变的不好就是凶。（line 919）

两者不是互斥的。它们是一件事的两个切面：**天卦说环境推着你往哪走，人卦说你能不能顶得住环境的推力**。天卦的力量决定了事件本身的基调，人卦决定了基调会不会被本人改写。

这也是紫占与命盘立太极最大的不同。命盘默认立命，切换太极点是为了换解释对象（父母 / 配偶 / 子女）；紫占默认立来因，切换到命宫是为了加一层**本人应对力**的读取，不换对象（详见 [[../断事方法/宫位立太极]]）。

## 为什么

看"房子会不会升值"这种问题，结果是外界经济走出来的，个人再怎么想也影响不了大方向——这类问题命宫无效信息，看了反而增加噪声（line 921）。

看"试用期能不能过"、"谈感情能不能成"、"考试能不能赢过竞争对手"这类问题，天意给出的是一股力量——辞退你的力量、拆散你们的力量、对手压你的力量——本人能不能顶住这股力量才是结果。这时只看天卦读出的是"会被淘汰"，但没说你能不能翻盘；必须再看人卦三层能不能克制天卦三层，克住就过，克不住就不过（line 923-927）。

> 常见的试用期的卦，一般主卦都会说怎么样就会被淘汰掉。这时人卦就很重要了，是要看你自己的3层卦能不能克制住开除你的力量。如果能克制住就是能通过试用，不能就过不了试用期。考试时的竞争卦也是这个样子。（line 925-927）

所以题型决定要不要用人卦，不是每卦必看。

## 操作步骤

1. **分类题型。** 判断问题的输出类型：
   - **输出靠环境**（房子是否升值、宏观经济走势、考试是否录取、对方是否来、物件在哪里）→ 仅天卦。
   - **输出靠本人应变**（试用期、竞争、争夺、抵抗、谈判对抗）→ 天卦 + 人卦。
   - **问题对象不是卦主自己**（问配偶、子女、老板）→ 按 [[../断事方法/宫位立太极]] 的规则切换太极到对应宫位，**不是默认走人卦**。
2. **排天卦。** 太极立**来因宫**，按 [[三层卦]] 排主卦 / 流十分钟 / 流分钟。读天卦的第一步意思：大环境的基调是什么、这股力量要把事推到哪里。
3. **若需要人卦，再排一套三层。** 太极立**命宫**，同样的起念时间、同样的真太阳时，但主卦位换成命宫，流十分钟和流分钟全部以命宫为起点重新排。注意：两套三层卦用的是**同一张紫微盘**，只是太极点换了、从哪一格起读变了。
4. **比较两卦的力量。** 天卦给出一股推力（例："被淘汰"），人卦给出一股应对力（例："顶住"或"顶不住"）。哪一股力量更大，哪一股是结果。
5. **力量比较的依据**来自星的庙旺、四化、宫位、煞星匹配——这部分详见 [[../断事方法/星意还原]] 和 [[../断事方法/正向应卦]]，此页不展开。
6. **避免混淆两卦结论。** 读天卦时把它当"外面"；读人卦时把它当"里面"。不要把人卦主卦的星拿来直接替代天卦主卦的星。

## 典型触发信号 / 适用场景

- **仅天卦就够**：
  - 房产升值 / 贬值（line 921）
  - 考试录取（学校端决定是否收）
  - 天气、路况、找物件、找人在不在
  - 宏观事件结果（股票大盘、行业走势）
  - 占物、占事（占闪电、占冰、占路上的人）——[[../../sources/紫占方法论|紫占方法论]] line 261-285 列举大量此类案例
- **天卦 + 人卦**：
  - 试用期能否通过（line 925）
  - 考试里有竞争对手要压制（line 927）
  - 感情谈判、商业谈判（能否顶住对方条件）
  - 病灶 / 症状是否被身体自身能克制（疾宫与命宫的对抗读法）
  - 官非、诉讼（天意判你输时本人能不能翻盘）
- **切换到其他宫做太极**（不走默认天/人卦）：
  - 问配偶的事 → 太极立夫妻宫
  - 问孩子的病 → 太极立子女宫
  - 问老板会不会炒你 → 太极立父母宫（领导位）
  - 这些属于 [[../断事方法/宫位立太极]] 的范围，不是本页主线。

## 例子

- **房子能不能升值**（line 921）——只看天卦。本人再怎么想升值也影响不了市场，命宫不看。天卦主卦若是"上行相"就升、"下行相"就跌。
- **谈感情但最后因财散**（line 923）——主卦（天卦）直接出"因财不合"这条路径。这类卦命宫再好也没用，钱的问题是外部条件。仅天卦。
- **试用期**（line 925）——天卦主卦出"会被开除"的力量；再排人卦（太极立命），看命宫三层卦的总力量能否克住开除力。能克就通过、不能就走人。
- **考试有竞争对手**（line 927）——天卦给出对手的力量（对手是外部环境），人卦给出自己的应对力。人卦压住对手则胜。
- **占路边美女长相**（line 275-279）——只看天卦（她是外界对象）；命宫不看，因为不是卦主自己。

## 常见误用 / 坑

- **环境题强上人卦。** 问房子升值还要看命宫——命宫跟市场无关，加进来全是噪声，把"应该看的外部力量"稀释成"不知所云"。
- **应变题漏掉人卦。** 问试用期只看天卦，读到"会被开除"就断定过不了——忽略了命宫应变力可能把结果逆过来。
- **人卦当独立卦读。** 排出人卦三层后就当一个全新的盘读——忘了它只是对同一时刻、同一天意的第二个切入点。读出来的意思要能跟天卦对话（克 / 被克 / 中立），不是两个各自独立的故事。
- **太极切到其他宫却走"人卦"叫法。** 切到夫妻宫看配偶的事是 [[../断事方法/宫位立太极]]，不是本页定义的人卦。"人卦" = 命宫为太极，固定用法。
- **天卦主卦位不立在来因宫。** 主卦位默认来因宫（line 901）。立错位置整张天卦就不对了。
