# 适用边界

> **核心原则：紫占看一件事的当前快照和条件内走向，不替人做决定，也不把一卦当终生命盘。**

## 核心原则

紫占是紫微斗数体系里“为事服务”的分支。它共用原始星意、宫位立太极、四化链，但它的对象不是一个人的一生，而是**起念那一刻，一件具体事的状态**。

可以用三个边界理解：

1. **对象边界**：一件事，不是整个人生。
2. **时间边界**：当前条件下的短中期走向，通常 3-5 年内；越远越受外部变量改变。
3. **责任边界**：紫占描述状态、关系、条件、代价，不替人做决策。

APK 入门资料里有一句可作入口判断：命盘是固定的，占盘是变化的；**命盘不能用来看一件单事，占盘不能用来定终身。**

## 能做什么

| 能力 | 说明 |
| --- | --- |
| 描述当前状态 | 这件事现在处于什么结构、阻力在哪里、能量是否对口。 |
| 看条件内走向 | 在现有条件不大变的前提下，事情会往哪个方向发展。 |
| 揭示隐藏信息 | 通过阴煞、天才、陀罗、追忌等看到当事人未意识到的因素。 |
| 追因果和代价 | 用追禄、追忌看事情从哪里来、靠什么推进、代价落在哪。 |
| 读物象 | 对物品形状、材质、颜色、结构、缺口做物象化描述。 |
| 辅助校验现实 | 把卦意转成现实锚点，让卦主回证，而不是只给玄学断语。 |

## 不能做什么

| 不能项 | 原因 |
| --- | --- |
| 不能替人做决定 | 决策涉及价值、风险承受、责任归属；卦只能给结构信息。 |
| 不能直接给绝对是 / 否 | 紫占的输出是状态图，不是单比特答案；倾向要附条件。 |
| 不能无限预测未来 | 外部条件变了，当前快照的解释范围就失效。 |
| 不能把卦当命看 | 占盘是起念快照，不是出生盘；一卦里的破财、桃花、疾病不等于命里如此。 |
| 不能绕过现实证据 | 结论必须能回到现实验证；无法验证的说法不应成为核心判断。 |
| 不能处理混合问题 | 一个卦只服务一个清晰心念；多问题需要拆卦。 |

## 判断一件事是否适合紫占

适合：

- “这次面试能不能推进？”
- “这个合作现在的问题在哪里？”
- “这个东西丢在哪里，形状/位置有什么相？”
- “他刚才那句话是真的吗？”
- “我现在想换工具/供应商，这个选择的结构对不对？”

不适合：

- “我这一生怎么样？”
- “我什么时候发财？”
- “所有关系里我到底是什么命？”
- “帮我随便看一卦。”
- “我已经决定了，只想让卦证明我对。”

## 和命盘推演的边界

| 维度 | 命盘推演 | 紫占 |
| --- | --- | --- |
| 盘的来源 | 出生时间 | 起心念时间 |
| 服务对象 | 人的一生结构 | 一件具体事 |
| 太极默认 | 命宫 | 来因宫 / 命宫 / 对象宫 |
| 应期体系 | 大限、小限、流年 | 三层卦、四化链、追禄 |
| 结果形态 | 长期结构、性格、人生轨迹 | 当前状态、条件内走向、物象、风险点 |

两者可以互相参照，但不能互相替代。命盘可以给长期结构，紫占可以看当下事件；如果两者冲突，先检查问题是不是把“人”和“事”混在了一起。
