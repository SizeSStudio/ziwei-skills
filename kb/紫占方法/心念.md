# 心念

> **核心原则：心念不是情绪，也不是愿望；心念是这张卦的输入信号。**
> 同一张盘，问题焦点不同，宫位、星意取法、合象方向都会改变。

## 核心原则

紫占用起念那一分钟排盘，但“那一分钟”本身还不够。时间给出的是天地快照，**心念给出这张快照要读哪一件事**。所以紫占里常说“卦随念走”：问工作的卦、问关系的卦、问物品的卦，即使盘面相似，读法也不一样。

APK 入门资料把心念列为紫占四要素之一，强调：

- 心念决定卦的焦点；
- 心念影响合象时每颗星取哪一层属性；
- 心念不纯净时卦象会变得混杂；
- 心念层级决定是读表面现象、关系互动、因果链，还是本质结构。

这和 [[起卦流程]] 的“起念时间”是一组概念：**起念时间解决何时拍照，心念解决拍照时到底在问什么。**

## 为什么

紫微盘不是“自动回答所有问题”的机器。盘面上同时有十二宫、星曜、四化、三层卦、多种相法，如果没有心念，解释空间过大，任何宫都可以被拉出来说话。

心念的作用类似查询条件：

| 心念要素 | 它决定什么 |
| --- | --- |
| 问题对象 | 该立哪个太极点：来因宫、命宫，还是切到夫妻、官禄、田宅等对象宫。 |
| 问题类型 | 读环境、读本人回应、读对方状态、读物象，还是读应期。 |
| 问题层级 | 只描述当前状态，还是追原因、追代价、追未来变化。 |
| 语境范围 | 同一星意在什么事上“对口”，从而进入 [[../断事方法/正向应卦]] 判断。 |

心念混乱时，盘面会同时带出多个问题的相。此时不是卦“坏”，而是输入本身把几个查询混在一起，后续断语自然会漂。

## 操作步骤

1. **把问题压成一句话。** 先写成“我想问 X 这件事，现在是什么状态 / 会怎么走 / 为什么这样”。写不成一句话，说明不是一卦一事。
2. **标出对象。** 这件事主要是环境、本人、对方、物品、家庭、事业、钱、身体，还是某个具体人？对象决定太极点。
3. **标出动作。** 是问能不能成、对方想法、原因、应期、风险，还是物象描述？动作决定读三层、追忌、追禄、十二相中的哪一类。
4. **回到第一念。** 记录第一次被这件事撞到的时间，不取说完话、预约、转述给别人、开始分析的时间。
5. **拆开多重问题。** “他喜不喜欢我、会不会复合、什么时候联系我”至少是三卦，不要硬塞进一卦。
6. **检查情绪噪声。** 愤怒、恐惧、极度期待会让起念变成“我想要某答案”，不是“我想看这件事”。情绪太强时先停。

## 心念层级

| 层级 | 问法 | 主要工具 |
| --- | --- | --- |
| 表面层 | “现在是什么状态？” | 三层卦、星意还原、物象化 |
| 关系层 | “我和他 / 这个对象之间是什么关系？” | 宫位立太极、冲宫合卦、一六共宗 |
| 因果层 | “为什么会这样？代价是什么？” | 追禄、追忌、四化组意 |
| 本质层 | “这件事真正的结构是什么？” | 三层合象、阴煞 / 天才 / 陀罗等干扰星、现实校验 |

层级越深，越需要现实校验。不要拿一个表面层问题强行读成本质层问题。

## 常见误用

- **把愿望当心念。** “我希望他回来”不是问题；“这段关系现在还有没有主动回流的结构”才是问题。
- **一卦多问。** 同一时间问三个问题，卦面容易混合，后续只能得到一团相。
- **问题太抽象。** “我以后怎么样”不是紫占问题；紫占服务一件具体事，不服务漫无边界的人生总问。
- **被别人诱导起念。** 卦主本来没想这事，是卦师追问后才想，这一念里已经有卦师的相。
- **情绪压过问题。** 强烈恐惧、报复、执念会让卦面优先呈现心态状态，而不是事情本身。
