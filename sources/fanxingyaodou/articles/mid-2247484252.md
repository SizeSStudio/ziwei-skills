# 吉星的阴差阳错-右弼

## 前言

在之前的文章里，我们一点点的为煞星正明了，让大家清晰了煞星的原始意向是什么，虽然古人说是煞星，但其实很多时候都并不算坏，反而为我们这个社会的发展，为了我们个人的发展提供了许多的帮助，可以说，没有煞星就，没有现在人类社会的发展，而从今天开始我们将开始讲解吉星！来看看所谓的吉星真的都有那么好吗？

这一系列的文章我取名叫吉星的阴差阳错，也是有趣，因为吉星的性质就是这么有趣！另外我也需要在文章开头再次的提醒大家，紫微斗数断命，不看单宫也不看单星，我们看的是整体，一个宫位的整体是怎样的，在 12 个宫位里这个整体又是怎样的，紫微斗数的体系是一套在系统内完全自洽的体系，是形成圆融循环的！

之前写了有关煞星的文章后，有好多朋友看到自己的宫位内有煞星后被吓到了，这里我要跟大家道个歉，我过去写的文章还是不够的详细和基础，不能让更多的人看懂，使得大家再看完后，还是不能理性客观的看待宫位，被吓一大跳！

我在这里还是要很郑重的跟大家说，单宫不论命，要整体全盘的看！

另外有一个可以判断你对单宫的判断是否正确的方法，因为在这个世界上没有任何事物是孤立存在的，每个事物间存在其联系，我们是可以从其他宫位去倒推你觉得不好的那个宫位，这样可以验证那个宫位是不是不好！同时，通过此举，我们也可以知道那个宫位为什么不好，我们也就只通过紫微斗数就知道如何改命的方法了！这是最好的方法，也并不涉及什么高深的技法，一切都在最基础里，只要你能真正的学会紫微斗数！话不多说，我们开启吉星的阴差阳错！

# 主星与小星的关系

我们要想炒一盘菜，食材虽然是重要的，但最后菜炒的好不好吃，其实是由所放的调料来决定的！主星是食材，小星是调料！你若是没法分辨，盐、鸡精、味精，你是没法判断分寸的！能不能调出蘸鞋底都好吃的调料，核心就在于学习原始星意！

# 右弼星的星意及应用

右弼星，属木，其实就是转变改变。就是这么简单的，但需要注意的是右弼的转变力度各有不同，主要在于所在的地支宫位，有些宫位是 180° 的转变，有些却幅度很小。

![image](https://mmbiz.qpic.cn/mmbiz_jpg/WteAm6SzIyiaECYQNYZF6MrwqbHQPVWDBTc4fxQX7ticsicEqNFU8sPsmNoC4q7HUfvE0gxjj4kpYS5LZKNFnTUQw/640?wx_fmt=webp&from=appmsg)

我亲身就经历了有好多人，在流年走到右弼的宫位，整个人发生了巨大的转变，但同样的，转变也是没有固定方向的，就意向中只会代表转变，要变得更好还是变得更坏只看命盘是没法确定的，只能通过你已经拥有了什么去判断转变成了什么。

比如，紫微右弼，紫微是最好的，那么加上右弼的话，会代表变得更好，同样的，你要是本来就很好的话，那可能会变得更差，所以这个性质是不太能是通过命盘就确定下来的，但可以确定的是一定会有些地方是发生了变化的。

所以我们可以通过右弼来确定是否转变改变了。

我们在起卦的时候用右弼会比较多 ，比如起卦的时候问，这个人有没有变心，那夫妻宫要是出现右弼的话，可能就是代表变心了，因为情感状态改变了，但感情改变也是很正常的，每个人的心都如流水般变化。感情状态改变了不代表会分手，因为在现在这个诱惑颇大的世界，你会喜欢很多的人，对很多人的喜欢其实也并不是因为合适，而是各种混杂的情绪，但跟你能在一起的人就那么几个，所以如果要看分手的话，还需要看兄弟宫和田宅宫有没有变动，这俩的决定因素会更大些，不过因为紫占的复杂性，对紫占卦象的梳理比紫微要更难，我们依旧不能以单宫单个意向去判断，我写在这是提醒读者，不要看到我写的一个比较容易应验的口诀后，就拿回去无脑的套用自己的命盘，然后自己吓自己，每个人盘都不一样，每个人也都是独立的人，就算你们的命盘是一样的，但那只是高维与你在相链接后输出的一个参数而已，每个人的着重点还会更有不同。需要我们再次链接后才能联通到未来的你，看到更多的信息。

右弼星跟左辅一样，还有同音卦，就是向右的意思，这一点很容易应在开车的司机上，开车又是向右，又是转向的。

# 右弼星在命盘中的应用案例

给大家来看看我的命盘，我命盘中的左辅和右弼是很特殊的，他体现了我的很多特质！

宫中的吉星蛮多的，还没讲解的我们暂时先不讲，只说左辅和右弼！

![image](https://mmbiz.qpic.cn/mmbiz_jpg/WteAm6SzIyiaECYQNYZF6MrwqbHQPVWDBibak4qro87INhdCUzXSyFyyNmgKuVtEST6rNQSrw5NTFbNr1zET10NQ/640?wx_fmt=jpeg&from=appmsg)

迁移宫，破军、左辅，就是多次向外突破的意思，有文曲，代表是突破什么内容，陀罗在迁移宫之前说了其实就是轮回，总结就是多次突破轮回内容。

在迁移宫的这套组合，是描述了我能够不断的突破，人生不可避免的就会面临多次的突破改变，带来超脱出这个轮回的知识和信息，这个也是我一直在做的事情，给大家写文章，教会大家紫微斗数的文章只是顺便的，更核心的是让大家能有更超脱的意识，来解决自己生活中的问题，能带来更高维的知识这个是我的天赋使命，所以我也想给大家真正的带来有用的东西，而不是陷入迷性里。

我们再看官禄宫，紫微，最高级的，文昌，传达信息，右弼行动改变，天越，高维直接帮助的，封诰被封存的信息，天厨技巧技术，阴煞，这个位面看不见的信息。

从官禄宫看的话， 我的官禄宫也是去做一些传递一些更高级的、未知的看不见的信息，简单来看就是这样，传道授业解惑嘛！

然后在这其中的右弼的话，他让我不执着，当我意识到这样做是错误的时候，我会快速的转变，并不会拘泥于身份地位积累之类的！我的行为不断的改变，只为了追寻大道，所以这样也让我的成长不是线性的，而是指数性提升的，因为如果你没有过去，不拘泥于过去的话，你就可以快速的切换，当然这个快速的切换也不是像现在说的那样云淡风轻。

很多时候，转变也是很痛苦的，但也能转，转完后继续投入其他的战场上！

紫微右弼的转变，前面说了，可能转向更差，也可能转向更好，而我的应用就是让自己转向更好更高！

我之前看到一个特别有意思的话：人类如何成长，其实就是不断的杀死过去的自己！过去的你已经死了，你自然也拥有新生了！

所以，最近也有不少朋友说我最开始写的那几篇主星的文章，说我之前说的那样，但现在怎么矛盾了，我在这里给大家再预告一下，我们在更新完辅星后，就会开始更新主星，更新理论体系，之前的文章没写错但不究竟，我们到最后还是要以原始星意来看全盘！希望大家能多多支持啦！

# 右弼星在各宫位的表现

然后，右弼星的转变，在各宫位也不同。

命宫的是自己人生的转变

父母宫，父母的转变，就是换父母嘛！在孩子身上就是容易遭遇父母离婚。这个在现代社会是很容易应验的，毕竟离婚率那么高了。父母宫也是文书位，所以转学，换专业也是在这看的。
