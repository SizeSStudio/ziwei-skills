## 陀罗星的深意与应用

需要注意的是有三颗星的组合是固定的，即擎羊、禄存、陀罗，这三颗星永远都是这么排的。所以我们提及的时候都说羊陀。

### 陀罗星的原始星意

陀罗属金，化气为忌。为原地打转，慢，拖延，旋转的意向，更有反复。大家在理解的时候经常只理解为陀螺，转圈圈之类的，那我问问大家，电钻算陀螺吗？算的，只要能转圈圈的都归在陀罗的意向里面，但具体怎么描述一个物体，我们还是要特别情况特别分析。

比如电钻，可以用武曲破军 + 陀罗来表示，强硬突破的反复旋转。再比如用呼拉圈减肥，可以拆分来分析：通过某个动作使得肉身变瘦，可以用陀螺 + 贪狼化忌，或者陀螺 + 太阴 + 天月。

### 陀罗的多维解读

-

• 二维平面：陀螺是一个圆

-

• 三维空间：陀螺是一个球

-

• 身体中的圆球状物：都可以用陀罗来表示

如何用陀罗形容踢足球？

天机（移动的） + 天梁（柱子） => 用脚去踢
陀螺（球状物） + 天马（移动） => 球的轨迹移动

## 陀罗的应验与突破

陀罗星的本意没什么不好的地方，就是一个反复旋转的意向，但实际应验在每个人的命盘里，老是容易出问题。所以往往陀罗所在的地方，往往就是你反复拖延，不愿意面对的点。遇到不好的情况，肿瘤的发生处往往也在有陀罗的地方。

陀罗和廉贞的功能类似：

-

• 陀罗：反复的重复走不开

-

• 廉贞：死死的抓紧不放手

这两年都是我们得肿瘤的原因，我们在不自觉的把气都聚在了一个地方。气聚在那里就容易长瘤子，堵塞！

所以在很多门派的应验上可以看到，陀罗和廉贞化禄化忌的时候，就容易死亡，因为这个就肿瘤扩大扩散的意向呀!

所以，我们可以从一个人的陀罗和廉贞的所在位置就知道一个人的弱点在哪？他哪里想不开一直在纠结!
