# 主星与小星的关系

我们要想炒一盘菜，食材虽然是重要的，但最后菜炒的好不好吃，其实是由所放的调料来决定的！主星是食材，小星是调料！你若是没法分辨，盐、鸡精、味精，你是没法判断分寸的！能不能调出蘸鞋底都好吃的调料，核心就在于学习原始星意！

# 左辅星的原始星意及应用

左辅属木，原始星意很简单，就是多的意思，但是需要注意的是，在实际应用的时候会出现同音卦，其他的星耀也都有这样的情况，市面上现在对星耀有各种各样的解释很大的原因就是因为同音卦的出现，同音卦不属于原始星意，因为这个会随着时代对名词定义的不同而改变。

这个原理要从占卜原理说起，占卜是人沟通天地的方法，是人类在没有直接到达高维方法时，通过投影的方法截取了一段信息，如果把我们现在所处的维度定义成 3 维，那术数就是属于 3.5 维的，截取信息的时候，3.5 维的信息会自动匹配我们所知的所有，就是说这个卦是专门为起卦的人呈现的，所以呈现的方式就会按照起卦人所能理解认知的信息呈现出来，只要基本功足够扎实就不会出现完全看不懂的卦象！

我们拿左辅举例，左辅的原始星意思是：多，很多的意思，其在数量上是 ≥2 的。

但在同音卦上，左辅可以拆分成：

-

1. 方向上的左，比如我们迷路了，起卦问，要往左走还是往右走，有左辅的话可能就是暗示我们要往左走，一些方向性相关的工作也会跟左辅有所关联

-

2. 辅助，顾名思义嘛，就是帮助，看一个人是不是你的助力。

所以，我们也可以简单的理解左辅这颗星了，就是 doubl！好的事情是可以翻倍，那坏的事情呢？坏的就不翻倍了？有一颗吉星在，同宫有煞星的话，不好的就会被化解掉？

你们要是按照什么是好，什么是坏，然后好坏混在一起就能怎样怎样的这套稀里糊涂的理论体系去学习的话，你这辈子没希望学会，有灵感的时候是可以断对不少信息，但那是灵感的功劳跟稀里糊涂的你没有关系！原谅我有点苛责了，但我是真的为紫微斗数这套体系而感到担忧，也是希望能有更多的人能看到原始星意，所以大家有希望的话，可以分享给别人，这是我的，更是左辅的意愿，因为左辅就是翻倍！你发给别人看了，那从数量上看不就是翻倍嘛？

# 左辅星在不同宫位的表现

言归正传，如果一个宫位所呈现出来的意向不太好的话，那加上左辅，会变得更加不好！当然如果是好事的话，那也是会更好的！

• 在兄弟宫，就兄弟姐妹多，有人说我是独生子女我也兄弟宫是左辅，那是不是错了 ，这是很好笑的一个事情，有些顾客闲的无聊，会让我们看看他们有没有兄弟姐妹是不是独生子，每次这种情况我都想翻白眼，你要是出生在上世纪五六十年代，那在农村，基本上家家户户都是一堆兄弟姐妹的，那你要是生在计划生育时代，你就算命盘里有很多兄弟姐妹的卦象，那你也不一定会有亲的兄弟姐妹，因为历史原因影响，再到现在这个时代，大家又不想生孩子了，那你是有还是没？时代大环境的影响笼罩着所有的人。
