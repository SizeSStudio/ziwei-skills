# ziwei-zhanbu — 紫占短期事件推演 Skill

基于原始紫微学派紫占方法论，针对**此时此刻一件具体事**（3-5 年内短期态势、应期与成败机制）进行一分钟级三层卦快照分析的 Claude Skill。

---

## 核心定位

- **服务范围**：针对具体单项事件（合作能不能成、某项交易前景、当前状态成因等）的精准研判。
- **排盘模型**：结合起念那一分钟的真太阳时与三层卦模型（主卦、流十分钟卦、流分钟卦）。
- **硬性约束**：严格遵循正向应卦判定（事之性质与星意是否吻合），给出 4-6 条可客观验证的现实校验锚点。
- **输出归档**：
  - `memo.md`：单次占事内部推理备忘录。
  - `reply.md`：面向咨询者的通俗综述。
  - 归档目标：`cases/divinations/<YYYY-MM-DD-topic>/`。
